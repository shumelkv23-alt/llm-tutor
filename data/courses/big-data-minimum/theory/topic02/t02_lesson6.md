# Метод главных компонент

## Снижение размерности

Метод главных компонент (PCA) заменяет много исходных признаков небольшим числом новых, сохраняя как можно больше разброса. Каждая главная компонента — линейная комбинация исходных признаков.

Перед PCA данные центрируют и приводят к одной шкале: иначе компоненты будут определяться единицами измерения. Компоненты ортогональны друг другу и упорядочены по объяснённой дисперсии: первая объясняет больше всех.

PCA полезен для визуализации (две компоненты на плоскость), сжатия и борьбы с мультиколлинеарностью. Уменьшение размерности может улучшить kNN и другие методы, убирая шум.

## Компоненты и интерпретация

Число компонент выбирают по доле объяснённой дисперсии (например, 80–95%) или по «каменистой осыпи» графика. Компоненты не обязаны иметь простой смысл: это смеси признаков.

В книге PCA применяют к пищевой ценности продуктов: много нутриентов сводят к нескольким осям, а продукты изображают на плоскости. Группы продуктов становятся видны без ручного выбора признаков.

Ограничения: PCA ловит только линейные связи, чувствителен к масштабу и выбросам, а интерпретация компонент затруднена. Для нелинейного сжатия нужны другие методы (t-SNE, UMAP, автоэнкодеры).
