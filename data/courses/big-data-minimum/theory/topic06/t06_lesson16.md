# Устройство нейронной сети

## Нейроны и слои

Нейронная сеть состоит из слоёв нейронов: входного, одного или нескольких скрытых и выходного. Каждый нейрон получает значения от предыдущего слоя, умножает их на веса, складывает с порогом и применяет функцию активации.

Веса — обучаемые параметры. Сеть с достаточным числом нейронов может приближать сложные нелинейные функции; глубина позволяет строить иерархии признаков.

Число входов задаётся признаками, число выходов — задачей: один выход для регрессии или бинарной классификации, несколько — для классов.

## Прямой проход

Прямой проход вычисляет прогноз: входные данные активируют первый слой, его выход становится входом следующего, и так до последнего слоя.

Для классификации выход часто интерпретируют как вероятности (softmax для нескольких классов, sigmoid для двух). Для регрессии — как число.

В книге сеть распознаёт рукописные цифры: вход — пиксели изображения, выход — одна из десяти цифр. Обучение подстраивает веса так, чтобы правильный выход был выше остальных.

Сети требуют много данных и вычислений; результат плохо интерпретируется.
