# Нормализация, регистр и сортировка Unicode

## Нормализация и регистр

Один и тот же символ можно записать по-разному: «é» как один код или как «e» плюс комбинирующий акут. Для сравнения строк их приводят к одной форме: `unicodedata.normalize("NFC", text)` или `"NFD"`.

NFC собирает комбинирующие символы, NFD разлагает их. NFKC и NFKD дополнительно заменяют совместимые символы (например, полноширинные формы). Нормализуйте обе строки перед сравнением, поиском и сохранением ключей.

`str.lower()` меняет регистр, но не всегда так, как нужно для сравнения без учёта регистра: немецкая `ß` и греческая сигма требуют `casefold()`. `casefold()` агрессивнее и подходит для поиска и ключей.

Удаление диакритики: разложить строку в NFD и отфильтровать символы категории `Mn` (Mark, nonspacing).

## Сортировка

`sorted()` сравнивает строки по кодовым точкам, а не по правилам языка. Поэтому «ё» может оказаться после всех латинских букв, а заглавные — раньше строчных.

Для человеческой сортировки применяйте ключ: `str.casefold` для регистронезависимой, `locale.strxfrm` для правил локали, `unicodedata.normalize` перед сравнением. В Unicode Collation Algorithm (модуль `pyuca`) задан порядок для языков.

Сортировка по кодовым точкам детерминирована и годится для машинных ключей; для показа пользователю нужен языковой порядок.
