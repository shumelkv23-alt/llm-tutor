# Ошибки кодирования и работа с файлами

## Ошибки кодирования

`UnicodeEncodeError` возникает, когда символ нельзя представить в целевой кодировке, например `"€".encode("ascii")`. `UnicodeDecodeError` — когда байты не являются корректной последовательностью в указанной кодировке.

У методов есть параметр `errors`: `strict` (по умолчанию), `ignore` (выбросить проблемные символы), `replace` (`?`), `backslashreplace`, `xmlcharrefreplace`. `ignore` опасен: текст молча теряет данные.

Если кодировка неизвестна, её определяют эвристикой (`charset_normalizer`, `chardet`) и проверяют результат глазами. Для исходников Python кодировку объявляют комментарием в первой или второй строке, иначе интерпретатор читает файл как UTF-8.

## Файлы и BOM

Всегда передавайте `encoding` в `open`, `Path.read_text` и `Path.write_text`: иначе используется локальная кодировка, и код по-разному ведёт себя на разных машинах.

BOM — невидимый символ U+FEFF в начале файла. Для UTF-8 с BOM используйте кодировку `utf-8-sig`: она съедает BOM при чтении и добавляет при записи. UTF-16 и UTF-32 тоже могут начинаться с BOM.

Для бинарных файлов открывайте режим `"rb"`/`"wb"` и работайте с `bytes`; смешивать текстовый и бинарный режимы нельзя.
