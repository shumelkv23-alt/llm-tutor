# Символы, кодировки и базовые преобразования

## Кодовая точка, символ, байт

`str` в Python — последовательность Unicode-символов (кодовых точек), а не байтов. `bytes` — последовательность октетов от 0 до 255. Эти типы несовместимы: нельзя смешать `str` и `bytes` без явного преобразования.

Unicode сопоставляет каждому символу кодовую точку: `ord("A") == 65`, `ord("€") == 8364`. Кодовая точка — абстрактное число; представление в байтах зависит от кодировки.

Кодировка — правило отображения кодовых точек в байты. UTF-8 кодирует ASCII одним байтом, а остальные символы — двумя–четырьмя; это самая распространённая кодировка для файлов и сети.

## encode и decode

`str.encode(encoding)` превращает текст в `bytes`; `bytes.decode(encoding)` — обратно. Кодировку нужно указывать явно: по умолчанию `encode` использует UTF-8, но читаемость кода от этого не страдает.

```python
text = "Привет"
data = text.encode("utf-8")
assert data.decode("utf-8") == text
```

`bytes([65, 66])` создаёт байты из чисел, `bytearray` — изменяемую версию. Для работы с бинарными форматами используйте `memoryview` и модуль `struct`, а не склеивайте строки.
