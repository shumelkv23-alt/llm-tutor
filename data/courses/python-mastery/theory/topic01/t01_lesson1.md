# Специальные методы и протоколы

## Протоколы вместо наследования

Специальные методы — это обычные методы с именами вида `__len__`, которые Python вызывает сам. Они позволяют вашим классам вести себя как встроенные типы, не наследуясь от них: достаточно реализовать нужный протокол.

Протокол — это набор методов, которых достаточно, чтобы объект поддерживал операцию. Например, последовательность узнаётся по `__len__` и `__getitem__`; итерация — по `__iter__`; контекстный менеджер — по `__enter__` и `__exit__`.

## Что вызывает интерпретатор

`len(x)` вызывает `x.__len__()`, `x[i]` — `x.__getitem__(i)`, `for` — `x.__iter__()` или, если его нет, `__getitem__` с индексами 0, 1, 2… Оператор `in` сначала пробует `__contains__`, затем итерацию. `repr(x)` вызывает `__repr__`, `str(x)` — `__str__` (или `__repr__`, если `__str__` нет).

Специальные методы не стоит вызывать вручную: `len(x)` понятнее и работает для встроенных типов, где `x.__len__` может отсутствовать. Исключение — вызов родительской реализации через `super()`.
