# Функции как объекты

## Функции первого класса

Функция — объект: её можно присвоить переменной, передать аргументом, вернуть из функции и положить в структуру данных. Поэтому функции высшего порядка (`map`, `filter`, `sorted(key=...)`) работают без специального синтаксиса.

```python
def shout(text):
    return text.upper()

actions = {"shout": shout, "fail": str.lower}
actions["shout"]("привет")
```

`lambda` — короткая анонимная функция для одного выражения. Для сложной логики лучше обычная функция с именем: её видно в трассировке.

Современная альтернатива `map`/`filter` — генераторные выражения и включения; `functools.reduce` нужен редко.

## Вызываемые объекты и параметры

Вызываемым может быть не только функция: метод, класс, экземпляр с `__call__`, встроенная функция. Все они отвечают на `callable(x)`.

Параметры можно делать позиционно-только (`def f(a, /, b)`) и именованно-только (`def f(*, b)`). Это защищает API от путаницы аргументов.

`operator` даёт готовые функции (`itemgetter`, `attrgetter`, `methodcaller`) вместо lambda. `functools.partial` фиксирует часть аргументов и создаёт новый вызываемый объект.
