# Замыкания и nonlocal

## Области видимости

Python ищет имя по правилу LEGB: локальная область, затем объемлющие функции, затем глобальная, затем встроенная. Присваивание внутри функции создаёт локальное имя, если оно не объявлено `global` или `nonlocal`.

```python
count = 0

def increment():
    global count
    count += 1
```

`global` меняет глобальное имя; `nonlocal` — имя в ближайшей объемлющей функции. Без объявления `count += 1` поднимет `UnboundLocalError`: Python считает `count` локальным на всю функцию.

## Замыкания

Замыкание — функция, которая запоминает переменные из объемлющей области, даже после того как та завершилась:

```python
def make_counter():
    count = 0

    def counter():
        nonlocal count
        count += 1
        return count

    return counter
```

`counter` хранит ссылку на ячейку `count`, а не копию значения. Поэтому несколько вызовов видят одно состояние, а два вызова `make_counter()` дают независимые счётчики.

Замыкания захватывают переменные по ссылке, а не по значению. В цикле это приводит к позднему связыванию: все лямбды увидят последнее значение. Исправляется аргументом по умолчанию (`lambda i=i: ...`) или отдельной фабрикой.
