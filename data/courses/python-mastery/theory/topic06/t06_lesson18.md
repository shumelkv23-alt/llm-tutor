# Декораторы и кэширование

## Простые декораторы

Декоратор — вызываемый объект, который получает функцию и возвращает замену. Синтаксис `@decorate` означает `func = decorate(func)` и выполняется при определении функции, обычно при импорте модуля.

```python
import functools

def logged(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("вызов", func.__name__)
        return func(*args, **kwargs)
    return wrapper
```

`functools.wraps` переносит имя, документацию и аннотации исходной функции; без него инструменты видят `wrapper`. Декоратор может регистрировать функцию в реестре, проверять аргументы, повторять вызов при ошибке.

Декоратор выполняется один раз при определении, а `wrapper` — при каждом вызове. Это важно, когда нужны побочные эффекты на этапе импорта.

## Кэш и параметризованные декораторы

`functools.cache` (и `lru_cache`) запоминает результаты по аргументам. Аргументы должны быть хешируемыми; функция не должна зависеть от изменяемого состояния.

```python
@functools.cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

Параметризованный декоратор — это фабрика: `@retry(times=3)` сначала вызывает `retry(times=3)` и получает декоратор. Внутри появляется третий уровень вложенности.

`functools.singledispatch` выбирает реализацию по типу первого аргумента — удобная альтернатива длинной цепочке `isinstance`.
