# Кортежи, распаковка и сопоставление с образцом

## Кортеж как запись

Кортеж — не просто неизменяемый список. В роли записи он хранит поля по позициям: `("Москва", 12.6, 55.75)`. Доступ по индексу читается плохо, поэтому для записей берут `namedtuple` или `@dataclass`.

Неизменяемость кортежа относится к ссылкам: сам кортеж нельзя расширить или заменить элемент, но изменяемый объект внутри него менять можно.

## Распаковка и match

Распаковка присваивает элементы переменным и проверяет их число:

```python
city, population, latitude = record
first, *rest = [1, 2, 3, 4]
```

`*rest` собирает остаток в список. Вложенную структуру можно распаковать так: `(a, b), (c, d) = [(1, 2), (3, 4)]`.

Оператор `match` (Python 3.10+) сравнивает структуру, а не только значение:

```python
match record:
    case [name, value]:
        ...
    case [name, *rest]:
        ...
```

Образец `[name, value]` требует ровно два элемента, `name` и `value` — захватывающие переменные, `_` — что угодно. `if` после образца добавляет охраняющее условие.
