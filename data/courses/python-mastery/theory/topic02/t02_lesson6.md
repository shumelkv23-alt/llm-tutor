# Срезы, конкатенация и выбор структуры

## Срезы и операции

Срез `s[start:stop:step]` не включает `stop`. Индексы могут быть отрицательными, шаг — отрицательным (тогда обход идёт с конца). Срез всегда создаёт новый объект, копируя ссылки.

```python
s = "bicycle"
s[::3]      # 'bye'
s[::-1]     # 'elcycib'
```

Присваивание срезу меняет длину списка: `lst[2:5] = [10]` заменяет три элемента одним. Это работает только у изменяемых последовательностей.

`+` и `*` создают новые последовательности. `lst += other` для списка меняет его на месте, а для кортежа создаёт новый объект. Умножение списка списков повторяет ссылки: `[[0] * 3] * 2` даёт две ссылки на один внутренний список.

## Выбор структуры

`list` — универсальный, но не всегда лучший выбор:

- `array.array` хранит числа компактно и умеет `tofile`;
- `memoryview` даёт доступ к буферу без копирования;
- `numpy.ndarray` — для численных массивов и векторных операций;
- `collections.deque` — быстрые добавления и удаления с обоих концов.

`sorted()` возвращает новый список, `list.sort()` сортирует на месте и возвращает `None`. Ключ `key=` вычисляется один раз на элемент, поэтому сортировка по вычисляемому признаку эффективнее функции сравнения.
