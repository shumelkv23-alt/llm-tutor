# Списковые включения и генераторные выражения

## Включения и читаемость

Списковое включение собирает новый список в одном выражении:

```python
symbols = "$¢£¥€¤"
codes = [ord(symb) for symb in symbols if ord(symb) > 127]
```

Оно читается лучше связки `map`/`filter` с `lambda`, когда нужны и преобразование, и отбор. В Python 3 переменная включения живёт в своей области и не протекает наружу.

Порядок вложенных `for` повторяет порядок в обычных циклах: `[x for row in matrix for x in row]` идёт по строкам, затем по элементам строки. Декартово произведение — два независимых `for` подряд.

## Ленивые генераторы

Генераторное выражение выглядит как включение в круглых скобках, но не строит список: `(ord(symb) for symb in symbols)` создаёт итератор, который вычисляет элементы по одному.

```python
total = sum(ord(symb) for symb in symbols)
```

Это экономит память на больших данных. Генератор одноразовый: после полного перебора он пуст, повторный `list(gen)` даст `[]`. Если результат нужен несколько раз, сохраните его в список.
