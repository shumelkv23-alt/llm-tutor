# Отсутствующие ключи: defaultdict, __missing__, Counter

## defaultdict и __missing__

`d[key]` поднимает `KeyError`, если ключа нет. `get` возвращает `None`, но не создаёт запись. `setdefault` создаёт ключ со значением по умолчанию.

`collections.defaultdict(list)` вызывает фабрику при обращении к отсутствующему ключу и сразу создаёт его:

```python
index = defaultdict(list)
for word in words:
    index[word[0]].append(word)
```

Свой класс-наследник `dict` может определить `__missing__(key)`: словарь вызовет его, если ключа нет. Это удобно, когда значение зависит от ключа. В стандартной библиотеке `__missing__` используют редко и не всегда последовательно.

## Другие отображения

- `Counter` считает элементы и умеет `most_common(n)`;
- `ChainMap` ищет ключ в нескольких словарях по очереди, не сливая их;
- `OrderedDict` сохраняет дополнительные гарантии порядка и имеет `move_to_end`;
- `UserDict` удобнее наследовать, чем `dict`: внутренние методы не обходят ваш класс;
- `MappingProxyType` даёт неизменяемое представление словаря.

Выбирайте минимальный инструмент: `Counter` для частот, `defaultdict` для группировки, `ChainMap` для настроек с переопределением.
