# Хеширование и устройство dict

## Хешируемость и устройство dict

Словарь — хеш-таблица. Ключ должен быть хешируемым: у него есть `__hash__`, а равные ключи имеют равный хеш. Числа, строки, кортежи из хешируемых элементов подходят; список и словарь — нет.

Хеш не гарантирует уникальность: коллизии разрешаются сравнением `__eq__`. Поэтому изменяемый объект нельзя делать ключом — после изменения его хеш поменяется, и словарь его не найдёт.

С Python 3.7 словарь сохраняет порядок вставки. Внутри — компактный массив записей и таблица индексов; удаление оставляет «дыры», которые переиспользуются при новых вставках.

## API и представления

Основные операции: `d[key]`, `d.get(key, default)`, `d.setdefault(key, default)`, `d.pop(key, default)`, `d.update(other)`, `d.items()`, `d.keys()`, `d.values()`.

Объединение словарей: `d | e` создаёт новый словарь, `d |= e` обновляет левый. Распаковка `{**d, **e}` тоже создаёт новый и удобна в литералах.

`keys()`, `values()` и `items()` — представления, а не копии. Они отражают текущее состояние словаря, поддерживают `len` и перебор, а `keys()` и `items()` — ещё и операции над множествами.
