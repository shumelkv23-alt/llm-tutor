# NamedTuple и @dataclass

## Именованные кортежи

`collections.namedtuple("Point", "x y")` создаёт подкласс tuple с полями. Экземпляр остаётся кортежем: работает распаковка, индексация, сравнение по значениям; он неизменяемый и хешируемый, если поля хешируемы.

`typing.NamedTuple` добавляет аннотации типов:

```python
class Point(NamedTuple):
    x: float
    y: float
```

Аннотации не проверяются во время выполнения, но помогают читать код и инструментам. Поле с значением по умолчанию должно идти после полей без него.

## @dataclass

`@dataclass` генерирует `__init__`, `__repr__` и `__eq__` по аннотированным полям. Это изменяемый класс, а не кортеж: экземпляр занимает больше памяти, зато поля можно менять и добавлять методы.

```python
@dataclass(frozen=True)
class Point:
    x: float
    y: float
```

`frozen=True` запрещает присваивание полей и даёт хеш. `order=True` добавляет сравнения `<`, `<=`, `>`, `>=`. `slots=True` (Python 3.10+) экономит память.

Выбирайте `NamedTuple` для маленьких неизменяемых записей, `dataclass` — когда нужны методы, изменяемость или сложные значения по умолчанию.
