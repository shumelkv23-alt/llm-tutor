# Ссылки, изменяемость и копирование

## Ссылки и алиасы

Переменная в Python — имя, связанное с объектом, а не коробка со значением. Присваивание `b = a` связывает два имени с одним объектом: это алиасы. Изменение изменяемого объекта через `b` видно через `a`.

`==` сравнивает значения, `is` — идентичность объектов. `is` уместен для `None`, `True`, `False` и проверки, что два имени указывают на один объект; для чисел и строк он не гарантирует ожидаемого.

Передача аргумента в функцию тоже передаёт ссылку. Функция может изменить переданный список, но не может переприсвоить имя вызывающего кода.

## Копирование и время жизни

Поверхностная копия (`list(x)`, `x[:]`, `copy.copy`) создаёт новый контейнер, но вложенные объекты остаются общими. Глубокая копия (`copy.deepcopy`) рекурсивно копирует вложенные структуры; она дороже и не всегда нужна.

Классическая ловушка — изменяемое значение по умолчанию:

```python
def add(item, bucket=[]):   # один список на все вызовы
    bucket.append(item)
    return bucket
```

Правильно — `bucket=None` и создать список внутри функции.

`del name` удаляет имя, а не объект; объект живёт, пока на него есть ссылки. CPython освобождает объект по подсчёту ссылок и умеет собирать циклы сборщиком мусора. `weakref` позволяет ссылаться на объект, не продлевая его жизнь.
