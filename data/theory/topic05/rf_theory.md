# Почему лес работает

Случайный лес часто работает «из коробки» лучше, чем можно ожидать.
Занятие объясняет это через разложение ошибки на смещение и разброс:
случайность в признаках уменьшает корреляцию между деревьями, а смещение
леса остаётся таким же, как у одного глубокого дерева. Заодно познакомимся
с родственным методом — Extremely Randomized Trees.

## Зачем

После занятия вы сможете:

- записать, от чего зависит разброс ответа случайного леса;
- объяснить, почему рост числа деревьев лесу не вредит, а корреляция между
  деревьями ограничивает выигрыш;
- сказать, как смещение леса соотносится со смещением одного дерева;
- обучить `ExtraTreesClassifier` и объяснить, чем он отличается от леса.

## Декорреляция деревьев

### Главное

Разброс среднего `B` деревьев с дисперсией `σ²` каждое и попарной
корреляцией `ρ` равен

`Var = ρ·σ² + (1 − ρ)·σ²/B`.

Чтобы он был мал, нужны малые `ρ` и достаточно большое `B`. Эта формула
объясняет все решения в конструкции леса.

**Число деревьев `B`.** Второе слагаемое убывает с ростом `B`. Первое от
`B` не зависит, поэтому после определённого числа деревьев качество
выходит на плато. Важно: добавление деревьев **не увеличивает** разброс и не
приводит к переобучению — худшее, что произойдёт, лес станет не лучше, а
обучение и прогноз замедлятся.

**Корреляция `ρ`.** Она определяет «пол» разброса. Бутстрэп уменьшает её,
но слабо: деревья по выборкам одних данных похожи. Случайные подпространства
уменьшают её сильнее, потому что в разных узлах доступны разные признаки.
Платой за это становится небольшой рост дисперсии одного дерева (оно
видит не лучшие признаки), но выигрыш от декорреляции обычно больше.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

rng = np.random.default_rng(0)
n, d = 600, 30
X = rng.normal(size=(n, d))
y = ((X[:, 0] + 0.7 * X[:, 1] + rng.normal(0, 1.0, n)) > 0).astype(int)

for B in (1, 5, 25, 100, 300):
    forest = RandomForestClassifier(n_estimators=B, random_state=17)
    score = cross_val_score(forest, X, y, cv=5).mean()
    print(B, "деревьев -> точность", round(float(score), 3))

# Корреляция ответов двух разных деревьев одного леса.
forest = RandomForestClassifier(n_estimators=50, random_state=17).fit(X, y)
p0 = forest.estimators_[0].predict_proba(X)[:, 1]
p1 = forest.estimators_[1].predict_proba(X)[:, 1]
print("корреляция двух деревьев:", round(float(np.corrcoef(p0, p1)[0, 1]), 2))
```

### Частые ошибки

- **Бояться «слишком много деревьев».** Лес не переобучается от их числа;
  разумный предел — время.
- **Ждать, что с ростом `B` качество растёт бесконечно.** Выигрыш упирается в
  корреляцию между деревьями.
- **Считать корреляцию между деревьями вредной сама по себе.** Нужен баланс:
  слишком сильная декорреляция делает отдельные деревья слабыми.

## Смещение леса

### Главное

Смещение среднего равно смещению отдельной модели: усреднение не меняет
математическое ожидание ответа. Деревья леса — глубокие, их смещение мало. Но
у них есть оговорка: из-за случайных подпространств и бутстрэпа каждое
дерево чуть хуже подогнано, чем одно дерево на всех данных, поэтому смещение
леса теоретически **может быть чуть выше** смещения глубокого дерева; на практике они
примерно равны.

Следствие: **выигрыш леса идёт от разброса**, а не от смещения. Лес
снижает ошибку главным образом тем, что гасит неустойчивость глубоких
деревьев. Поэтому лес нельзя «починить» усреднением, если базовые деревья
слишком простые: у мелкого дерева высокое смещение, и ансамбль его
унаследует.

Отсюда практическое правило: деревья в лесу растят **глубокими**, а
разброс контролируют числом деревьев и `max_features`.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.tree import DecisionTreeRegressor

rng = np.random.default_rng(1)
x_grid = np.linspace(0, 6, 60).reshape(-1, 1)
truth = np.sin(x_grid).ravel()


def bias_variance(make_model, repeats=60):
    predictions = []
    for _ in range(repeats):
        x = rng.uniform(0, 6, (100, 1))
        y = np.sin(x).ravel() + rng.normal(0, 0.4, 100)
        predictions.append(make_model().fit(x, y).predict(x_grid))
    predictions = np.array(predictions)
    return (float(np.mean((predictions.mean(axis=0) - truth) ** 2)),
            float(predictions.var(axis=0).mean()))


tree_bias, tree_var = bias_variance(lambda: DecisionTreeRegressor())
forest_bias, forest_var = bias_variance(lambda: RandomForestRegressor(n_estimators=30, random_state=0))
print("дерево: bias² =", round(tree_bias, 3), "разброс =", round(tree_var, 3))
print("лес:    bias² =", round(forest_bias, 3), "разброс =", round(forest_var, 3))
```

### Частые ошибки

- **Ждать, что лес исправит недообучение.** Он лечит разброс; смещение
  остаётся.
- **Ограничивать глубину деревьев сильнее нужного.** Это поднимает смещение
  всего леса.
- **Путать разброс леса и шум.** Шум в данных ансамбль не уберёт.

## Extremely Randomized Trees

### Главное

**Extremely Randomized Trees** (ExtraTrees, «крайне случайные деревья»)
идут дальше случайного леса в сторону случайности. Различий два:

- каждое дерево обучается на **всей** обучающей выборке (по умолчанию без
  бутстрэпа);
- в узле для каждого из `m` случайных признаков порог выбирается **случайно**,
  а не ищется оптимальным; из случайных разбиений берут лучшее.

Случайные пороги дополнительно декоррелируют деревья и ускоряют обучение —
не нужно сортировать значения в поисках лучшего порога. Цена — чуть большее
смещение отдельного дерева. Метод стоит пробовать, когда случайный лес
слишком сильно **переобучается** на данных или нужен быстрый базовый
вариант. В scikit-learn: `ExtraTreesClassifier` и `ExtraTreesRegressor` с тем
же интерфейсом, что у леса.

### Пример

```python
import numpy as np
from sklearn.ensemble import ExtraTreesClassifier, RandomForestClassifier
from sklearn.model_selection import cross_val_score

rng = np.random.default_rng(2)
n, d = 500, 20
X = rng.normal(size=(n, d))
y = ((X[:, 0] - X[:, 1] + X[:, 2] * X[:, 3] + rng.normal(0, 1.0, n)) > 0).astype(int)

forest = RandomForestClassifier(n_estimators=150, random_state=17)
extra = ExtraTreesClassifier(n_estimators=150, random_state=17)
print("случайный лес:", round(float(cross_val_score(forest, X, y, cv=5).mean()), 3))
print("ExtraTrees:  ", round(float(cross_val_score(extra, X, y, cv=5).mean()), 3))
print("бутстрэп у ExtraTrees по умолчанию:", extra.bootstrap)
```

### Частые ошибки

- **Считать ExtraTrees всегда лучше леса.** Они иногда выигрывают, иногда
  проигрывают; сравнивайте на кросс-валидации.
- **Ждать бутстрэпа.** По умолчанию `bootstrap=False`; для OOB-оценки его
  включают (`bootstrap=True`).
- **Забывать про смещение.** Случайные пороги слегка поднимают смещение
  дерева; на очень простых данных это заметно.

## Итоги занятия

| Что | Что означает |
|---|---|
| `ρσ² + (1 − ρ)σ²/B` | разброс среднего B деревьев с корреляцией ρ |
| рост `n_estimators` | разброс не растёт, качество выходит на плато |
| случайные подпространства | снижают корреляцию деревьев |
| смещение леса ≈ смещение глубокого дерева | выигрыш леса — от разброса |
| `ExtraTreesClassifier` | то же, что лес, но пороги разбиения выбираются случайно |

Порядок рассуждения: разброс = корреляция + число деревьев → декорреляция
через подпространства → смещение не меняется → ExtraTrees как ещё более
случайный вариант.
