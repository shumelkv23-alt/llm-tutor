# Настройка леса

У случайного леса немного параметров, и он хорошо работает на значениях по
умолчанию. Но настройка всё же даёт прирост, а главное — позволяет понять,
какие параметры за что отвечают. Занятие — про `max_features`, остальные
гиперпараметры и кривые, по которым их подбирают.

## Зачем

После занятия вы сможете:

- выбрать `max_features` и объяснить, что происходит при слишком малом и
  слишком большом значении;
- назвать параметры, регулирующие сложность деревьев леса, и параметры,
  не влияющие на переобучение;
- построить кривую качества по числу деревьев или по другому параметру;
- найти разумные значения через `GridSearchCV` и OOB-оценку.

## max_features

### Главное

`max_features` — число признаков, из которых выбирается лучшее разбиение в
каждом узле. Это самый важный параметр леса, и вот как он действует.

- **Малое значение** — деревья сильно различаются (корреляция падает), но
  каждое строится по слабым случайным признакам и получается плохим
  (растёт смещение). Если информативных признаков мало, велик шанс, что в
  узле доступны одни шумовые.
- **Большое значение** — деревья хороши, но похожи друг на друга; в пределе
  `max_features = d` получается обычный бэггинг.

Правила, с которых начинают: классификация — `"sqrt"` (√d признаков),
регрессия — `1/3` (треть признаков). В scikit-learn значением может быть
целое число, доля, `"sqrt"` или `"log2"`. По умолчанию у
`RandomForestClassifier` стоит `"sqrt"`, а у `RandomForestRegressor` — все
признаки; для регрессии значение `1/3` задают явно.

Оптимум зависит от данных: если почти все признаки информативны, лучше
большее значение; если шумовых много — меньшее.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

rng = np.random.default_rng(0)
n, d = 500, 40
X = rng.normal(size=(n, d))
y = ((X[:, :5].sum(axis=1) + rng.normal(0, 1.5, n)) > 0).astype(int)   # 5 полезных из 40

for m in (1, 3, 6, 20, 40):
    forest = RandomForestClassifier(n_estimators=100, max_features=m, random_state=17)
    score = cross_val_score(forest, X, y, cv=5).mean()
    print(f"max_features={m:2d} -> {score:.3f}")
print("sqrt(40) =", int(np.sqrt(d)))
```

### Частые ошибки

- **Перебирать только `n_estimators`.** `max_features` обычно влияет сильнее.
- **Задавать `max_features` долей и забывать, что это доля от числа
  признаков.** Значение `0.5` на 40 признаках означает 20.
- **Принимать оптимум на одной выборке за универсальный.** Он зависит от
  числа информативных признаков.

## Гиперпараметры

### Главное

Параметры леса делятся на три группы.

**Размер ансамбля.** `n_estimators` — число деревьев. Чем больше, тем лучше
и стабильнее, до плато; переобучения от этого нет. Берут столько, сколько
позволяет время, обычно сотни.

**Сложность деревьев.** `max_depth` (максимальная глубина),
`min_samples_leaf` (минимум объектов в листе), `min_samples_split`,
`max_leaf_nodes`. Именно они регулируют **переобучение отдельных деревьев**.
По умолчанию деревья растут без ограничений, и обычно лучше всего именно так;
но если лес переобучается (на обучении 100%, на проверке заметно меньше),
помогают умеренные ограничения, чаще всего `min_samples_leaf`.

**Случайность.** `max_features`, `bootstrap` (использовать ли бутстрэп),
`max_samples` (размер бутстрэп-выборки).

Стопроцентная точность леса на обучающей выборке — **не** признак ошибки
сама по себе: глубокие деревья запоминают обучающие данные всегда. Судить о
переобучении нужно по OOB или тестовому качеству. Только если они заметно
ниже, имеет смысл усиливать ограничения.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier

rng = np.random.default_rng(1)
n = 600
X = rng.normal(size=(n, 12))
y = ((X[:, 0] - X[:, 1] + rng.normal(0, 1.2, n)) > 0).astype(int)

settings = [
    {"min_samples_leaf": 1},
    {"min_samples_leaf": 5},
    {"min_samples_leaf": 20},
    {"max_depth": 3},
]
for params in settings:
    forest = RandomForestClassifier(
        n_estimators=150, oob_score=True, random_state=17, **params
    ).fit(X, y)
    print(params, "обучение", round(forest.score(X, y), 3), "OOB", round(forest.oob_score_, 3))
```

### Частые ошибки

- **Пугаться 100% на обучении.** Для леса это норма; сравнивайте OOB и тест.
- **Ограничивать глубину сильно.** Так лес превращается в ансамбль слабых
  деревьев с высоким смещением.
- **Подбирать все параметры сразу большой сеткой.** Начните с
  `max_features` и `min_samples_leaf`, число деревьев задайте заранее.

## Кривые подбора

### Главное

Параметры леса удобно подбирать по **кривым**: строят качество на
валидации (или OOB) при разных значениях одного параметра, как в занятии про
кривые валидации. По кривой видно, где качество выходит на асимптоту, и нет
смысла тратить время на дальнейший рост.

Для `n_estimators` кривая выходит на плато: после этой точки качество почти
не растёт. Для `max_features` — как правило, с выраженным максимумом.
Инструменты: `validation_curve` и `GridSearchCV`, а для быстрой оценки —
OOB (`oob_score_`), которая не требует кросс-валидации и поэтому в несколько
раз дешевле.

Практический порядок: сначала дерево-«эскиз» с умеренным числом деревьев и
OOB, потом подбор `max_features` и `min_samples_leaf`, в конце — увеличить
`n_estimators` для финальной модели.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV, validation_curve

rng = np.random.default_rng(2)
n = 500
X = rng.normal(size=(n, 15))
y = ((X[:, 0] + X[:, 1] * X[:, 2] + rng.normal(0, 1.0, n)) > 0).astype(int)

forest = RandomForestClassifier(random_state=17)
sizes = [5, 20, 80, 200]
train, valid = validation_curve(forest, X, y, param_name="n_estimators",
                                param_range=sizes, cv=5)
for size, score in zip(sizes, valid.mean(axis=1)):
    print(size, "деревьев ->", round(float(score), 3))

grid = GridSearchCV(
    RandomForestClassifier(n_estimators=100, random_state=17),
    {"max_features": [2, 4, 8], "min_samples_leaf": [1, 5]},
    cv=3,
).fit(X, y)
print(grid.best_params_, round(grid.best_score_, 3))
```

### Частые ошибки

- **Выбирать `n_estimators` по обучающей линии.** Она почти не меняется, а
  решает валидация.
- **Подбирать параметры без фиксированного `random_state`.** Случайность леса
  маскирует различия между значениями.
- **Тратить время на тысячи деревьев на старте.** Сначала найдите хорошие
  значения остальных параметров на небольшом ансамбле.

## Итоги занятия

| Что | Что делает |
|---|---|
| `max_features` | сколько признаков доступно в узле; главный параметр |
| `"sqrt"` / `1/3` | значения для классификации и регрессии |
| `n_estimators` | число деревьев; больше — лучше, до плато |
| `max_depth`, `min_samples_leaf` | сложность деревьев; регулируют переобучение |
| `oob_score=True` | быстрая оценка без кросс-валидации |
| `validation_curve`, `GridSearchCV` | кривые и перебор параметров |

Порядок подбора: `max_features` → `min_samples_leaf` → число деревьев; оценка
— по OOB или кросс-валидации.
