# Случайный лес

Бэггинг деревьев даёт выигрыш, но деревья по бутстрэп-выборкам остаются
похожими: у всех в корне стоит один и тот же сильный признак. Случайный лес
добавляет ещё одну дозу случайности — случайные подмножества признаков — и
получает более разнообразные деревья. А ещё — бесплатную оценку качества без
отдельной проверочной выборки.

## Зачем

После занятия вы сможете:

- объяснить, чем случайный лес отличается от бэггинга над деревьями;
- выбрать число признаков для каждого разбиения (`max_features`) по правилу
  для классификации и регрессии;
- обучить `RandomForestClassifier` и получить оценку out-of-bag;
- объяснить, как считается ошибка out-of-bag и почему она честная.

## Случайные подпространства

### Главное

В бэггинге все деревья видят все признаки. Если один признак сильно
информативнее остальных, он окажется в корне почти каждого дерева, и деревья
станут очень похожими — а ансамбль из похожих моделей выигрывает мало.

**Метод случайных подпространств** решает проблему так: для построения
каждого разбиения признаки не перебирают все, а берут **случайное
подмножество** из `m` признаков и ищут лучшее разбиение только среди них.
Сильный признак доступен не всегда, поэтому в разных деревьях (и в разных
узлах одного дерева) решающую роль играют разные признаки. Деревья
**декоррелируют**, и разброс среднего ансамбля падает сильнее.

Размер подмножества `m` — главный параметр леса, `max_features`.
Практические рекомендации из статьи модуля: для **классификации** `m ≈ √d`,
для **регрессии** `m ≈ d/3`, где `d` — число признаков. Например, при 64
признаках в классификации берут 8, при 60 признаках в регрессии — 20.

### Пример

```python
import numpy as np

d = 64
print("классификация, d =", d, "-> m =", int(np.sqrt(d)))
print("регрессия, d = 60 -> m =", 60 // 3)

# Один сильный признак встречается в корне почти всех деревьев бэггинга,
# но реже — если на каждом разбиении доступна лишь часть признаков.
rng = np.random.default_rng(0)
n_trees, d = 1000, 10
available = rng.random((n_trees, d)).argsort(axis=1)[:, :3]    # 3 случайных признака из 10
print("сильный признак (номер 0) доступен в", round(float((available == 0).any(axis=1).mean()), 2),
      "узлов; при полном переборе - в 1.0")
```

### Частые ошибки

- **Оставлять `max_features` равным числу всех признаков.** Тогда лес
  вырождается в бэггинг.
- **Брать слишком маленькое `m`.** Деревья станут слабыми: слишком часто
  доступны только неинформативные признаки.
- **Переносить правило √d на регрессию.** Для регрессии рекомендуют `d/3`.

## Алгоритм леса

### Главное

**Случайный лес** (Random Forest, Лео Брейман, 2001) — это бэггинг глубоких
деревьев плюс случайные подпространства:

1. Для каждого из `B` деревьев сделать бутстрэп-выборку.
2. Растить дерево на ней без ограничения глубины (до листьев с заданным
   минимальным числом объектов). В **каждом** узле выбирать лучшее разбиение
   среди `m` случайно выбранных признаков.
3. Объединить ответы: в классификации — голосованием (или усреднением
   вероятностей), в регрессии — **усреднением** числовых ответов деревьев.

Отличие от бэггинга деревьев — только пункт про случайные подмножества
признаков при поиске разбиения. Деревья растят глубокими, потому что у глубокого дерева малое
смещение, а разброс гасит усреднение.

В scikit-learn: `RandomForestClassifier(n_estimators=…, max_features="sqrt",
random_state=…)` и `RandomForestRegressor`. Деревья обучаются независимо,
поэтому работу можно распараллелить: `n_jobs=-1`.

### Пример

```python
import numpy as np
from sklearn.ensemble import BaggingClassifier, RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(4)
n, d = 800, 30
X = rng.normal(size=(n, d))
y = ((X[:, 0] + X[:, 1] - X[:, 2] + rng.normal(0, 1.0, n)) > 0).astype(int)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17, stratify=y
)

bagging = BaggingClassifier(estimator=DecisionTreeClassifier(), n_estimators=100,
                            random_state=17).fit(X_train, y_train)
forest = RandomForestClassifier(n_estimators=100, max_features="sqrt",
                                random_state=17).fit(X_train, y_train)
print("бэггинг:", round(bagging.score(X_test, y_test), 3))
print("случайный лес:", round(forest.score(X_test, y_test), 3))
print("признаков на разбиение:", forest.estimators_[0].max_features_)
```

### Частые ошибки

- **Ограничивать глубину деревьев «для порядка».** Базовые деревья должны
  быть сложными; регуляризация леса — другими параметрами (занятие про
  настройку).
- **Путать голосование и усреднение вероятностей.** `predict_proba` леса —
  среднее вероятностей деревьев, а не доля голосов.
- **Забыть про `random_state`.** Без него результат леса нельзя
  воспроизвести.

## Оценка out-of-bag

### Главное

Около трети объектов не попадает в бутстрэп-выборку каждого дерева (вероятность
не быть вытянутым стремится к `1/e`). Для дерева эти объекты — настоящие
«новые» данные. Отсюда **оценка out-of-bag** (OOB):

1. Для каждого объекта найти деревья, которые его **не видели**.
2. Получить ответ только от этих деревьев (голосованием или усреднением).
3. Сравнить с истинным и усреднить качество по всем объектам.

Это почти то же, что кросс-валидация, но бесплатно: не нужно ни откладывать
часть данных, ни переобучать модель. Оценка получается не по обучающим
ответам, а по ответам деревьев, не знавших объект, поэтому не завышена.

В scikit-learn: `RandomForestClassifier(oob_score=True)`; после `fit`
доступны `oob_score_` (точность) и `oob_decision_function_`. Для надёжной
оценки нужно достаточно деревьев, чтобы каждый объект побывал вне
бутстрэп-выборки хотя бы у некоторых.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(5)
X = rng.normal(size=(600, 10))
y = ((X[:, 0] - X[:, 1] + rng.normal(0, 1.0, 600)) > 0).astype(int)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17, stratify=y
)

forest = RandomForestClassifier(n_estimators=200, oob_score=True, random_state=17)
forest.fit(X_train, y_train)
print("точность на обучении:", round(forest.score(X_train, y_train), 3))   # завышена
print("oob_score_:", round(forest.oob_score_, 3))
print("на отложенной выборке:", round(forest.score(X_test, y_test), 3))     # близко к OOB
```

### Частые ошибки

- **Считать точность на обучении оценкой качества.** Лес почти всегда
  запоминает обучающие данные; смотрите на OOB или тест.
- **Включать `oob_score` при малом числе деревьев.** Объекты, не оказавшиеся
  вне ни одной выборки, останутся без OOB-ответа.
- **Подбирать параметры по OOB, а итог оценивать им же.** Как и с
  кросс-валидацией, финальную проверку лучше делать на отложенных данных.

## Итоги занятия

| Что | Что делает |
|---|---|
| случайные подпространства | на каждом разбиении перебирают `m` случайных признаков |
| `max_features="sqrt"` / `1/3` | правило для классификации (√d) и регрессии (d/3) |
| `RandomForestClassifier(n_estimators, max_features)` | бэггинг глубоких деревьев + подпространства |
| `oob_score=True`, `oob_score_` | оценка качества по деревьям, не видевшим объект |
| `n_jobs=-1` | параллельное обучение деревьев |

Порядок работы: задать число деревьев и `max_features` → обучить → посмотреть
OOB → при необходимости подбирать параметры.
