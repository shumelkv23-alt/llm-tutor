# Ансамбли и бэггинг

Одно дерево нестабильно: чуть изменили данные — получили другое дерево.
Идея ансамблей в том, чтобы обучить много моделей и усреднить их ответы:
ошибки разных моделей частично гасят друг друга. Занятие объясняет, почему
это работает, как получить много разных выборок из одной (бутстрэп) и как из
этого строится бэггинг.

## Зачем

После занятия вы сможете:

- объяснить, что такое ансамбль, и пересказать идею теоремы Кондорсе;
- построить бутстрэп-выборку и сказать, какая доля объектов в неё попадает;
- обучить `BaggingClassifier` над деревьями и сравнить его с одним деревом;
- объяснить, почему усреднение снижает разброс и когда эффект максимален.

## Мудрость толпы

### Главное

**Ансамбль** — набор моделей, ответы которых объединяют в один общий:
голосованием в классификации, усреднением в регрессии. Основание —
«мудрость толпы»: независимые ошибки разных участников компенсируют друг
друга. Формальный вариант для классификации — **теорема Кондорсе о
присяжных**: если каждый из `n` независимых присяжных прав с вероятностью
больше 0,5, то вероятность верного решения большинства выше, чем у любого
одного, и стремится к 1 с ростом `n`.

Ключевые условия: модели должны быть **лучше случайного угадывания** и
**независимыми** (или хотя бы мало коррелированными). Если все модели
ошибаются на одних и тех же объектах, голосование ничего не даёт. Поэтому
главный вопрос при построении ансамбля — как получить разнообразные модели.
Для этого меняют обучающие данные (бэггинг), признаки (случайный лес), сами
алгоритмы.

### Пример

```python
from math import comb

import numpy as np


def majority_accuracy(n_voters: int, p: float) -> float:
    """Вероятность, что большинство из n независимых избирателей право."""
    need = n_voters // 2 + 1
    return sum(comb(n_voters, k) * p**k * (1 - p) ** (n_voters - k) for k in range(need, n_voters + 1))


for n in (1, 5, 25, 101):
    print(n, "моделей по 0.6 ->", round(majority_accuracy(n, 0.6), 3))

# Проверка симуляцией: 101 независимая модель, каждая права с вероятностью 0.6.
rng = np.random.default_rng(0)
votes = rng.random((20000, 101)) < 0.6
print("симуляция:", round(float((votes.sum(axis=1) > 50).mean()), 3))
```

### Частые ошибки

- **Считать, что ансамбль всегда лучше.** Если базовые модели хуже случайных
  или одинаково ошибаются, большинство не поможет.
- **Забыть про независимость.** Копии одной модели не образуют «толпу».
- **Усреднять сильно разные по качеству модели без весов.** Слабая модель
  может испортить результат сильной.

## Бутстрэп

### Главное

Чтобы получить разные модели, нужны разные обучающие выборки, а данные у нас
одни. **Бутстрэп** решает задачу: из выборки размера `n` берут `n` объектов
**с возвращением**. Получается новая выборка того же размера, в которой
одни объекты повторяются несколько раз, а другие не встречаются вовсе.

Вероятность того, что конкретный объект не попал ни в одну из `n` попыток,
равна `(1 − 1/n)ⁿ` и при больших `n` стремится к `1/e ≈ 0,368`. Значит, в
бутстрэп-выборку попадает **около 63%** различных объектов исходной
выборки, а около трети остаются вне её. Эти «невыбранные» объекты потом
пригодятся для честной оценки (out-of-bag, ближе к концу модуля).

В `numpy` бутстрэп-выборка — `rng.choice(n, size=n, replace=True)`: индексы
объектов с повторами.

### Пример

```python
import numpy as np

rng = np.random.default_rng(1)
n = 1000
shares = []
for _ in range(200):
    idx = rng.choice(n, size=n, replace=True)
    shares.append(len(np.unique(idx)) / n)
print("доля уникальных объектов:", round(float(np.mean(shares)), 3))   # около 0.632
print("предел 1 - 1/e:", round(1 - 1 / np.e, 3))

small = rng.choice(10, size=10, replace=True)
print(sorted(small.tolist()))          # есть повторы и пропуски
```

### Частые ошибки

- **Выбирать без возвращения.** Тогда выборка того же размера совпадёт с
  исходной (перестановка), и разнообразия не будет.
- **Ждать, что в выборку попадут все объекты.** Около трети остаётся вне
  каждой бутстрэп-выборки.
- **Применять бутстрэп к зависимым наблюдениям** (временные ряды) без
  учёта зависимости.

## Бэггинг

### Главное

**Бэггинг** (bagging, Bootstrap AGGregatING — «бутстрэп и объединение») —
метод Лео Бреймана, 1994 год:

1. Сделать `B` бутстрэп-выборок из обучающих данных.
2. На каждой обучить свою базовую модель (чаще всего глубокое дерево).
3. Объединить ответы: голосованием в классификации, усреднением в регрессии.

Базовые модели делают **глубокими**: у глубокого дерева малое смещение, но
большой разброс, а усреднение как раз гасит разброс. Каждое дерево видит
чуть другие данные, поэтому деревья получаются разными.

В scikit-learn: `BaggingClassifier(estimator=DecisionTreeClassifier(),
n_estimators=B)`. Параметр `random_state` фиксирует выборки. Обучается
ансамбль обычным `fit`, прогнозирует `predict`; к нему применимы все
инструменты оценки.

### Пример

```python
import numpy as np
from sklearn.ensemble import BaggingClassifier
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(2)
X = rng.normal(size=(600, 6))
y = (X[:, 0] + X[:, 1] * X[:, 2] + rng.normal(0, 0.8, 600) > 0).astype(int)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17, stratify=y
)

tree = DecisionTreeClassifier(random_state=17).fit(X_train, y_train)
bagging = BaggingClassifier(
    estimator=DecisionTreeClassifier(), n_estimators=50, random_state=17
).fit(X_train, y_train)
print("одно дерево:", round(tree.score(X_test, y_test), 3))
print("бэггинг:", round(bagging.score(X_test, y_test), 3))
print(len(bagging.estimators_), "деревьев в ансамбле")
```

### Частые ошибки

- **Бэггинг над сильно ограниченными деревьями.** Мелкие деревья имеют
  большое смещение, которое усреднение не лечит.
- **Брать слишком мало моделей.** Эффект проявляется с десятков деревьев.
- **Ждать выигрыша от бэггинга над устойчивой моделью** (линейной
  регрессией): её разброс и так мал, усреднять нечего.

## Почему падает разброс

### Главное

Пусть `B` моделей дают ответы с одинаковой дисперсией `σ²`. Если модели
**независимы**, дисперсия их среднего равна `σ²/B` — падает в `B` раз. Если
же их ответы связаны корреляцией `ρ`, дисперсия среднего:

`ρ·σ² + (1 − ρ)·σ²/B`.

Отсюда два вывода. Во-первых, добавление моделей уменьшает только вторую
часть, а первая — `ρ·σ²` — остаётся. Эффект ограничен корреляцией между
деревьями бэггинга: деревья по бутстрэп-выборкам одних данных довольно
похожи. Во-вторых, чем сильнее разброс отдельной модели (глубокие деревья,
малая выборка), тем больше выигрыш: поэтому бэггинг особенно помогает на
**малых выборках**, где базовые модели получаются очень разными.

Смещение при усреднении не растёт: среднее нескольких моделей с одинаковым
смещением имеет то же смещение. Итог — ошибка падает за счёт разброса.

### Пример

```python
import numpy as np

rng = np.random.default_rng(3)
sigma, trials = 1.0, 20000

for rho in (0.0, 0.5, 0.9):
    for B in (1, 10, 100):
        shared = rng.normal(size=(trials, 1))                 # общая часть ошибки
        own = rng.normal(size=(trials, B))                    # своя часть ошибки
        errors = sigma * (np.sqrt(rho) * shared + np.sqrt(1 - rho) * own)
        measured = errors.mean(axis=1).var()
        theory = rho * sigma**2 + (1 - rho) * sigma**2 / B
        print(f"rho={rho} B={B:3d}: измерено {measured:.3f}, формула {theory:.3f}")
```

### Частые ошибки

- **Ждать, что дисперсия упадёт до нуля при росте числа моделей.** Остаётся
  вклад корреляции между моделями.
- **Считать, что бэггинг снижает смещение.** Он снижает разброс; смещение
  остаётся таким же, как у базовых моделей.
- **Путать разброс модели и шум в данных.** Шум неустраним, ансамбль его не
  уберёт.

## Итоги занятия

| Что | Что делает |
|---|---|
| ансамбль | объединяет ответы нескольких моделей (голосование, среднее) |
| теорема Кондорсе | независимые модели лучше случайных → большинство ещё лучше |
| `rng.choice(n, size=n, replace=True)` | бутстрэп-выборка: n объектов с возвращением |
| ≈ 63% / ≈ 37% | доля попавших / не попавших в бутстрэп-выборку |
| `BaggingClassifier(estimator=…, n_estimators=B)` | бэггинг над базовой моделью |
| `ρσ² + (1 − ρ)σ²/B` | дисперсия среднего B коррелированных моделей |

Порядок рассуждения: нужно много разных моделей → бутстрэп даёт разные
выборки → бэггинг усредняет → разброс падает, смещение не меняется.
