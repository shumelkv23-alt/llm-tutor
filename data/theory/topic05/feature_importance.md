# Важность признаков

Случайный лес не только предсказывает, но и отвечает на вопрос «на какие
признаки он опирается?». Это ценно для понимания задачи и отбора признаков.
Занятие — про два способа посчитать важность (по неоднородности и
перестановочную), их достоинства и подводные камни и про разбор кейса с
оценками хостелов.

## Зачем

После занятия вы сможете:

- объяснить идею важности признака на интуитивном уровне;
- посчитать перестановочную важность и объяснить, что именно она измеряет;
- получить `feature_importances_` леса и знать, чему равна их сумма и когда
  они завышают важность;
- прочитать важности в кейсе и сформулировать осторожный вывод.

## Идея важности

### Главное

Что значит «признак важен»? Интуитивно — если мы уберём его (или испортим),
качество модели заметно упадёт. Для деревьев есть и более прямое наблюдение:
**чем ближе признак в среднем к корню** деревьев, тем важнее — в корне
стоит разбиение, которое лучше всего делит всю выборку, а до нижних узлов
доходит лишь малая её часть.

Из этой интуиции вырастают два практических способа:

- **по прибыли от разбиений**: за каждое разбиение по признаку засчитывают,
  насколько оно уменьшило неоднородность (энтропию, Джини, дисперсию), с
  учётом доли объектов, прошедших узел; сумма по всем узлам и деревьям —
  важность признака;
- **перестановочная**: портим один признак и смотрят, насколько просело
  качество.

Оба способа дают **относительные** числа: они сравнивают признаки внутри
одной модели, но не отвечают на вопрос «этот признак причина результата».
Важность описывает модель, а не мир.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier

rng = np.random.default_rng(0)
n = 600
important = rng.normal(size=n)
helper = rng.normal(size=n)
noise = rng.normal(size=(n, 3))
X = np.column_stack([important, helper, noise])
y = ((2 * important + 0.7 * helper + rng.normal(0, 0.8, n)) > 0).astype(int)

forest = RandomForestClassifier(n_estimators=150, random_state=17).fit(X, y)
names = ["important", "helper", "noise1", "noise2", "noise3"]
for name, value in sorted(zip(names, forest.feature_importances_), key=lambda p: -p[1]):
    print(f"{name:10s} {value:.3f}")
```

### Частые ошибки

- **Считать важность причинностью.** Она показывает, на что опирается
  модель, а не что влияет на мир.
- **Сравнивать важности из разных моделей напрямую.** Шкалы зависят от модели
  и данных.
- **Ждать «правильной» важности.** Разные способы дают разный порядок, особенно
  для сильно связанных признаков.

## Перестановочная важность

### Главное

**Перестановочная важность** (permutation importance) измеряет вклад
признака в **качество**. Алгоритм:

1. Посчитать качество обученной модели на наборе объектов (например,
   отложенной выборке).
2. Для одного признака **перемешать** его значения по объектам — ломая связь
   признака с ответом, но сохраняя его распределение.
3. Снова посчитать качество. **Падение качества** — важность признака.
4. Повторить для каждого признака (и несколько раз, усредняя).

В классической версии для случайного леса качество считают на
**out-of-bag** объектах каждого дерева: для дерева перемешивают признак среди
объектов, которых оно не видело, и смотрят, насколько вырастает ошибка. Если
признака в дереве нет, перемешивать нечего, и его важность для этого дерева
равна нулю.

В scikit-learn: `sklearn.inspection.permutation_importance(model, X, y,
n_repeats=…, random_state=…)` — работает с любой моделью и считается на
переданных данных (обычно тестовых). Результат содержит `importances_mean` и
`importances_std`. Если признак шумовой, перемешивание не меняет качества, и
важность около нуля — иногда чуть отрицательная.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(1)
n = 800
X = rng.normal(size=(n, 5))
y = ((2 * X[:, 0] + 0.8 * X[:, 1] + rng.normal(0, 0.8, n)) > 0).astype(int)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17, stratify=y
)

forest = RandomForestClassifier(n_estimators=150, random_state=17).fit(X_train, y_train)
result = permutation_importance(forest, X_test, y_test, n_repeats=10, random_state=17)
for i in np.argsort(-result.importances_mean):
    print(f"признак {i}: падение точности {result.importances_mean[i]:+.3f} "
          f"± {result.importances_std[i]:.3f}")
```

### Частые ошибки

- **Считать перестановочную важность на обучающих данных.** Лес запомнил их, и
  картина искажена; берите отложенную выборку или OOB.
- **Игнорировать разброс.** Повторяйте перемешивание (`n_repeats`) и смотрите
  на `importances_std`.
- **Удивляться, что у двух сильно коррелирующих признаков важность делится.**
  Модель может опираться на любой из них, и перемешивание одного почти не
  вредит.

## Важность по неоднородности

### Главное

Атрибут `feature_importances_` обученного леса в scikit-learn — **важность по
уменьшению неоднородности** (mean decrease in impurity). Для каждого узла
считают, насколько разбиение уменьшило критерий (Джини или энтропию) с
учётом доли объектов в узле; суммируют по узлам, где участвует признак, и
усредняют по деревьям. Затем значения **нормируют: в сумме они дают единицу**
по всем признакам модели.

Метод быстрый — важность известна сразу после обучения, не нужны
дополнительные прогоны. Но у него есть известный недостаток: **завышенная
оценка для признаков с большим числом уровней и уникальных значений**
(числовых, непрерывных, идентификаторов). Такой признак предлагает больше
вариантов порога, и случайно подходящий найдётся чаще — даже в шумовом
признаке. Кроме того, важность считается по обучающей выборке, где лес
переобучен.

Поэтому важность по неоднородности удобна для быстрого обзора, а для
надёжных выводов её сверяют с перестановочной важностью на отложенной
выборке.

### Пример

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(2)
n = 600
useful = rng.integers(0, 2, n)                     # бинарный полезный признак
noise_binary = rng.integers(0, 2, n)               # бинарный шум
noise_continuous = rng.normal(size=n)              # непрерывный шум: много порогов
y = ((useful + rng.normal(0, 0.8, n)) > 0.5).astype(int)
X = np.column_stack([useful, noise_binary, noise_continuous])
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17, stratify=y
)

forest = RandomForestClassifier(n_estimators=150, random_state=17).fit(X_train, y_train)
print("сумма важностей:", round(float(forest.feature_importances_.sum()), 3))
print("по неоднородности:", forest.feature_importances_.round(3))

perm = permutation_importance(forest, X_test, y_test, n_repeats=10, random_state=17)
print("перестановочная:  ", perm.importances_mean.round(3))
```

### Частые ошибки

- **Доверять `feature_importances_` для признаков с разной «ёмкостью».**
  Непрерывные и категориальные признаки с множеством значений получают
  завышенную оценку.
- **Забыть про нормировку.** Значения — доли от суммы, а не абсолютные
  величины.
- **Отбрасывать признаки по порогу важности без проверки.** Убедитесь, что
  качество на отложенной выборке не упало.

## Кейс: отзывы о хостелах

### Главное

В кейсе курса по оценкам хостелов нужно было понять, из чего складывается
общая оценка: сервис, персонал, чистота, расположение, соотношение цены и
качества. Модель — случайный лес для регрессии, по ней считают важность
каждого признака. В материале курса лидерами оказались **персонал** и
**соотношение цены и качества проживания**; остальные признаки заметно
отставали от них или шли вплотную друг к другу — поэтому выводы формулируют
осторожно.

Рабочий порядок такого анализа: обучить лес, оценить его по OOB или на
отложенной выборке (иначе важности не имеют смысла), посчитать оба вида
важности, сравнить порядок и обсудить расхождения. Итог — гипотеза «на
общую оценку больше всего влияют персонал и цена/качество», которую затем
проверяют на новых данных, а не окончательный вывод.

### Пример

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.inspection import permutation_importance
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(3)
n = 700
columns = ["staff", "value", "cleanliness", "location", "facilities"]
X = pd.DataFrame(rng.uniform(1, 10, size=(n, 5)), columns=columns)
overall = (0.40 * X["staff"] + 0.35 * X["value"] + 0.10 * X["cleanliness"]
           + 0.05 * X["location"] + 0.03 * X["facilities"] + rng.normal(0, 0.5, n))
X_train, X_test, y_train, y_test = train_test_split(X, overall, test_size=0.3, random_state=17)

forest = RandomForestRegressor(n_estimators=150, oob_score=True, random_state=17)
forest.fit(X_train, y_train)
print("OOB R²:", round(forest.oob_score_, 3), "тест R²:", round(forest.score(X_test, y_test), 3))

perm = permutation_importance(forest, X_test, y_test, n_repeats=10, random_state=17)
table = pd.DataFrame(
    {"impurity": forest.feature_importances_, "permutation": perm.importances_mean},
    index=columns,
).sort_values("permutation", ascending=False)
print(table.round(3))
```

### Частые ошибки

- **Смотреть важности у плохой модели.** Если OOB и тест низкие, порядок
  признаков ничего не значит.
- **Считать вывод окончательным.** Разница между соседними признаками может
  быть в пределах разброса.
- **Не сверять два способа.** Расхождения указывают на признаки, чью
  важность по неоднородности завысила их «ёмкость».

## Итоги занятия

| Что | Что делает |
|---|---|
| `forest.feature_importances_` | важность по уменьшению неоднородности, сумма равна 1 |
| `permutation_importance(model, X, y, n_repeats)` | падение качества после перемешивания признака |
| перемешивание на OOB | классический вариант для леса, признак вне дерева даёт 0 |
| завышение | важность по неоднородности завышает признаки с большим числом уровней |
| сверка двух способов | расхождения подсказывают, чему не доверять |

Порядок анализа: сначала качество модели (OOB или тест) → важность по
неоднородности для обзора → перестановочная для проверки → осторожный вывод.
