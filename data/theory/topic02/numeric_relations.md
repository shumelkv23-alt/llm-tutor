# Связи количественных признаков

Один признак по отдельности мало что говорит о задаче. Модель строится на
связях: какие признаки меняются вместе, какие дублируют друг друга, какие
хоть как-то связаны с целевым. Это занятие — о трёх инструментах поиска связей
между числовыми признаками: матрице корреляций, диаграмме рассеяния и
`pairplot`, который рисует их все сразу.

## Зачем

После занятия вы сможете:

- посчитать матрицу корреляций, нарисовать её тепловой картой и прочитать;
- объяснить, чего коэффициент Пирсона не видит и почему корреляция — не
  причинность;
- построить диаграмму рассеяния с раскраской по классу и справиться с
  наложением точек;
- выбрать подмножество признаков для `pairplot` и прочитать его панели.

## Корреляции и heatmap

### Главное

**Коэффициент корреляции Пирсона** измеряет, насколько хорошо связь двух
признаков описывается прямой. Он лежит между −1 и 1: близко к 1 — признаки
растут вместе, близко к −1 — один растёт, другой убывает, около 0 — прямой
связи нет.

`df.corr(numeric_only=True)` строит **матрицу** парных корреляций; она
симметрична, а на диагонали стоят единицы. Читать таблицу из десятков чисел
неудобно, поэтому её рисуют **тепловой картой**: `sns.heatmap(corr,
annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1)`. Фиксированные
`vmin` и `vmax` важны: без них цветовая шкала растягивается под данные, и
слабая связь выглядит такой же яркой, как сильная.

Зачем это в ML. Во-первых, признак, сильно связанный с целевым, — кандидат
на хороший предиктор. Во-вторых, пары признаков с корреляцией, близкой к ±1,
дублируют друг друга: в данных оттока минуты разговоров и их стоимость
связаны почти идеально (стоимость — те же минуты, умноженные на тариф), и
один из двух признаков можно убрать.

Ограничения те же, что у прямой. Пирсон не замечает нелинейных связей:
у параболической зависимости корреляция может быть около нуля. И высокая
корреляция не доказывает причинности.

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(6)
n = 500
minutes = rng.normal(180, 50, n)
df = pd.DataFrame(
    {
        "Total day minutes": minutes,
        "Total day charge": minutes * 0.17 + rng.normal(0, 0.05, n),
        "Total eve minutes": rng.normal(200, 50, n),
        "Customer service calls": rng.poisson(1.5, n),
    }
)
corr = df.corr(numeric_only=True)

fig, ax = plt.subplots(figsize=(5, 4))
sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1, ax=ax)
print(corr["Total day charge"].round(2))

# Нелинейная связь: y полностью определяется x, а корреляция около нуля.
x = np.linspace(-3, 3, 200)
print(round(np.corrcoef(x, x**2)[0, 1], 3))
```

### Частые ошибки

- **Выводить причинность из корреляции.** Мороженое и утопления коррелируют
  летом; причина у них общая — жара.
- **Считать корреляцию с кодами категорий.** Номер штата в алфавитном порядке
  ничего не значит, а `corr` этого не заметит.
- **Доверять нулевой корреляции.** «Нет линейной связи» не значит «нет связи».
  Сначала посмотрите на диаграмму рассеяния.

## Диаграмма рассеяния

### Главное

**Диаграмма рассеяния** (scatter plot) рисует каждое наблюдение точкой: по оси
X один признак, по оси Y другой. Она показывает то, что скрыто в
коэффициенте: линейная ли связь, нет ли изгиба, есть ли кластеры, насколько
плотно точки лежат около линии, не тянет ли корреляцию вверх пара выбросов.

Добавьте третье измерение цветом: `sns.scatterplot(data=df, x=…, y=…,
hue="Churn")` — и сразу видно, концентрируются ли ушедшие клиенты в какой-то
области. Это один из самых полезных приёмов первичного анализа.

Когда точек тысячи, они сливаются в пятно (**наложение**). Лекарство —
прозрачность (`alpha=0.3`), меньший размер точки (`s=10`) или выборка из
таблицы.

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(7)
n = 700
churn = rng.random(n) < 0.15
df = pd.DataFrame(
    {
        "Churn": churn,
        "Total day minutes": np.where(churn, rng.normal(215, 45, n), rng.normal(175, 50, n)),
        "Customer service calls": np.where(churn, rng.poisson(3, n), rng.poisson(1.4, n)),
    }
)
df["Total day charge"] = df["Total day minutes"] * 0.17

fig, axes = plt.subplots(1, 2, figsize=(11, 4))
sns.scatterplot(data=df, x="Total day minutes", y="Total day charge", s=12,
                alpha=0.5, ax=axes[0])
axes[0].set_title("Почти прямая: признаки дублируют друг друга")
sns.scatterplot(data=df, x="Total day minutes", y="Customer service calls",
                hue="Churn", s=15, alpha=0.5, ax=axes[1])
axes[1].set_title("Ушедшие — выше и правее")
print(df.groupby("Churn")[["Total day minutes", "Customer service calls"]].mean().round(1))
```

### Частые ошибки

- **Рисовать тысячи непрозрачных точек.** Плотность скрыта; используйте
  `alpha` и малый размер маркера.
- **Не подписать оси и легенду.** `hue="Churn"` без легенды превращает цвета
  в загадку.
- **Читать скопление точек как закон.** Дискретный признак (число звонков)
  рисует «полосы»; это не структура, а следствие целочисленных значений.

## pairplot

### Главное

`sns.pairplot(df, vars=[…], hue="Churn")` строит **матрицу диаграмм**:
для каждой пары выбранных признаков — диаграмму рассеяния, а на диагонали —
распределение каждого признака (гистограмма или KDE, `diag_kind="kde"`). Это
способ быстро «пролистать» все парные связи за один взгляд.

Цена — размер: для k признаков получается k² панелей. Десять признаков дают
сто маленьких графиков, в которых ничего не разобрать. Поэтому в `vars`
передают небольшое подмножество (4–6 признаков), а матрицу корреляций
используют, чтобы выбрать, какие. Параметр `corner=True` убирает дублирующую
половину панелей (верхний треугольник отражает нижний).

С `hue="Churn"` каждая панель раскрашена по классам: если ушедшие клиенты
образуют отдельное облако, признак (или пара) разделяет классы, и модели
будет за что зацепиться.

### Пример

```python
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(8)
n = 400
churn = rng.random(n) < 0.2
df = pd.DataFrame(
    {
        "Churn": churn,
        "Total day minutes": np.where(churn, rng.normal(215, 40, n), rng.normal(175, 45, n)),
        "Total eve minutes": rng.normal(200, 45, n),
        "Customer service calls": np.where(churn, rng.poisson(2.8, n), rng.poisson(1.3, n)),
    }
)

grid = sns.pairplot(
    df,
    vars=["Total day minutes", "Total eve minutes", "Customer service calls"],
    hue="Churn",
    diag_kind="kde",
    corner=True,
    plot_kws={"s": 12, "alpha": 0.5},
)
print(grid.axes.shape)   # сетка 3×3; при corner=True верхний треугольник пуст
```

### Частые ошибки

- **Передать в pairplot все столбцы.** Получится нечитаемая мозаика, а
  построение займёт минуты.
- **Включить в `vars` бинарные и категориальные признаки.** Точки лягут в две
  вертикальные полосы; для таких признаков есть другие графики (следующее
  занятие).
- **Искать в pairplot причины.** Это разведка: она подсказывает, что проверить
  дальше, но не доказывает.

## Итоги занятия

| Что | Что делает |
|---|---|
| `df.corr(numeric_only=True)` | матрица корреляций Пирсона |
| `sns.heatmap(corr, annot=True, vmin=-1, vmax=1, cmap="coolwarm")` | тепловая карта корреляций |
| `sns.scatterplot(data=df, x=…, y=…, hue=…, alpha=…)` | диаграмма рассеяния с раскраской по классу |
| `sns.pairplot(df, vars=[…], hue=…, corner=True)` | матрица парных диаграмм |

Порядок работы: корреляции — чтобы найти интересные пары; рассеяние — чтобы
проверить, что за корреляцией стоит; pairplot — когда пар немного и нужен
общий взгляд.
