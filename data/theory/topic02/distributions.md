# Распределение одного признака

Любой анализ начинается с вопроса «как устроен каждый признак по отдельности?».
Какие значения бывают, где их больше всего, нет ли хвостов и странностей.
Занятие — о четырёх картинках, которые отвечают на этот вопрос: гистограмме,
плотности, ящике с усами (и его брате — скрипке) и столбцах частот.

## Зачем

После занятия вы сможете:

- построить гистограмму и объяснить, как число корзин меняет картину;
- сравнить распределение признака у двух групп (ушли / остались) через плотность;
- прочитать ящик с усами: медиана, квартили, «усы» и выбросы;
- посчитать и нарисовать частоты категориального признака и увидеть дисбаланс
  классов.

## Гистограмма

### Главное

Гистограмма делит ось значений на **корзины** (bins) одинаковой ширины и
показывает, сколько наблюдений попало в каждую. Это основной способ увидеть
**форму** распределения: симметрично ли оно, есть ли длинный хвост, один горб
или несколько, нет ли одинокого столбика-выброса.

Главный параметр — число корзин. Мало корзин сглаживают всё до «холма»; много
— рассыпают картину на шум из отдельных столбиков. Универсального числа нет:
пробуйте несколько значений, 20–50 для сотен наблюдений — разумная точка
старта.

Вертикальная ось по умолчанию — **число** наблюдений. Если сравниваются
выборки разного размера, ось переводят в доли или плотность
(`density=True` в matplotlib, `stat="density"` в seaborn).

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(2)
df = pd.DataFrame({"Total day minutes": rng.normal(180, 55, 600).clip(0).round(1)})

fig, axes = plt.subplots(1, 3, figsize=(13, 3))
axes[0].hist(df["Total day minutes"], bins=4)
axes[0].set_title("bins=4: слишком грубо")
axes[1].hist(df["Total day minutes"], bins=30)
axes[1].set_title("bins=30: форма видна")
sns.histplot(df["Total day minutes"], bins=30, stat="density", ax=axes[2])
axes[2].set_title("seaborn, доли вместо чисел")

counts, edges = np.histogram(df["Total day minutes"], bins=30)
print(counts.sum(), len(df))   # каждое наблюдение попало ровно в одну корзину
```

### Частые ошибки

- **Выбрать число корзин один раз и поверить ему.** Пара картинок с разным
  `bins` — быстрая проверка, что «горб» не артефакт.
- **Сравнивать гистограммы разного размера по высоте столбцов.** Больше
  данных — выше столбцы. Сравнивайте доли.
- **Строить гистограмму категориального признака.** У категорий нет числовой
  шкалы; им нужны столбцы частот (последний раздел занятия).

## Плотность KDE

### Главное

**KDE** (kernel density estimate) — сглаженная гистограмма. Вокруг каждого
наблюдения ставится небольшая «горка» (ядро), горки складываются, и получается
плавная кривая. Площадь под ней равна единице, поэтому высота — не число
наблюдений, а плотность.

Плавность задаёт ширина горок (bandwidth): в seaborn её масштабируют параметром
`bw_adjust` — меньше единицы даёт кривую «нервнее», больше — глаже. Кривая
хороша тем, что **несколько распределений легко нарисовать поверх друг друга**:
гистограммы при наложении заслоняют друг друга, а линии читаются. Именно так
сравнивают ушедших и оставшихся: `hue="Churn"`.

При сравнении групп разного размера добавляйте `common_norm=False`: тогда
каждая группа нормируется отдельно (иначе малочисленная группа выглядит
приплюснутой). У KDE есть и подвох: кривая «вылезает» за границы данных, и
количество звонков может получить плотность при −1. Для таких признаков
ограничивают хвосты: `cut=0`.

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(3)
n = 800
churn = rng.random(n) < 0.15
df = pd.DataFrame(
    {
        "Churn": churn,
        "Total day minutes": np.where(
            churn, rng.normal(207, 60, n), rng.normal(175, 50, n)
        ).clip(0),
    }
)

fig, axes = plt.subplots(1, 2, figsize=(11, 3))
sns.kdeplot(data=df, x="Total day minutes", hue="Churn", common_norm=False,
            cut=0, ax=axes[0])
axes[0].set_title("Каждая группа нормирована отдельно")
sns.histplot(data=df, x="Total day minutes", kde=True, bins=30, ax=axes[1])
axes[1].set_title("Гистограмма + KDE")
print(df.groupby("Churn")["Total day minutes"].mean().round(1))
```

### Частые ошибки

- **Считать KDE «настоящим» распределением.** Это оценка по выборке; на
  десятках наблюдений она рисует горбы, которых нет.
- **Забыть `common_norm=False`.** Если ушедших 15%, общая нормировка делает их
  кривую в разы ниже, и различие в форме теряется.
- **Читать плотность как вероятность.** Высота кривой может быть больше
  единицы; вероятность — это площадь под участком кривой.

## Ящик с усами и скрипка

### Главное

**Ящик с усами** (boxplot) сжимает распределение до пяти чисел. Ящик — от
первого квартиля Q1 до третьего Q3, линия внутри — медиана. «Усы» тянутся до
самых далёких наблюдений, не выходящих за `Q1 − 1,5·IQR` и `Q3 + 1,5·IQR`,
где `IQR = Q3 − Q1`. Всё, что дальше, рисуется точками и называется
**выбросами** по правилу Тьюки.

Ящик занимает мало места, поэтому удобен для сравнения многих групп бок о бок.
Его слабость — он не показывает форму: распределения с двумя горбами и с
одним могут дать одинаковые ящики.

**Скрипка** (violin) — это зеркально отражённый KDE, внутри которого нарисован
маленький ящик. Она сохраняет компактность и добавляет форму: два горба на
скрипке видны сразу.

Важно: «выброс» по правилу Тьюки — не обязательно ошибка. Это просто далёкое
значение; решать, удалять его или оставить, нужно по смыслу данных.

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(4)
df = pd.DataFrame(
    {
        "Customer service calls": rng.poisson(1.6, 500),
        "Churn": rng.random(500) < 0.2,
    }
)
df.loc[df["Churn"], "Customer service calls"] += rng.poisson(1.2, df["Churn"].sum())

fig, axes = plt.subplots(1, 2, figsize=(10, 3))
df.boxplot(column="Customer service calls", by="Churn", ax=axes[0])  # или sns.boxplot
sns.violinplot(data=df, x="Churn", y="Customer service calls", cut=0, ax=axes[1])

calls = df["Customer service calls"]
q1, q3 = calls.quantile([0.25, 0.75])
upper_fence = q3 + 1.5 * (q3 - q1)
print(q1, calls.median(), q3, upper_fence)
print((calls > upper_fence).sum(), "выбросов по правилу Тьюки")
```

### Частые ошибки

- **Считать выбросы ошибками.** Клиент с девятью звонками в поддержку —
  реальный клиент, возможно, самый интересный для задачи оттока.
- **Судить о форме по ящику.** Два горба спрятаны внутри ящика; для формы
  берите гистограмму или скрипку.
- **Забыть про размер групп.** Ящик из пяти наблюдений выглядит так же солидно,
  как ящик из пяти тысяч.

## Частоты категорий и баланс классов

### Главное

Категориальный признак описывают **частотами**: сколько раз встретилось каждое
значение. Считает их `value_counts()` (с `normalize=True` — доли), рисует
`sns.countplot` или `df[col].value_counts().plot(kind="bar")`. Порядок столбцов
лучше задавать осмысленно: по убыванию частоты (так сделает `value_counts`),
а для порядковых признаков — по порядку значений.

Особая категория — **целевой признак**. Если классы представлены неравномерно,
говорят о **дисбалансе классов**. В данных оттока ушло около 15% клиентов, и
модель, которая всегда отвечает «останется», получает accuracy около 85% —
не узнав ничего полезного. Поэтому частоты классов смотрят в самом начале, до
первой модели, а качество оценивают не только долей верных ответов (метрики
для такого случая — в следующих модулях).

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(5)
df = pd.DataFrame(
    {
        "State": rng.choice(["WV", "MN", "NY", "AL", "OH", "WI"], 400),
        "Churn": rng.random(400) < 0.145,
    }
)

shares = df["Churn"].value_counts(normalize=True)
print(shares.round(3))
print("accuracy константы «останется»:", round(shares[False], 3))

fig, axes = plt.subplots(1, 2, figsize=(10, 3))
sns.countplot(data=df, x="Churn", ax=axes[0])
axes[0].set_title("Баланс классов")
df["State"].value_counts().plot(kind="bar", ax=axes[1])
axes[1].set_title("Штаты по убыванию частоты")
```

### Частые ошибки

- **Не смотреть на баланс классов.** Высокая accuracy при дисбалансе может
  ничего не значить.
- **Раскладывать столбцы по алфавиту.** Для сотни штатов порядок по частоте
  читается заметно лучше.
- **Рисовать `pie` с десятком секторов.** Углы сравнивать трудно; столбцы
  точнее.

## Итоги занятия

| Что | Что делает |
|---|---|
| `ax.hist(x, bins=…)`, `sns.histplot(x, stat="density")` | гистограмма, число корзин — главный параметр |
| `sns.kdeplot(data=df, x=…, hue=…, common_norm=False)` | сглаженная плотность, сравнение групп |
| `sns.boxplot`, `sns.violinplot` | ящик с усами и скрипка по группам |
| `Q1 − 1,5·IQR`, `Q3 + 1,5·IQR` | границы усов, за ними — выбросы |
| `value_counts(normalize=True)` | доли категорий и баланс классов |
| `sns.countplot(data=df, x=…)` | столбцы частот |

Порядок работы: форма (гистограмма, KDE) → сводка и выбросы (ящик) → частоты
категорий и целевой признак.
