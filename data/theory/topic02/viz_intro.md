# Зачем графики и чем их строить

Таблица отвечает на вопросы, которые вы догадались задать. График показывает
то, о чём вы не догадывались: выбросы, перекосы, неожиданные связи. Первое
занятие модуля — о том, где графики нужны в машинном обучении, какие бывают
признаки и какими инструментами графики строят.

## Зачем

После занятия вы сможете:

- назвать, на каких этапах работы с моделью нужны графики и зачем;
- отличить количественный признак от категориального и порядкового — от этого
  зависит, какой график строить;
- построить график тремя способами: matplotlib, seaborn и `df.plot`;
- понимать, как устроены фигура (Figure) и оси (Axes) в matplotlib.

## Графики на всех этапах ML

### Главное

Визуализация — не украшение отчёта, а рабочий инструмент на каждом шаге:

1. **Первичный анализ.** Распределения признаков, выбросы, пропуски, баланс
   классов. Ошибку в данных проще увидеть, чем вычислить: столбец, где
   «возраст» доходит до 999, бросается в глаза на гистограмме.
2. **Отбор и построение признаков.** Какие признаки связаны с целевым, какие
   дублируют друг друга (сильная корреляция), какие стоит преобразовать
   (логарифм для длинного хвоста).
3. **Оценка модели.** Кривые обучения, матрица ошибок, важность признаков —
   всё это графики, о них — в следующих модулях.
4. **Объяснение результата.** Заказчику понятнее столбик «доля оттока у
   клиентов с тарифом и без», чем таблица коэффициентов.

Хороший график отвечает на один вопрос. Перед построением сформулируйте его:
«как распределены минуты разговоров?», «отличается ли число звонков в
поддержку у ушедших?». От вопроса зависит и тип графика.

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

rng = np.random.default_rng(0)
df = pd.DataFrame({"Total day minutes": rng.normal(180, 55, 300).round(1)})
df.loc[5, "Total day minutes"] = 999.0   # ошибка ввода

# В describe() выброс прячется в max, на графике — виден сразу.
print(df["Total day minutes"].describe().round(1))
fig, ax = plt.subplots(figsize=(6, 3))
ax.hist(df["Total day minutes"], bins=40)
ax.set_title("Минуты днём: одинокий столбик справа — выброс")
```

### Частые ошибки

- **Строить «всё подряд».** Десятки графиков без вопроса утомляют и ничего не
  показывают. Сначала вопрос, потом график.
- **Верить сводке без графика.** Одинаковые среднее и стандартное отклонение
  бывают у совсем разных распределений.
- **Забыть подписи.** График без названия и подписей осей через неделю
  непонятен и самому автору.

## Типы признаков

### Главное

Тип признака определяет и график, и способ обработки:

- **Количественные** (числовые): минуты разговоров, сумма счёта, возраст.
  Их можно складывать и усреднять. Графики — гистограмма, ящик с усами,
  диаграмма рассеяния.
- **Категориальные** (номинальные): штат, тарифный план, цвет. Значения —
  метки без порядка. Графики — столбцы частот, таблицы сопряжённости.
- **Бинарные** — частный случай категориальных с двумя значениями: `Churn`,
  «есть международный тариф».
- **Порядковые**: значения можно упорядочить, но расстояния между ними не
  определены — «плохо / нормально / хорошо», число звонков в поддержку как
  градация недовольства.

Ловушка — числа, которые на самом деле категории: код региона, номер тарифа.
`Area code` в данных оттока — число, но среднее по нему бессмысленно. Такие
признаки рисуют и считают как категориальные.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "Total day minutes": [265.1, 161.6, 243.4, 299.4, 166.7],
        "Area code": [415, 415, 510, 408, 415],
        "International plan": ["No", "No", "No", "Yes", "Yes"],
        "Customer service calls": [1, 4, 0, 2, 3],
        "Churn": [False, True, False, False, True],
    }
)
print(df.nunique())   # мало уникальных значений — кандидат в категориальные

# Код региона — число, но это категория: считаем частоты, а не среднее.
df["Area code"] = df["Area code"].astype("category")
print(df["Area code"].value_counts())
print(df.select_dtypes("number").columns.tolist())
```

### Частые ошибки

- **Усреднять коды.** «Средний код региона 432,6» ничего не значит.
- **Строить гистограмму по категориям.** Для категорий нужны столбцы частот:
  у гистограммы ось X — числовая шкала, у категорий шкалы нет.
- **Терять порядок у порядковых.** Строки «плохо / нормально / хорошо»
  сортируются по алфавиту; порядок задают категориальным типом с `ordered=True`.

## matplotlib, seaborn и df.plot

### Главное

Три инструмента, которые встретятся в курсе:

- **matplotlib** — базовая библиотека. График состоит из **фигуры** (Figure,
  холст) и **осей** (Axes, область с координатами). `fig, ax =
  plt.subplots()` создаёт их, дальше рисуют методами осей: `ax.hist`,
  `ax.plot`, `ax.scatter`, `ax.bar`; подписи — `ax.set_title`,
  `ax.set_xlabel`. Несколько графиков рядом — `plt.subplots(1, 2)`.
- **pandas `df.plot`** — обёртка над matplotlib: `df["col"].plot(kind="hist")`
  строит график прямо из таблицы и возвращает Axes. Виды: `line`, `bar`,
  `barh`, `hist`, `box`, `scatter`, `pie`.
- **seaborn** — надстройка над matplotlib для статистических графиков:
  `sns.histplot`, `sns.boxplot`, `sns.countplot`, `sns.heatmap`. Принимает
  таблицу и названия столбцов, сам считает частоты и подписывает оси.

Все три рисуют на осях matplotlib, поэтому их можно смешивать: передать в
seaborn параметр `ax=…` и дописать подпись методами matplotlib. В Jupyter
график появляется под ячейкой сам; в скрипте его показывают `plt.show()` или
сохраняют `fig.savefig("plot.png")`.

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(1)
df = pd.DataFrame(
    {
        "Total day minutes": rng.normal(180, 50, 200).round(1),
        "Customer service calls": rng.poisson(1.5, 200),
    }
)

fig, axes = plt.subplots(1, 3, figsize=(12, 3))
axes[0].hist(df["Total day minutes"], bins=20)          # matplotlib
axes[0].set_title("matplotlib: ax.hist")
df["Total day minutes"].plot(kind="box", ax=axes[1])     # pandas
axes[1].set_title("pandas: df.plot")
sns.countplot(x="Customer service calls", data=df, ax=axes[2])  # seaborn
axes[2].set_title("seaborn: countplot")
print(len(fig.axes))
```

### Частые ошибки

- **Рисовать «в pyplot» и «в оси» вперемешку.** `plt.title` подписывает
  текущие оси — при нескольких графиках это не те оси. Работайте через `ax`.
- **Не передать `ax=` в seaborn.** Без него seaborn рисует на текущих осях, и
  графики накладываются друг на друга.
- **Искать график в выводе `print`.** `df.plot` возвращает объект Axes, а не
  картинку; картинка — в окне или файле.

## Итоги занятия

| Что | Что делает |
|---|---|
| `fig, ax = plt.subplots(rows, cols)` | холст и оси |
| `ax.hist`, `ax.bar`, `ax.scatter`, `ax.plot` | базовые графики matplotlib |
| `ax.set_title`, `ax.set_xlabel` | подписи |
| `df["col"].plot(kind=…, ax=…)` | график из таблицы, возвращает Axes |
| `sns.histplot/boxplot/countplot(…, data=df, ax=…)` | статистические графики seaborn |
| `astype("category")` | число-код → категория |

Порядок работы: вопрос → тип признаков → вид графика → инструмент.
