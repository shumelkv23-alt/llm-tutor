# Весь датасет на плоскости и интерактив

Парные графики показывают два-три признака за раз, а в таблице их десятки.
Хочется взглянуть на весь датасет целиком: есть ли в нём кластеры, отделяются
ли ушедшие клиенты от оставшихся. Для этого признаки «сжимают» до двух
координат. А чтобы такую картину можно было рассмотреть, графики делают
интерактивными. Занятие — про снижение размерности (PCA и t-SNE) и библиотеку
plotly.

## Зачем

После занятия вы сможете:

- объяснить, зачем сжимать признаки до двух координат и что при этом теряется;
- подготовить данные (масштабирование) и сжать их через PCA и t-SNE;
- прочитать картину t-SNE и не сделать из неё лишних выводов;
- построить интерактивный график plotly с подсказками при наведении.

## Зачем снижать размерность

### Главное

Нарисовать можно два-три признака; у реальной таблицы их десятки. **Снижение
размерности** переводит каждое наблюдение из пространства многих признаков в
пространство двух-трёх, стараясь сохранить главное: близкие объекты остаются
близкими. На получившейся плоскости видно кластеры, выбросы и то, насколько
классы вообще отделимы друг от друга.

Это инструмент **разведки**, а не доказательства. Сжатие неизбежно теряет
информацию, и по картинке нельзя сказать, что модель справится: объекты,
накладывающиеся на плоскости, в исходном пространстве могут быть далеки.

Два правила подготовки. Во-первых, брать только числовые признаки (категории
сначала кодируют). Во-вторых, **масштабировать**: расстояния чувствительны к
единицам измерения, и признак в сотнях минут задавил бы признак в единицах
звонков. `StandardScaler` приводит каждый признак к среднему 0 и дисперсии 1.

Простейший метод — **PCA** (метод главных компонент): он строит новые оси,
вдоль которых разброс данных максимален, и оставляет первые две. Доля
разброса, объяснённая каждой осью, лежит в `explained_variance_ratio_`.

### Пример

```python
import numpy as np
import pandas as pd
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(12)
n = 300
minutes = rng.normal(180, 50, n)
df = pd.DataFrame(
    {
        "Total day minutes": minutes,
        "Total day charge": minutes * 0.17 + rng.normal(0, 0.5, n),
        "Total eve minutes": rng.normal(200, 50, n),
        "Customer service calls": rng.poisson(1.5, n),
    }
)

X = StandardScaler().fit_transform(df)
pca = PCA(n_components=2, random_state=0)
coords = pca.fit_transform(X)
print(coords.shape)
print(pca.explained_variance_ratio_.round(2))   # какую долю разброса несут две оси
```

### Частые ошибки

- **Не масштабировать.** Без этого одна колонка с большими числами определяет
  всю картинку.
- **Принимать плоскость за истину.** Видно лишь проекцию; мало разброса
  объяснено двумя осями — картинка обманчива.
- **Подавать в метод целевой признак.** `Churn` нужен только для раскраски,
  но не как входной признак: иначе классы «отделятся» сами собой.

## t-SNE

### Главное

**t-SNE** (t-distributed Stochastic Neighbor Embedding) — нелинейный метод,
который особенно хорош в картинках: он старается сохранить **соседства**.
Объекты, близкие в исходном пространстве, остаются близкими на плоскости, а
разные группы расходятся. Поэтому на t-SNE кластеры видны ярче, чем на PCA.

Использование: `TSNE(random_state=17).fit_transform(X)` возвращает массив
n×2. Как читать результат — с осторожностью:

- метод **случайный**: без `random_state` каждый запуск даёт другую картинку;
- **расстояния между кластерами и их размеры ничего не значат** — сохраняются
  только локальные соседства;
- параметр `perplexity` (грубо — число соседей, которых учитывают) меняет
  картину; разумно попробовать несколько значений, 5–50;
- метод медленный: на десятках тысяч объектов работает минутами, поэтому
  берут выборку.

Раскраска по `Churn` показывает, отделяются ли ушедшие клиенты. Если на
t-SNE они перемешаны с остальными, это сигнал: простой границы между
классами в этих признаках может не быть.

### Пример

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import seaborn as sns
from sklearn.manifold import TSNE
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(13)
n = 300
churn = rng.random(n) < 0.25
df = pd.DataFrame(
    {
        "Total day minutes": np.where(churn, rng.normal(230, 30, n), rng.normal(165, 35, n)),
        "Customer service calls": np.where(churn, rng.poisson(3.5, n), rng.poisson(1.2, n)),
        "Total eve minutes": rng.normal(200, 45, n),
        "Total night minutes": rng.normal(200, 45, n),
    }
)

X = StandardScaler().fit_transform(df)
embedding = TSNE(n_components=2, perplexity=30, random_state=17).fit_transform(X)
print(embedding.shape)

fig, ax = plt.subplots(figsize=(5, 4))
sns.scatterplot(x=embedding[:, 0], y=embedding[:, 1], hue=churn, s=15, ax=ax)
ax.set_title("t-SNE: цвет — Churn, но в обучении он не участвовал")
```

### Частые ошибки

- **Мерить расстояния между кластерами.** «Эти две группы далеко» на t-SNE ни
  о чём не говорит; значимо лишь то, что точки внутри группы — соседи.
- **Сделать вывод по одному запуску.** Смените `random_state` и `perplexity`:
  устойчивая структура сохранится, случайная исчезнет.
- **Запускать на всём большом датасете.** Возьмите случайную подвыборку в пару
  тысяч строк.

## Интерактивные графики plotly

### Главное

Обычный график — картинка: подпись к точке не прочитать, область не
приблизить. **plotly** строит интерактивные графики: при наведении всплывает
подсказка, область можно выделить и увеличить, а клик по легенде скрывает
класс. Поэтому он особенно удобен для t-SNE: вы наводите курсор на точку и
видите, что это за клиент.

Основной интерфейс — `plotly.express` (обычно `px`): `px.scatter(df, x=…, y=…,
color="Churn", hover_data=[…])`, а также `px.histogram`, `px.box`, `px.bar`,
`px.line`. Функция возвращает объект **Figure**, который можно донастроить
(`fig.update_layout(title=…)`), показать (`fig.show()` в ноутбуке или
браузере) или сохранить в самостоятельный файл (`fig.write_html("plot.html")`).

Обратите внимание на отличие от matplotlib: данные берутся из столбцов
таблицы по имени, а подсказки собираются из `hover_data` и `hover_name`.

### Пример

```python
import numpy as np
import pandas as pd
import plotly.express as px

rng = np.random.default_rng(14)
n = 200
df = pd.DataFrame(
    {
        "x": rng.normal(size=n),
        "y": rng.normal(size=n),
        "Churn": np.where(rng.random(n) < 0.2, "ушёл", "остался"),
        "Customer service calls": rng.poisson(1.5, n),
        "State": rng.choice(["OH", "NJ", "AL", "MN"], n),
    }
)

fig = px.scatter(
    df,
    x="x",
    y="y",
    color="Churn",
    hover_name="State",
    hover_data=["Customer service calls"],
    title="Интерактивная диаграмма",
)
fig.update_layout(width=520, height=400)
# В ноутбуке график покажет fig.show(); в файл — fig.write_html("plot.html").
print(type(fig).__name__, len(fig.data), "серии (по одной на значение color)")
```

### Частые ошибки

- **Ждать картинку от `print(fig)`.** Это текстовое описание объекта; график
  показывают через `fig.show()` или сохраняют в HTML.
- **Подавать числовой код как `color`.** Число с небольшим числом значений
  plotly покрасит градиентом; для категорий приведите столбец к строке.
- **Строить интерактивные графики на огромных таблицах.** Сотни тысяч точек
  делают страницу медленной; рисуйте выборку.

## Итоги занятия

| Что | Что делает |
|---|---|
| `StandardScaler().fit_transform(X)` | приводит признаки к одному масштабу |
| `PCA(n_components=2)` | линейное сжатие, `explained_variance_ratio_` — доля разброса |
| `TSNE(random_state=…, perplexity=…)` | нелинейное сжатие, сохраняет соседства |
| `px.scatter(df, x, y, color, hover_data)` | интерактивная диаграмма |
| `fig.update_layout`, `fig.write_html` | настройка и сохранение |

Порядок работы: числовые признаки → масштаб → PCA или t-SNE → раскраска по
классу → интерактив для знакомства с отдельными точками.
