# Метод ближайших соседей

Второй метод модуля устроен совсем иначе, чем дерево. Он не выучивает
правила, а просто хранит обучающие данные и отвечает «как соседи»: чтобы
предсказать класс нового клиента, находит самых похожих на него и смотрит,
что у них. Занятие — про идею, главные параметры и пределы метода.

## Зачем

После занятия вы сможете:

- объяснить, как kNN классифицирует объект и почему его называют «ленивым»;
- настроить `n_neighbors`, `weights` и метрику в `KNeighborsClassifier`;
- объяснить, зачем kNN нужно масштабирование признаков, и собрать `Pipeline`;
- назвать достоинства и ограничения метода, включая проклятие размерности.

## Идея kNN

### Главное

**Метод k ближайших соседей** (k Nearest Neighbors) работает по принципу
«скажи мне, кто твои соседи, и я скажу, кто ты»:

1. Посчитать расстояние от нового объекта до каждого объекта обучающей
   выборки.
2. Выбрать `k` ближайших.
3. В классификации — вернуть **самый частый класс** среди соседей (голосование);
   в регрессии — **среднее или медиану** их целевой переменной.

Метод называют **ленивым**: на стадии `fit` модель по сути ничего не строит,
а только запоминает данные. Вся работа происходит при `predict`: поиск
соседей. Поэтому обучение мгновенное, а прогноз на больших данных может быть
медленным.

Расстояние по умолчанию — евклидово: корень из суммы квадратов разностей
по всем признакам. Главное допущение метода: **близкие объекты имеют
похожие ответы**. Если это не так, kNN бесполезен.

### Пример

```python
import numpy as np
from sklearn.neighbors import KNeighborsClassifier

rng = np.random.default_rng(9)
X = np.vstack([rng.normal([0, 0], 1.0, (50, 2)), rng.normal([3, 3], 1.0, (50, 2))])
y = np.array([0] * 50 + [1] * 50)

knn = KNeighborsClassifier(n_neighbors=5).fit(X, y)
new = np.array([[2.5, 2.8]])
distances, indices = knn.kneighbors(new)
print("индексы соседей:", indices[0])
print("классы соседей:", y[indices[0]])
print("прогноз:", knn.predict(new))
```

### Частые ошибки

- **Ждать от kNN «выученной» модели.** Он хранит все данные и пересчитывает
  расстояния заново при каждом прогнозе.
- **Забыть про регрессию.** kNN работает и для чисел: усредняет значения
  соседей (`KNeighborsRegressor`).
- **Считать расстояния по признакам разной природы без раздумий.** Расстояние
  складывает все признаки, и если они несопоставимы, результат бессмыслен
  (об этом — следующий раздел).

## Параметры и масштабирование

### Главное

Главные параметры `KNeighborsClassifier`:

- `n_neighbors` — число соседей `k`. При `k = 1` метод чувствителен к
  выбросам и шуму (переобучение), при слишком большом `k` граница сглаживается
  до недообучения. Подбирают на проверочной выборке;
- `weights` — `"uniform"` (все соседи равны) или `"distance"` (вес соседа
  обратно пропорционален расстоянию до него);
- `metric` / `p` — способ измерять расстояние: евклидово, манхэттенское и т. д.

Главная подготовка данных — **масштабирование**. Расстояние суммирует вклады
признаков, и признак с большими числами (минуты разговора в сотнях)
перевешивает признак с малыми (число звонков в единицах). `StandardScaler`
приводит признаки к одному масштабу. Чтобы масштабирование не «подглядывало»
в тестовые данные, его включают в `Pipeline`: тогда на каждой проверке
параметры масштаба считаются только по обучающей части.

### Пример

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(10)
n = 400
minutes = rng.normal(180, 50, n)           # сотни
calls = rng.integers(0, 8, n).astype(float)  # единицы
y = (calls + rng.normal(0, 1.0, n) > 4).astype(int)   # ответ зависит от звонков
X = np.column_stack([minutes, calls])
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17, stratify=y
)

raw = KNeighborsClassifier(n_neighbors=5).fit(X_train, y_train)
scaled = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=5))
scaled.fit(X_train, y_train)
print("без масштаба:", round(raw.score(X_test, y_test), 3))
print("с масштабом:", round(scaled.score(X_test, y_test), 3))

for k in (1, 5, 25):
    model = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=k, weights="distance"))
    print(k, round(model.fit(X_train, y_train).score(X_test, y_test), 3))
```

### Частые ошибки

- **Не масштабировать признаки перед kNN.** Тогда «ближайшие» определяются
  одним признаком с большим разбросом.
- **Масштабировать всю таблицу до разбиения.** Тестовые данные попадают в
  расчёт среднего и разброса: оценка завышается. Используйте `Pipeline`.
- **Выбирать `k` по обучающей выборке.** При `k = 1` точность на ней 100%
  (объект — сам себе ближайший сосед), но это не качество.

## Плюсы и минусы kNN

### Главное

**Достоинства.** Метод прост, не требует обучения и даёт сильный базовый
результат, особенно когда расстояние осмысленно: распознавание цифр,
рекомендации по похожим пользователям. Он естественно многоклассовый и
гибко описывает сложную границу.

**Недостатки.**

- **Медленный прогноз** на больших данных: нужно искать соседей среди всех
  объектов (спасают специальные индексы, но не бесконечно).
- **Память:** хранятся все обучающие данные.
- **Проклятие размерности.** Когда признаков очень много, расстояния между
  объектами выравниваются: «близкие» и «далёкие» становятся неразличимы, и
  метод теряет смысл.
- **Чувствительность к масштабу и к шумовым признакам:** все признаки
  вносят вклад в расстояние одинаково, и лишние портят результат.
- **Чувствительность к выбросам** при малом `k`.

Поэтому kNN хорош на небольших и средних данных с небольшим числом
осмысленных числовых признаков. Для больших таблиц чаще берут деревья и их
ансамбли.

### Пример

```python
import numpy as np

rng = np.random.default_rng(11)

# Проклятие размерности: отношение дальнего расстояния к ближнему стремится к 1.
for dim in (2, 20, 500):
    points = rng.uniform(size=(300, dim))
    distances = np.linalg.norm(points[1:] - points[0], axis=1)
    print(dim, "признаков: дальний/ближний =", round(distances.max() / distances.min(), 2))
```

### Частые ошибки

- **Добавлять в kNN все признаки подряд.** Шумовой признак вносит в расстояние
  такой же вклад, как полезный.
- **Применять kNN к огромным таблицам без индекса.** Прогноз одного объекта
  требует прохода по всем обучающим.
- **Путать малое `k` с «точностью».** `k = 1` повторяет шум в данных.

## Итоги занятия

| Что | Что делает |
|---|---|
| `KNeighborsClassifier(n_neighbors=k)` | классификация по `k` ближайшим соседям |
| `KNeighborsRegressor` | регрессия: среднее по соседям |
| `weights="distance"` | вес соседа обратно пропорционален расстоянию |
| `knn.kneighbors(X)` | расстояния и индексы соседей |
| `make_pipeline(StandardScaler(), KNeighborsClassifier())` | масштаб внутри модели, без утечки |

kNN: прост, без обучения, но требует масштабирования, медленно предсказывает
и страдает от большого числа признаков.
