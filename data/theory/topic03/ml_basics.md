# Задачи ML и обучение с учителем

Модуль начинается с общей картины: что вообще называют задачей машинного
обучения, чем обучение с учителем отличается от обучения без него и как
понять, хорошо ли модель отвечает. Дальше в модуле — деревья решений и
метод ближайших соседей, и всё это опирается на понятия из этого занятия.

## Зачем

После занятия вы сможете:

- по описанию задачи определить её тип: классификация, регрессия или
  кластеризация;
- объяснить, что такое признаки, целевая переменная и обучающая выборка;
- разделить данные на обучающую и тестовую части и обучить модель в scikit-learn;
- посчитать долю правильных ответов и понять, когда ей нельзя доверять.

## Типы задач ML

### Главное

Классическое определение Тома Митчелла: программа **учится** на опыте *E*
решать задачи *T*, если мера её качества *P* на задачах *T* растёт с опытом
*E*. Для задачи оттока: опыт *E* — таблица клиентов с известным исходом,
задача *T* — предсказать, уйдёт ли новый клиент, мера *P* — доля верных
ответов.

Задачи различают по тому, что именно нужно получить:

- **Классификация** — ответ из конечного набора меток: «уйдёт / останется»,
  «спам / не спам», цифра от 0 до 9.
- **Регрессия** — ответ-число: на сколько дней клиент просрочит платёж, какая
  будет выручка.
- **Кластеризация** — разбить объекты на группы похожих, когда готовых меток
  нет. Это пример задачи без учителя.
- **Снижение размерности** — представить данные меньшим числом признаков
  (с ним вы познакомились в модуле о визуализации).

Чтобы определить тип задачи, спросите: «Что у меня есть в качестве ответа?»
Если ответ — метка, это классификация; число — регрессия; ответа нет —
скорее всего, кластеризация.

### Пример

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor

rng = np.random.default_rng(0)
X = rng.normal(size=(60, 2))                 # признаки: 60 клиентов, 2 числа
churn = (X[:, 0] + X[:, 1] > 0).astype(int)  # метка: ушёл (1) или остался (0)
delay_days = 5 * X[:, 0] + 10                # число: дни просрочки

classifier = DecisionTreeClassifier(max_depth=2, random_state=0).fit(X, churn)
regressor = DecisionTreeRegressor(max_depth=2, random_state=0).fit(X, delay_days)
clusters = KMeans(n_clusters=2, n_init=10, random_state=0).fit_predict(X)  # без ответов

print(classifier.predict(X[:3]))            # метки классов
print(regressor.predict(X[:3]).round(1))    # числа
print(clusters[:3])                         # номера групп, смысла у номеров нет
```

### Частые ошибки

- **Называть регрессией любую задачу с числами.** Если число — это номер
  класса («цифра 7»), задача остаётся классификацией.
- **Путать кластеризацию и классификацию.** Номера кластеров придумывает
  алгоритм, у них нет названия, пока человек не посмотрит на группы.
- **Начинать с модели, не сформулировав задачу.** Сначала — что предсказываем
  и по каким данным, потом выбор метода.

## Обучение с учителем

### Главное

При **обучении с учителем** в обучающей выборке известна **целевая
переменная** *y* — «правильный ответ» для каждого объекта. Описание объекта
— вектор **признаков**; таблица признаков обозначается *X* (строки —
объекты, столбцы — признаки), а столбец ответов — *y*.

Модель можно понимать как функцию, которая по признакам объекта выдаёт
ответ. Обучение — подбор её внутренних параметров так, чтобы ответы на
обучающих объектах были близки к известным. Интерфейс scikit-learn един для
всех моделей:

- `model.fit(X, y)` — обучить;
- `model.predict(X_new)` — получить ответы для новых объектов.

Главный вопрос — как модель поведёт себя на объектах, которых она не видела.
Поэтому данные делят на **обучающую** и **тестовую** части:
`train_test_split(X, y, test_size=0.3, random_state=17)`. Обучаются на первой,
качество измеряют на второй. Для классов полезно `stratify=y`: доли классов в
обеих частях получаются одинаковыми.

### Пример

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(1)
X = rng.normal(size=(200, 3))
y = (X[:, 0] - 0.5 * X[:, 1] + rng.normal(0, 0.5, 200) > 0).astype(int)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17, stratify=y
)
print(X_train.shape, X_test.shape)

model = DecisionTreeClassifier(max_depth=3, random_state=17)
model.fit(X_train, y_train)          # учимся только на обучающей части
print(model.predict(X_test[:5]), y_test[:5])
```

### Частые ошибки

- **Обучаться на всех данных, а проверять на них же.** Такая оценка
  оптимистична: модель могла просто запомнить ответы.
- **Подмешать целевую переменную в признаки.** Тогда качество станет
  фантастическим, а на новых данных, где ответа нет, модель окажется
  бесполезной.
- **Не фиксировать `random_state`.** Без него разбиение каждый раз другое, и
  результаты не воспроизвести.

## Доля правильных ответов

### Главное

Простейшая метрика классификации — **accuracy**, доля правильных ответов:
число совпадений прогноза с истиной, делённое на число объектов. Если из 100
объектов модель угадала 90, accuracy равна 0,9. В scikit-learn:
`accuracy_score(y_true, y_pred)` или метод `model.score(X, y)`.

Считать accuracy нужно на отложенной (тестовой) выборке, не на обучающей.
И сравнивать её нужно не с единицей, а с **простейшей стратегией** —
например, «всегда предсказывать самый частый класс». Если ушедших 15%, то
такая тривиальная модель получит 85%, и результат в 87% — почти ничего не
значит.

Поэтому дисбаланс классов смотрят первым делом, а при сильном дисбалансе
используют и другие метрики (точность, полноту, площадь под ROC-кривой), о
которых речь пойдёт позже.

### Пример

```python
import numpy as np
from sklearn.dummy import DummyClassifier
from sklearn.metrics import accuracy_score
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(2)
X = rng.normal(size=(500, 4))
y = (X[:, 0] + rng.normal(0, 0.8, 500) > 1.3).astype(int)   # редкий класс
print("доля класса 1:", y.mean().round(2))

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17, stratify=y
)
baseline = DummyClassifier(strategy="most_frequent").fit(X_train, y_train)
tree = DecisionTreeClassifier(max_depth=3, random_state=17).fit(X_train, y_train)

print("всегда «0»:", round(accuracy_score(y_test, baseline.predict(X_test)), 3))
print("дерево:", round(accuracy_score(y_test, tree.predict(X_test)), 3))
print("дерево на обучении:", round(tree.score(X_train, y_train), 3))
```

### Частые ошибки

- **Радоваться 90% без базового уровня.** Сначала посчитайте, чего достигает
  «всегда самый частый класс».
- **Оценивать качество на обучающей части.** Она всегда выглядит лучше, чем
  реальность.
- **Сравнивать accuracy на разных тестовых выборках.** Для честного сравнения
  моделей данные для проверки должны быть одинаковыми.

## Итоги занятия

| Что | Что делает |
|---|---|
| классификация, регрессия, кластеризация | три типа задач: метка, число, группы без ответа |
| `X`, `y` | признаки (таблица) и целевая переменная |
| `train_test_split(X, y, test_size, random_state, stratify)` | разбиение на обучающую и тестовую части |
| `model.fit(X_train, y_train)`, `model.predict(X_test)` | обучение и прогноз |
| `accuracy_score(y_true, y_pred)`, `model.score(X, y)` | доля правильных ответов |
| `DummyClassifier(strategy="most_frequent")` | базовый уровень для сравнения |

Порядок работы: тип задачи → разбиение → обучение → оценка на тесте →
сравнение с базовым уровнем.
