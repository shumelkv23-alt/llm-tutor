# Мультиколлинеарность и гребневая регрессия

Если два признака почти повторяют друг друга, МНК теряет устойчивость: веса
становятся огромными и сильно меняются от выборки к выборке. Лекарство —
регуляризация: чуть-чуть «сдавить» веса, пожертвовав точностью на обучающих
данных ради устойчивости. Занятие — про проблему и самое простое решение,
гребневую регрессию.

## Зачем

После занятия вы сможете:

- объяснить, что такое мультиколлинеарность и чем она мешает МНК;
- записать функцию потерь гребневой регрессии и понять роль параметра `λ`;
- обучить `Ridge`, подобрать `alpha` и объяснить, почему признаки надо
  масштабировать;
- сказать, как рост регуляризации меняет смещение и разброс.

## Мультиколлинеарность

### Главное

**Мультиколлинеарность** — сильная корреляция между признаками модели:
один признак почти выражается через другие. В данных оттока так связаны
минуты разговора и стоимость, если стоимость — те же минуты, умноженные на
тариф.

Для МНК это проблема. Матрица `XᵀX` становится почти вырожденной, и решение
нормального уравнения **неустойчиво**: небольшое изменение данных сильно
меняет веса. Веса при коррелирующих признаках могут получиться большими по
модулю и противоположными по знаку, компенсируя друг друга; прогнозы при этом
остаются разумными, но интерпретировать веса нельзя.

Обнаружить мультиколлинеарность помогают матрица корреляций и число
обусловленности `XᵀX`. Способы справиться:

- убрать один из дублирующих признаков (самый простой путь, если важна
  интерпретация);
- объединить признаки в один — сумму, среднее, разность;
- сжать пространство признаков (например, методом главных компонент);
- применить регуляризацию — она делает задачу корректной, не требуя
  вмешательства в данные.

Какой путь выбрать, зависит от цели: если нужны понятные коэффициенты —
чистят признаки, если важен прогноз — часто хватает регуляризации.

### Пример

```python
import numpy as np
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(6)
n = 100
x1 = rng.normal(size=n)
x2 = x1 + rng.normal(0, 0.02, n)         # почти копия x1
y = 3 * x1 + rng.normal(0, 0.5, n)
X = np.column_stack([x1, x2])
print("корреляция признаков:", round(float(np.corrcoef(x1, x2)[0, 1]), 4))
print("число обусловленности:", f"{np.linalg.cond(X.T @ X):.0f}")

for seed in range(3):
    idx = np.random.default_rng(seed).choice(n, size=n, replace=True)   # бутстрэп-выборка
    w = LinearRegression().fit(X[idx], y[idx]).coef_
    print("веса на выборке", seed, w.round(2), "сумма", round(float(w.sum()), 2))
```

### Частые ошибки

- **Интерпретировать веса при коррелирующих признаках.** Вклад «делится»
  между копиями непредсказуемо; смотреть нужно на сумму.
- **Считать, что мультиколлинеарность портит прогнозы.** Чаще она портит
  устойчивость и интерпретацию весов.
- **Проверять только парные корреляции.** Признак может быть комбинацией
  нескольких других, хотя с каждым по отдельности корреляция умеренная.

## L2-регуляризация

### Главное

**Гребневая регрессия** (Ridge) добавляет к MSE штраф за большие веса:

`J(w) = Σ (yᵢ − ŷᵢ)² + λ · Σ wⱼ²`.

Слагаемое с `λ` — квадрат **L2-нормы** вектора весов (свободный член
обычно не штрафуется). Параметр `λ ≥ 0` управляет силой штрафа: при `λ = 0`
получается обычный МНК, при росте `λ` веса прижимаются к нулю. Решение
по-прежнему записывается формулой, но теперь обращается матрица
`XᵀX + λ·I`, которая невырождена, — поэтому метод устойчив даже при
коррелирующих признаках.

Цена регуляризации — **смещение**: оценки весов сдвинуты к нулю, на обучающей
выборке ошибка чуть выше. Выигрыш — меньший **разброс**. Подбирают `λ`
перебором на кросс-валидации. В scikit-learn параметр называется `alpha`
(`Ridge(alpha=…)`), а `RidgeCV` перебирает значения сам.

Важно: штраф одинаково действует на все веса, поэтому перед `Ridge`
признаки **масштабируют** (`StandardScaler`). Иначе признак с большими
числами окажется в привилегированном положении.

### Пример

```python
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge

rng = np.random.default_rng(7)
n = 100
x1 = rng.normal(size=n)
x2 = x1 + rng.normal(0, 0.02, n)
y = 3 * x1 + rng.normal(0, 0.5, n)
X = np.column_stack([x1, x2])

spread = {"МНК": [], "Ridge": []}
for seed in range(200):
    idx = np.random.default_rng(seed).choice(n, size=n, replace=True)
    spread["МНК"].append(LinearRegression().fit(X[idx], y[idx]).coef_)
    spread["Ridge"].append(Ridge(alpha=1.0).fit(X[idx], y[idx]).coef_)

for name, weights in spread.items():
    weights = np.array(weights)
    print(name, "средний вес", weights.mean(axis=0).round(2),
          "разброс весов", weights.std(axis=0).round(2))

for alpha in (0.01, 1, 100):
    print(alpha, "сумма весов:", round(float(Ridge(alpha=alpha).fit(X, y).coef_.sum()), 3))
```

Формулу решения можно проверить напрямую: при `fit_intercept=False`
`Ridge` возвращает ровно `(XᵀX + λ·I)⁻¹ · Xᵀy`.

```python
import numpy as np
from sklearn.linear_model import Ridge

rng = np.random.default_rng(8)
X = rng.normal(size=(60, 3))
y = X @ np.array([1.0, -2.0, 0.5]) + rng.normal(0, 0.3, 60)
lam = 5.0

w_formula = np.linalg.solve(X.T @ X + lam * np.eye(3), X.T @ y)
w_ridge = Ridge(alpha=lam, fit_intercept=False).fit(X, y).coef_
print(np.allclose(w_formula, w_ridge))        # True
print(np.linalg.norm(w_ridge) < np.linalg.norm(np.linalg.solve(X.T @ X, X.T @ y)))
```

Родственный метод — **Lasso** с L1-штрафом `λ·Σ|wⱼ|`: он обнуляет часть весов
и тем самым отбирает признаки. Гребень только сжимает веса, но не обнуляет
их.

### Частые ошибки

- **Не масштабировать признаки перед Ridge.** Штраф становится несправедливым.
- **Штрафовать свободный член.** В scikit-learn он не штрафуется; при ручной
  реализации не включайте столбец единиц в штраф.
- **Выбирать `alpha` по обучающей выборке.** Там лучше всего `alpha = 0`;
  значение нужно подбирать на кросс-валидации.

## Итоги занятия

| Что | Что делает |
|---|---|
| мультиколлинеарность | сильная связь между признаками, неустойчивые веса |
| `np.linalg.cond(X.T @ X)` | число обусловленности: огромное — признак беды |
| `J(w) = SSE + λ·Σwⱼ²` | функция потерь гребневой регрессии |
| `Ridge(alpha=λ)`, `RidgeCV` | гребневая регрессия и перебор `alpha` |
| `StandardScaler` | обязателен перед регуляризацией |

Рост `λ`: веса уменьшаются, смещение растёт, разброс падает. Подбор — на
кросс-валидации.
