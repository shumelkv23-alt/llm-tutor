# Линейная регрессия и МНК

Линейная регрессия — самая простая модель для предсказания числа и основа
для многих более сложных методов. Занятие показывает, как она устроена, чем
измеряется ошибка и как веса находятся одной формулой — нормальным
уравнением.

## Зачем

После занятия вы сможете:

- записать модель линейной регрессии в матричном виде и объяснить роль столбца
  из единиц;
- объяснить, что минимизирует метод наименьших квадратов (МНК) и чему равна MSE;
- найти веса по нормальному уравнению в `numpy` и сверить результат с
  `LinearRegression`;
- понять, когда нормальное уравнение не имеет решения.

## Модель линейной регрессии

### Главное

Линейная регрессия предсказывает число как **линейную комбинацию признаков**:

`ŷ = w₀ + w₁·x₁ + w₂·x₂ + … + w_d·x_d`.

Числа `w₁…w_d` — **веса** (коэффициенты) при признаках, `w₀` — свободный
член (сдвиг). Модель настраивают подбором весов так, чтобы прогнозы на
обучающих объектах были близки к известным ответам.

Для всей выборки удобна матричная запись `ŷ = X·w`. Чтобы свободный член не
выделять отдельно, к матрице признаков `X` добавляют **столбец из единиц**:
тогда `w₀` умножается на единицу и входит в общее матричное произведение.
Размеры: `X` — `n × (d + 1)`, `w` — вектор длины `d + 1`, `ŷ` — вектор длины
`n`.

В scikit-learn столбец единиц добавлять не нужно: `LinearRegression` хранит
свободный член отдельно (`intercept_`), а веса признаков — в `coef_`.

### Пример

```python
import numpy as np
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(0)
n = 100
minutes = rng.normal(180, 50, n)
calls = rng.poisson(1.5, n).astype(float)
bill = 5 + 0.04 * minutes + 1.2 * calls + rng.normal(0, 1.0, n)   # «истинная» связь

X = np.column_stack([minutes, calls])
model = LinearRegression().fit(X, bill)
print("свободный член:", round(model.intercept_, 2))
print("веса:", model.coef_.round(3))      # близки к 0.04 и 1.2

X1 = np.column_stack([np.ones(n), X])      # столбец из единиц
w = np.array([model.intercept_, *model.coef_])
print(np.allclose(X1 @ w, model.predict(X)))   # матричная запись даёт те же прогнозы
```

### Частые ошибки

- **Путать признаки и веса.** Признаки — данные (`X`), веса — то, что модель
  подбирает (`w`).
- **Добавить столбец единиц и оставить `fit_intercept=True`.** Свободный член
  тогда задваивается; в scikit-learn единицы добавлять не надо.
- **Считать вес мерой важности признака.** Вес зависит от масштаба признака:
  минуты и звонки несравнимы без стандартизации.

## МНК и MSE

### Главное

Как понять, что веса хороши? Для каждого объекта считают **ошибку**
(остаток) `yᵢ − ŷᵢ`. Складывать ошибки напрямую нельзя — положительные и
отрицательные сократятся, поэтому их возводят в квадрат. **Среднеквадратичная
ошибка** (MSE):

`MSE = (1/n) · Σ (yᵢ − ŷᵢ)²`.

**Метод наименьших квадратов** (МНК, OLS) выбирает веса, при которых эта
сумма квадратов минимальна. Квадрат сильно штрафует большие ошибки: промах на
10 «стоит» в сто раз больше, чем промах на 1. Отсюда же чувствительность
метода к выбросам.

В scikit-learn MSE считает `mean_squared_error(y_true, y_pred)`. Иногда
берут корень из неё (RMSE): он измеряется в тех же единицах, что и ответ.

### Пример

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

rng = np.random.default_rng(1)
x = rng.uniform(0, 10, 60)
y = 3 + 2 * x + rng.normal(0, 1.5, 60)
X = x.reshape(-1, 1)

model = LinearRegression().fit(X, y)
pred = model.predict(X)
print("MSE:", round(mean_squared_error(y, pred), 3))
print("то же вручную:", round(float(np.mean((y - pred) ** 2)), 3))

# Любые другие веса дают MSE не меньше.
other = 3.5 + 1.8 * x
print("другие веса:", round(float(np.mean((y - other) ** 2)), 3))

# Один выброс резко увеличивает MSE.
y_out = y.copy()
y_out[0] += 30
print("с выбросом:", round(float(np.mean((y_out - pred) ** 2)), 3))
```

### Частые ошибки

- **Минимизировать сумму ошибок без квадрата.** Положительные и отрицательные
  отклонения сократятся, и «хорошие» веса найти не получится.
- **Забывать о выбросах.** Квадрат делает одно большое отклонение главным
  вкладом в MSE.
- **Сравнивать MSE на разных шкалах ответа.** Для таких сравнений берут
  относительные метрики или RMSE в понятных единицах.

## Нормальное уравнение

### Главное

Минимум MSE у линейной модели находится **аналитически**. Приравняв
производную по весам к нулю, получают **нормальное уравнение**:

`Xᵀ·X · w = Xᵀ·y`, откуда `w = (Xᵀ·X)⁻¹ · Xᵀ·y`.

Это формула весов через матрицы: обратная к `XᵀX` матрица, умноженная на `Xᵀy`.
Подбирать веса итерациями не нужно — достаточно решить систему.

Условие: матрица `XᵀX` должна быть **обратимой**. Если один признак является
линейной комбинацией других (например, дублирует другой), `XᵀX`
вырождена, обратной матрицы нет, и решения у нормального уравнения не
существует, а точнее — их бесконечно много. Практически близкая к вырожденной
матрица тоже плоха: решение неустойчиво (этому посвящено одно из следующих
занятий). Вместо явной обратной матрицы пользуются `np.linalg.solve` или
`np.linalg.lstsq`, которые работают устойчивее.

### Пример

```python
import numpy as np
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(2)
n = 80
X = rng.normal(size=(n, 2))
y = 1.0 + 2.0 * X[:, 0] - 3.0 * X[:, 1] + rng.normal(0, 0.3, n)

X1 = np.column_stack([np.ones(n), X])
w = np.linalg.solve(X1.T @ X1, X1.T @ y)        # нормальное уравнение
print("нормальное уравнение:", w.round(3))

model = LinearRegression().fit(X, y)
print("LinearRegression:", np.r_[model.intercept_, model.coef_].round(3))

# Дублирующий признак делает матрицу вырожденной.
X_dup = np.column_stack([np.ones(n), X[:, 0], 2 * X[:, 0]])
print("ранг:", np.linalg.matrix_rank(X_dup.T @ X_dup), "из", X_dup.shape[1])
```

### Частые ошибки

- **Считать обратную матрицу через `np.linalg.inv`.** Результат менее
  устойчив, чем у `solve` и `lstsq`.
- **Не проверять вырожденность.** Ранг `XᵀX` меньше числа столбцов — признак
  дублирования информации.
- **Применять нормальное уравнение к огромным данным.** Обращение матрицы
  растёт как куб числа признаков; для больших задач используют итерационные
  методы.

## Итоги занятия

| Что | Что делает |
|---|---|
| `ŷ = X·w` | модель; в `X` добавлен столбец из единиц |
| `LinearRegression().fit(X, y)` | обучает; `coef_` — веса, `intercept_` — свободный член |
| `MSE = (1/n)·Σ(yᵢ − ŷᵢ)²` | функция потерь МНК |
| `mean_squared_error(y, pred)` | MSE в scikit-learn |
| `w = (XᵀX)⁻¹Xᵀy` | нормальное уравнение |
| `np.linalg.solve(A, b)`, `lstsq` | устойчивое решение вместо явной обратной |

Порядок работы: записать модель → выбрать функцию потерь → найти веса →
проверить обратимость `XᵀX`.
