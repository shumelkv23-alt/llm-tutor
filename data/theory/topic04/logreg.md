# Логистическая регрессия

Несмотря на название, логистическая регрессия решает задачу классификации.
Она строит линейную границу между классами и умеет выдавать вероятность —
а не только метку «уйдёт / не уйдёт». Занятие объясняет, как линейный
классификатор превращается в вероятностный и какую функцию потерь он
минимизирует.

## Зачем

После занятия вы сможете:

- объяснить, как линейный классификатор разделяет классы гиперплоскостью;
- связать вероятность, шансы (odds) и логит, и записать сигмоиду;
- вычислить отступ объекта и логистическую потерю;
- получить вероятности из `LogisticRegression` и проверить их вручную.

## Линейный классификатор

### Главное

Пусть метки классов — `−1` и `+1`. **Линейный классификатор** вычисляет
взвешенную сумму признаков и смотрит на её знак:

`a(x) = sign(w₁x₁ + … + w_d·x_d + b)`.

Уравнение `w·x + b = 0` задаёт **гиперплоскость** — границу между классами: в
двух измерениях это прямая, в трёх — плоскость. Вектор весов `w`
перпендикулярен границе и показывает, куда растёт «принадлежность» к классу
`+1`. Чем дальше от границы точка, тем увереннее ответ.

Выборка **линейно разделима**, если существует гиперплоскость, делящая классы
без ошибок. На реальных данных это бывает редко, поэтому цель — найти
гиперплоскость, которая ошибается как можно реже. Но число ошибок — функция
негладкая (ответы меняются скачками), и напрямую её не минимизируют. На
помощь приходят гладкие функции потерь, о которых — ниже.

### Пример

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

rng = np.random.default_rng(9)
X = np.vstack([rng.normal([-1.5, -1.5], 1.0, (60, 2)), rng.normal([1.5, 1.5], 1.0, (60, 2))])
y = np.array([0] * 60 + [1] * 60)

model = LogisticRegression().fit(X, y)
w, b = model.coef_[0], model.intercept_[0]
print("веса:", w.round(2), "сдвиг:", round(float(b), 2))

score = X @ w + b                          # знак определяет сторону границы
print("совпадает с predict:", bool(((score > 0).astype(int) == model.predict(X)).all()))
print("точность:", round(model.score(X, y), 3))
```

### Частые ошибки

- **Ждать, что классы всегда разделимы.** Реальные данные пересекаются;
  модель ищет гиперплоскость с наименьшими потерями.
- **Не понимать, что граница — только в пространстве признаков.** Без
  преобразований (полиномиальные признаки) она не бывает кривой.
- **Считать вектор весов «важностью» признаков без масштабирования.** Вес
  зависит от единиц измерения.

## Вероятность, шансы и логит

### Главное

Линейная модель выдаёт число `z = w·x + b` из диапазона от −∞ до +∞, а
вероятность должна лежать в `[0, 1]`. Мост между ними строится через
**шансы**.

**Шансы** (odds) события — отношение его вероятности к вероятности
противоположного: `odds = p / (1 − p)`. Шансы 3 к 1 соответствуют вероятности
0,75. Логарифм шансов называют **логитом**: `logit(p) = ln(p / (1 − p))`. Он
пробегает всю числовую прямую — от −∞ при `p → 0` до +∞ при `p → 1`.

Логистическая регрессия **предполагает, что логит линеен по признакам**:
`ln(p / (1 − p)) = w·x + b`. Обратное преобразование — **сигмоида**:

`p = σ(z) = 1 / (1 + e^(−z))`.

Она сжимает любую точку числовой прямой в отрезок `(0, 1)`, монотонна, при
`z = 0` даёт 0,5. Так модель выдаёт **вероятность** положительного класса.
Практический смысл вероятности — в ранжировании: банк может выбрать порог
отсечения под свой риск, а не довольствоваться жёстким ответом «да / нет».

### Пример

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

rng = np.random.default_rng(10)
X = rng.normal(size=(300, 2))
y = (X[:, 0] - 0.7 * X[:, 1] + rng.normal(0, 0.8, 300) > 0).astype(int)
model = LogisticRegression().fit(X, y)

z = model.decision_function(X[:4])                     # логит: w·x + b
p_manual = 1 / (1 + np.exp(-z))                        # сигмоида
p_sklearn = model.predict_proba(X[:4])[:, 1]
print(np.allclose(p_manual, p_sklearn))

odds = p_manual / (1 - p_manual)
print("логит = ln(шансов):", np.allclose(np.log(odds), z))
print("p = 0.75 -> шансы", round(0.75 / 0.25, 1))
```

### Частые ошибки

- **Путать вероятность и шансы.** Вероятность 0,5 — это шансы 1 к 1; шансы 2 к
  1 — вероятность 2/3, а не 2.
- **Считать, что вероятность из модели всегда откалибрована.** Это оценка
  при предположении о форме модели; на практике её проверяют отдельно.
- **Применять сигмоиду к метке.** Сигмоида преобразует выход модели `z` в
  вероятность, а не наоборот.

## Отступ и логистическая потеря

### Главное

Для меток `y ∈ {−1, +1}` вводят **отступ** (margin) объекта:

`M = y · (w·x + b)`.

Знак отступа показывает, верно ли классифицирован объект: `M > 0` — верно,
`M < 0` — ошибка. Модуль отступа — удалённость от границы. Поэтому большой по
модулю отрицательный отступ означает, что объект далеко от границы **и
классифицирован неверно** — самая тяжёлая ошибка.

Функция потерь должна штрафовать малые и отрицательные отступы. Доля ошибок
(`M < 0`) негладкая, поэтому берут её гладкую верхнюю оценку. Для логистической
регрессии это **логистическая потеря**:

`L(M) = ln(1 + e^(−M))`.

При большом положительном `M` потеря почти нулевая, при отрицательном —
растёт примерно линейно. Минимизация суммы таких потерь по обучающей
выборке — то же, что максимизация правдоподобия модели с сигмоидой. Именно
это и делает `LogisticRegression.fit` (по умолчанию с L2-регуляризацией, см. следующее занятие).

### Пример

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import log_loss

rng = np.random.default_rng(11)
X = rng.normal(size=(200, 2))
y01 = (X[:, 0] + rng.normal(0, 0.7, 200) > 0).astype(int)
y_pm = 2 * y01 - 1                                    # метки -1 и +1

model = LogisticRegression(C=1e6).fit(X, y01)         # почти без регуляризации
margin = y_pm * model.decision_function(X)            # отступы
loss = np.log1p(np.exp(-margin)).mean()
print("ошибок (M < 0):", int((margin < 0).sum()))
print("средняя логистическая потеря:", round(float(loss), 4))
print("sklearn log_loss:", round(float(log_loss(y01, model.predict_proba(X))), 4))
print("потеря при M=5 и M=-5:", round(float(np.log1p(np.exp(-5.0))), 4),
      round(float(np.log1p(np.exp(5.0))), 2))
```

### Частые ошибки

- **Минимизировать долю ошибок напрямую.** Она негладкая и без полезного
  градиента; вместо неё берут гладкую верхнюю границу.
- **Путать формулу для меток {−1, +1} и {0, 1}.** Запись через отступ
  работает только для меток −1 и +1.
- **Не заметить, что потеря хорошо классифицированных объектов тоже
  ненулевая.** Модель всегда стремится увеличить отступ.

## Итоги занятия

| Что | Что означает |
|---|---|
| `sign(w·x + b)` | линейный классификатор, граница — гиперплоскость |
| `odds = p/(1−p)`, `logit = ln(odds)` | шансы и логит, диапазон логита — вся прямая |
| `σ(z) = 1/(1 + e^(−z))` | сигмоида: логит → вероятность |
| `M = y·(w·x + b)` | отступ: `M < 0` — ошибка, чем меньше, тем хуже |
| `ln(1 + e^(−M))` | логистическая потеря |
| `predict_proba`, `decision_function` | вероятности и логиты в scikit-learn |

Порядок рассуждения: линейная граница → логит → вероятность через сигмоиду →
обучение минимизацией логистической потери.
