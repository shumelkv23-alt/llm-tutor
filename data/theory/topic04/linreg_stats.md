# Почему МНК: статистический взгляд

Метод наименьших квадратов вводят «просто потому, что удобно». Занятие
объясняет, почему он ещё и обоснован: при каких условиях он лучший среди
линейных несмещённых оценок, как он получается из принципа максимального
правдоподобия и из чего складывается ошибка любой модели.

## Зачем

После занятия вы сможете:

- перечислить условия теоремы Гаусса–Маркова и объяснить, что она гарантирует;
- вывести связь между нормальными ошибками и минимизацией MSE;
- разложить ошибку прогноза на смещение, разброс и неустранимый шум;
- оценить смещение и разброс простой модели численным экспериментом.

## Теорема Гаусса–Маркова

### Главное

Пусть истинная связь линейна: `y = X·w + ε`, где `ε` — случайные ошибки.
**Теорема Гаусса–Маркова** утверждает: если ошибки

- имеют нулевое математическое ожидание,
- имеют одинаковую конечную дисперсию (**гомоскедастичность**),
- не коррелируют между собой,

а признаки не дублируют друг друга (матрица `X` имеет полный ранг), то оценка
весов, полученная МНК, — **лучшая линейная несмещённая оценка** (BLUE):
среди всех линейных несмещённых оценок у неё наименьшая дисперсия.

Слова теоремы стоит читать точно. «Несмещённая» значит, что в среднем по
разным выборкам оценка попадает в истинный вес. «Линейная» — что оценка
линейно зависит от `y`. «Лучшая» — наименьшая дисперсия, то есть наименьший
разброс от выборки к выборке. Теорема **не** говорит, что МНК лучше любых
методов: нелинейные или смещённые оценки (например, с регуляризацией) могут
оказаться точнее на практике.

### Пример

```python
import numpy as np

rng = np.random.default_rng(3)
true_w = np.array([2.0, -1.0])
n, repeats = 50, 2000
estimates = np.empty((repeats, 2))
for i in range(repeats):
    X = np.column_stack([np.ones(n), rng.uniform(0, 5, n)])
    y = X @ true_w + rng.normal(0, 1.0, n)            # ошибки с нулевым средним
    estimates[i] = np.linalg.lstsq(X, y, rcond=None)[0]

print("средняя оценка:", estimates.mean(axis=0).round(3))   # близка к [2, -1]: несмещённость
print("разброс оценок:", estimates.std(axis=0).round(3))
```

### Частые ошибки

- **Считать теорему обещанием «самой точной модели».** Она про класс
  линейных несмещённых оценок при выполненных условиях.
- **Игнорировать условия.** Если дисперсия ошибок растёт вместе с признаком
  (гетероскедастичность), выводы теоремы перестают работать.
- **Путать несмещённость оценки и отсутствие ошибки.** Несмещённая оценка
  может сильно ошибаться на одной конкретной выборке.

## Правдоподобие и квадратичная ошибка

### Главное

Другой путь к МНК — **метод максимального правдоподобия**. Правдоподобие —
вероятность увидеть именно такие данные при заданных параметрах; метод
выбирает параметры, при которых она наибольшая.

Для независимых наблюдений правдоподобие — **произведение** вероятностей.
Произведение неудобно, поэтому переходят к логарифму: логарифм превращает
произведение в **сумму** слагаемых и сохраняет положение максимума.

Теперь добавим предположение о шуме: ошибки распределены **нормально** вокруг
нуля. Логарифм плотности нормального распределения для каждого объекта —
константа минус `(yᵢ − ŷᵢ)² / (2σ²)`. Максимизация суммы таких слагаемых по
весам — то же самое, что **минимизация суммы квадратов ошибок**. Итог:
максимум правдоподобия при нормальных ошибках совпадает с МНК.

Это объясняет роль нормальности: она не нужна для теоремы Гаусса–Маркова, но
даёт МНК вероятностную интерпретацию. Если ошибки распределены иначе
(например, с тяжёлыми хвостами), «правильной» функцией потерь будет не квадрат.

### Пример

```python
import numpy as np

rng = np.random.default_rng(4)
x = rng.uniform(0, 10, 200)
y = 1.5 * x + rng.normal(0, 2.0, 200)


def neg_log_likelihood(w, sigma=2.0):
    residuals = y - w * x
    return float(np.sum(residuals**2 / (2 * sigma**2) + np.log(sigma * np.sqrt(2 * np.pi))))


def sse(w):
    return float(np.sum((y - w * x) ** 2))


grid = np.linspace(1.0, 2.0, 101)
best_ml = grid[np.argmin([neg_log_likelihood(w) for w in grid])]
best_ls = grid[np.argmin([sse(w) for w in grid])]
print(best_ml, best_ls)     # один и тот же вес
```

### Частые ошибки

- **Думать, что МНК «требует» нормальности.** Для несмещённости и теоремы она
  не нужна; нормальность нужна для вывода через правдоподобие.
- **Забыть про логарифм.** Максимизировать произведение вероятностей
  численно неудобно, а сумма логарифмов — удобна.
- **Переносить вывод на другие ошибки.** При других распределениях шума
  максимум правдоподобия даёт другую функцию потерь.

## Смещение и разброс

### Главное

Ошибка прогноза модели в новой точке складывается из трёх частей:

`ожидаемая ошибка = смещение² + разброс + неустранимая ошибка`.

- **Смещение** (bias) — насколько прогноз в среднем (по разным обучающим
  выборкам) отличается от истины. Оно велико, если модель слишком проста и не
  может описать закономерность.
- **Разброс** (variance) — насколько прогноз меняется от выборки к выборке.
  Он велик, если модель слишком гибкая и подстраивается под шум конкретных
  данных.
- **Неустранимая ошибка** (шум) — случайность в самих ответах; повлиять на
  неё модель не может.

С ростом сложности модели (например, числа параметров) разброс обычно растёт,
а смещение падает. Лучшая модель — компромисс. Эта идея объясняет и
переобучение, и регуляризацию (следующее занятие).

### Пример

```python
import numpy as np

rng = np.random.default_rng(5)


def truth(x):
    return np.sin(2 * x)


x_grid = np.linspace(0, 3, 40)
for degree in (1, 3, 5):
    predictions = []
    for _ in range(300):
        x = rng.uniform(0, 3, 30)
        y = truth(x) + rng.normal(0, 0.3, 30)
        coefficients = np.polyfit(x, y, degree)
        predictions.append(np.polyval(coefficients, x_grid))
    predictions = np.array(predictions)
    bias2 = float(np.mean((predictions.mean(axis=0) - truth(x_grid)) ** 2))
    variance = float(np.mean(predictions.var(axis=0)))
    print(degree, "степень: bias² =", round(bias2, 3), "разброс =", round(variance, 3))
```

### Частые ошибки

- **Считать, что можно снизить обе части сколь угодно.** Одна обычно растёт,
  когда падает другая; шум не уменьшить вовсе.
- **Путать смещение оценки весов и смещение прогноза.** Это связанные, но
  разные величины.
- **Оценивать разброс по одной выборке.** Для него нужно много разных обучающих
  выборок (или их аналог — кросс-валидация, бутстрэп).

## Итоги занятия

| Что | Что означает |
|---|---|
| условия Гаусса–Маркова | нулевое среднее ошибок, одинаковая дисперсия, некоррелированность, полный ранг `X` |
| BLUE | лучшая линейная несмещённая оценка: наименьшая дисперсия |
| правдоподобие | вероятность наблюдаемых данных при параметрах; логарифм превращает произведение в сумму |
| нормальные ошибки | максимум правдоподобия ⇔ минимум MSE |
| ошибка = смещение² + разброс + шум | три источника ошибки модели |

Порядок рассуждения: условия на ошибки → оптимальность МНК → вероятностный
вывод → цена сложности модели.
