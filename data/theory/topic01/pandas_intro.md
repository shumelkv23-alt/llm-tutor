# Series и DataFrame

## Зачем

В pandas две главные структуры, и почти всё остальное — операции над ними. **Series** — это один столбец с подписями строк, **DataFrame** — таблица из таких столбцов. Когда понятно, что и как в них хранится, остальные темы ложатся на это знание.

## Главное

- **Series** — одномерный массив значений одного типа плюс **индекс** (подписи элементов). Похож на словарь «подпись → значение», который умеет векторную арифметику.
- **DataFrame** — двумерная таблица: строки — объекты (клиенты, заказы), столбцы — признаки (возраст, сумма). Каждый столбец — это Series, все столбцы делят общий индекс строк.
- У DataFrame есть **индекс строк** (`df.index`) и **подписи столбцов** (`df.columns`).
- Таблицу удобно создавать из словаря списков: ключи становятся столбцами.
- Столбец достают по имени: `df["age"]` даёт Series, а `df[["age", "city"]]` — DataFrame из двух столбцов.
- Импортируют pandas по соглашению так: `import pandas as pd`.

## Пример

```python
import pandas as pd

ages = pd.Series([31, 45, 27], index=["Аня", "Борис", "Вера"], name="age")
print(ages)
print(ages["Борис"])     # 45 — доступ по подписи
print(ages.mean())       # 34.33...

df = pd.DataFrame({
    "name": ["Аня", "Борис", "Вера"],
    "city": ["Казань", "Москва", "Казань"],
    "age": [31, 45, 27],
})
print(df)
print(type(df["age"]))   # <class 'pandas.core.series.Series'>
print(df.columns.tolist())  # ['name', 'city', 'age']
```

Двойные скобки возвращают таблицу, одинарные — столбец:

```python
print(df[["name", "age"]].shape)  # (3, 2) — DataFrame
print(df["age"].shape)            # (3,) — Series
```

## Частые ошибки

- **Ждать таблицу от `df["col"]`:** одинарные скобки дают Series. Для таблицы нужен список столбцов: `df[["col"]]`.
- **Забывать про индекс:** при арифметике двух Series pandas выравнивает значения **по подписям**, а не по позициям. Несовпавшие подписи дают `NaN`.
- **Считать DataFrame списком строк:** `for x in df` перебирает **имена столбцов**, а не строки.
