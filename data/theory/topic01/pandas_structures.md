# Series и DataFrame

Зачем pandas, Series с индексом и DataFrame — таблица из столбцов-Series.

## Зачем pandas

### Series и DataFrame

#### Зачем

В pandas две главные структуры, и почти всё остальное — операции над ними. **Series** — это один столбец с подписями строк, **DataFrame** — таблица из таких столбцов. Когда понятно, что и как в них хранится, остальные темы ложатся на это знание.

#### Главное

- **Series** — одномерный массив значений одного типа плюс **индекс** (подписи элементов). Похож на словарь «подпись → значение», который умеет векторную арифметику.
- **DataFrame** — двумерная таблица: строки — объекты (клиенты, заказы), столбцы — признаки (возраст, сумма). Каждый столбец — это Series, все столбцы делят общий индекс строк.
- У DataFrame есть **индекс строк** (`df.index`) и **подписи столбцов** (`df.columns`).
- Таблицу удобно создавать из словаря списков: ключи становятся столбцами.
- Столбец достают по имени: `df["age"]` даёт Series, а `df[["age", "city"]]` — DataFrame из двух столбцов.
- Импортируют pandas по соглашению так: `import pandas as pd`.

#### Пример

```python
import pandas as pd

ages = pd.Series([31, 45, 27], index=["Аня", "Борис", "Вера"], name="age")
print(ages)
print(ages["Борис"])     # 45 — доступ по подписи
print(ages.mean())       # 34.33...

df = pd.DataFrame({
    "name": ["Аня", "Борис", "Вера"],
    "city": ["Казань", "Москва", "Казань"],
    "age": [31, 45, 27],
})
print(df)
print(type(df["age"]))   # <class 'pandas.core.series.Series'>
print(df.columns.tolist())  # ['name', 'city', 'age']
```

Двойные скобки возвращают таблицу, одинарные — столбец:

```python
import pandas as pd

df = pd.DataFrame({"name": ["Аня", "Борис", "Вера"], "age": [31, 45, 27]})
print(df[["name", "age"]].shape)  # (3, 2) — DataFrame
print(df["age"].shape)            # (3,) — Series
```

#### Частые ошибки

- **Ждать таблицу от `df["col"]`:** одинарные скобки дают Series. Для таблицы нужен список столбцов: `df[["col"]]`.
- **Забывать про индекс:** при арифметике двух Series pandas выравнивает значения **по подписям**, а не по позициям. Несовпавшие подписи дают `NaN`.
- **Считать DataFrame списком строк:** `for x in df` перебирает **имена столбцов**, а не строки.

## Series: значения и индекс

### Series

#### Зачем

Каждый столбец таблицы — это Series. Фильтры, статистики, `value_counts` и `apply` для столбцов работают именно с ней. Если понимать Series, становится понятно, что возвращают выражения вроде `df["age"] > 30`.

#### Главное

- Series состоит из **значений** (`s.values`; для обычных типов — массив NumPy одного типа) и **индекса** (`s.index`).
- Тип значений хранится в `s.dtype`: `int64`, `float64`, `object` (строки), `bool`, `category`.
- **Векторная арифметика:** `s * 2` и `s + 1` применяются к каждому элементу.
- **Выравнивание по индексу:** `s1 + s2` складывает элементы с одинаковыми подписями. Где подпись есть только в одной Series, результат — `NaN`.
- **Сравнение** даёт булеву Series той же длины: `s > 30`. Её используют как маску.
- **Методы-статистики:** `mean`, `median`, `min`, `max`, `std`, `sum`, `count` (число непустых значений).
- **Пропуски** обозначаются `NaN`. Статистики их по умолчанию пропускают, а `isna()` находит.

#### Пример

```python
import pandas as pd

visits = pd.Series([3, 7, 1, 7], index=["пн", "вт", "ср", "чт"])
print(visits.dtype)       # int64
print(visits * 10)        # каждое значение ×10
print(visits > 2)         # булева Series
print(visits[visits > 2]) # только пн, вт и чт
print(visits.max(), visits.idxmax())  # 7 вт — первое вхождение максимума
```

Выравнивание по индексу и пропуски:

```python
import pandas as pd

a = pd.Series([1, 2, 3], index=["x", "y", "z"])
b = pd.Series([10, 20], index=["y", "z"])
total = a + b
print(total)              # x — NaN, y — 12.0, z — 23.0
print(total.isna().sum()) # 1
print(total.mean())       # 17.5 — NaN не учитывается
```

#### Частые ошибки

- **Удивляться `NaN` после арифметики** — подписи двух Series не совпали. Используйте `a.add(b, fill_value=0)`, если отсутствие значения означает ноль.
- **Путать `count` и `len`:** `count()` не считает пропуски, `len(s)` считает все элементы.
- **Ожидать сохранения целого типа:** появление `NaN` в целочисленном столбце превращает его в `float64`.

## DataFrame: строки, столбцы, индекс

### DataFrame

#### Зачем

DataFrame — основной рабочий объект анализа данных: в нём лежит датасет, над ним считают сводки и из него готовят признаки для моделей. Важно понимать его устройство: строки, столбцы, индекс и типы.

#### Главное

- Строки — **объекты** наблюдения, столбцы — **признаки**. В датасете оттока клиентов строка — клиент, столбцы — его тариф, минуты разговоров и факт ухода.
- **Размер** — `df.shape`, кортеж `(число строк, число столбцов)`.
- **Индекс строк** по умолчанию — числа `0, 1, 2…`. Его можно заменить столбцом через `set_index`.
- **Типы столбцов** — `df.dtypes`. В одном столбце один тип, а разные столбцы могут иметь разные типы.
- **Новый столбец** создаётся присваиванием: `df["new"] = выражение`. Выражение считается векторно, по всем строкам сразу.
- **Транспонирование** `df.T` меняет строки и столбцы местами. Это удобно, когда признаков много, а строк мало.

#### Пример

```python
import pandas as pd

df = pd.DataFrame({
    "client": ["a1", "a2", "a3", "a4"],
    "tariff": ["base", "pro", "base", "pro"],
    "minutes": [120.5, 340.0, 80.0, 410.2],
    "churn": [False, True, False, True],
})
print(df.shape)    # (4, 4)
print(df.dtypes)   # object, object, float64, bool

df["hours"] = df["minutes"] / 60          # вычисляемый столбец
print(df[["client", "hours"]].round(1))

df = df.set_index("client")               # client — теперь индекс строк
print(df.loc["a2", "tariff"])             # pro — выбор по метке, подробнее в теме «loc и iloc»
print(df.T)                               # строки и столбцы поменялись местами
```

#### Частые ошибки

- **Ждать, что `set_index` изменит таблицу на месте.** Метод возвращает новую таблицу: её нужно присвоить (`df = df.set_index(...)`).
- **Создавать столбец через атрибут** (`df.hours = ...`) — так pandas создаст атрибут объекта, а не столбец. Пишите `df["hours"] = ...`.
- **Перебирать строки циклом** там, где хватит векторной операции над столбцами. Цикл по строкам (`iterrows`) медленный, к нему прибегают в крайнем случае.
