# Series и DataFrame

Первое занятие курса: из чего состоит таблица в pandas. Всё остальное — чтение
данных, выборки, группировки — опирается на две структуры: Series и DataFrame.

## Зачем

После занятия вы сможете:

- объяснить, чем таблица pandas удобнее списка словарей или массива NumPy;
- создать Series и DataFrame из словаря и списка и задать им индекс;
- достать из таблицы столбец, строку по метке и одно значение;
- понять, почему результат операции — Series, а не DataFrame (и наоборот).

Курс рассчитан на базовый Python: списки, словари, функции и циклы вы уже
знаете. Здесь — только то, что добавляет pandas.

## Зачем pandas

### Главное

Почти любые данные для машинного обучения — это таблица: строка — объект
(клиент, сделка, письмо), столбец — признак (возраст, сумма, число звонков). В
чистом Python такую таблицу хранят списком словарей, и каждый вопрос к данным
превращается в цикл: «средний возраст», «сколько клиентов ушло», «у кого больше
четырёх звонков в поддержку».

pandas — библиотека, которая хранит таблицу по столбцам и даёт операции над
целыми столбцами сразу. Вместо цикла — одно выражение: `df["age"].mean()`.
Это короче, быстрее (внутри работают массивы NumPy) и меньше мест для ошибки.

Три идеи, на которых держится pandas:

1. **Столбцы однотипны.** Внутри столбца — числа, строки или логические
   значения, а у разных столбцов типы могут отличаться.
2. **У строк есть индекс** — подписи, по которым строку находят. По умолчанию
   это 0, 1, 2…, но индексом может быть и номер клиента, и дата.
3. **Операции векторные.** `df["calls"] > 3` сравнивает с тройкой каждый
   элемент столбца и возвращает столбец из True/False.

Принято импортировать библиотеку под коротким именем `pd` — так написаны и
документация, и все материалы курса.

### Пример

Одна и та же задача — доля ушедших клиентов — в чистом Python и в pandas:

```python
import pandas as pd

clients = [
    {"State": "KS", "Customer service calls": 1, "Churn": False},
    {"State": "OH", "Customer service calls": 4, "Churn": True},
    {"State": "NJ", "Customer service calls": 0, "Churn": False},
    {"State": "OH", "Customer service calls": 5, "Churn": True},
]

# Чистый Python: цикл и счётчик.
churned = 0
for client in clients:
    if client["Churn"]:
        churned += 1
print(churned / len(clients))

# pandas: таблица из списка словарей и среднее по логическому столбцу.
df = pd.DataFrame(clients)
print(df["Churn"].mean())
```

Среднее по столбцу из True/False — это доля True: True считается единицей,
False — нулём. Этот приём понадобится в каждом занятии модуля.

### Частые ошибки

- **Писать циклы по строкам.** `for i in range(len(df))` работает, но в
  десятки раз медленнее и длиннее векторной операции. Если тянет написать
  цикл — сначала поищите метод столбца.
- **Путать pandas и NumPy.** У массива NumPy нет подписей строк и столбцов, у
  таблицы pandas — есть. Метод `.mean()` есть у обоих, но индекс и имена
  столбцов сохраняет только pandas.

## Series: значения и индекс

### Главное

**Series** — одномерный массив с подписями. У него две части:

- `values` — сами значения (массив NumPy);
- `index` — подписи элементов.

Series создают из списка (индекс будет 0, 1, 2…) или из словаря (ключи станут
индексом). Индекс можно задать явно параметром `index`.

К элементу обращаются по метке: `s["OH"]`. Арифметика и сравнения работают
поэлементно, а при операции над двумя Series pandas **выравнивает их по
индексу**: складываются значения с одинаковыми метками, а не стоящие на одной
позиции. Метка, которой нет в одной из Series, даёт пропуск — `NaN`.

У Series есть имя (`name`): когда Series — столбец таблицы, имя совпадает с
названием столбца.

### Пример

```python
import pandas as pd

# Число звонков в поддержку по штатам: ключи словаря становятся индексом.
calls = pd.Series({"KS": 1, "OH": 4, "NJ": 0}, name="calls")
print(calls)
print(calls["OH"])          # элемент по метке
print(calls.index.tolist())  # ['KS', 'OH', 'NJ']
print(calls * 10)            # поэлементно

# Выравнивание по индексу: складываются одинаковые метки.
extra = pd.Series({"OH": 1, "KS": 2, "MO": 3})
print(calls + extra)         # у NJ и MO будет NaN — метки есть только в одной Series
```

Обратите внимание на последнюю строку: порядок элементов в `extra` другой, но
сложение всё равно идёт по меткам. Для KS получится 1 + 2, для OH — 4 + 1.

### Частые ошибки

- **Ждать сложения по позициям.** Две Series с разными индексами складываются
  по меткам, и несовпавшие метки дают `NaN`. Если нужны позиции — сравните
  `.values` или сбросьте индекс через `reset_index(drop=True)`.
- **Путать `s[0]` и метку 0.** Квадратные скобки у Series ищут **метку**.
  Если индекс — строки, позицию надёжнее брать через `.iloc[0]` (о нём — в
  занятии «Выборка данных»).
- **Терять пропуски из виду.** `NaN` после выравнивания — не ошибка pandas, а
  честный ответ «значения нет». Его видно в `isna()`.

## DataFrame: строки, столбцы, индекс

### Главное

**DataFrame** — таблица: набор Series с общим индексом строк. У таблицы есть:

- `index` — подписи строк;
- `columns` — названия столбцов;
- `shape` — размер «строк × столбцов» кортежем.

Удобнее всего создавать таблицу из словаря «название столбца → список
значений»: все списки должны быть одной длины. Индекс строк задают параметром
`index`.

Квадратные скобки у DataFrame выбирают **столбцы**:

- `df["Churn"]` — один столбец, результат — **Series**;
- `df[["State", "Churn"]]` — несколько столбцов (список внутри скобок),
  результат — **DataFrame**.

Строку по метке индекса достают через `df.loc[метка]` — тоже Series, только
подписями у неё будут названия столбцов. Одно значение — `df.loc[метка,
"столбец"]`.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "State": ["KS", "OH", "NJ", "OH"],
        "Total day minutes": [265.1, 161.6, 243.4, 299.4],
        "Customer service calls": [1, 4, 0, 2],
        "Churn": [False, True, False, False],
    },
    index=["c1", "c2", "c3", "c4"],
)
print(df.shape)              # (4, 4)
print(df.columns.tolist())

churn = df["Churn"]          # Series
print(type(churn).__name__, churn.index.tolist())

part = df[["State", "Churn"]]  # DataFrame из двух столбцов
print(type(part).__name__, part.shape)

print(df.loc["c2"])                         # строка c2 — Series
print(df.loc["c2", "Customer service calls"])  # одно значение
```

### Частые ошибки

- **Одни скобки вместо двух.** `df["State", "Churn"]` — это поиск одного
  столбца с именем-кортежем, и pandas ответит `KeyError`. Для нескольких
  столбцов нужен список: `df[["State", "Churn"]]`.
- **Ждать строку от `df["c2"]`.** Скобки у таблицы ищут столбец. Строка по
  метке — только через `df.loc["c2"]`.
- **Списки разной длины в словаре.** `pd.DataFrame({"a": [1, 2], "b": [1]})`
  падает с `ValueError`: столбцы таблицы всегда одной длины.

## Итоги занятия

| Что | Что делает |
|---|---|
| `pd.Series(данные, index=…)` | одномерный массив с подписями |
| `pd.DataFrame(словарь, index=…)` | таблица из столбцов-списков |
| `s.values`, `s.index` | значения и подписи Series |
| `df.shape`, `df.columns`, `df.index` | размер, названия столбцов, подписи строк |
| `df["col"]` | столбец — Series |
| `df[["a", "b"]]` | несколько столбцов — DataFrame |
| `df.loc[метка]`, `df.loc[метка, "col"]` | строка по метке, одно значение |
| `series.mean()` по True/False | доля True |

Главная мысль занятия: операции идут над столбцами целиком и выравниваются по
индексу, а не по позиции.
