# Основы NumPy

## Зачем

pandas построен поверх NumPy: значения столбца хранятся в массиве NumPy, а арифметика над столбцами — это векторные операции NumPy. Поэтому полезно понимать, что такое `ndarray`, почему операции идут «целиком по массиву» и как работает broadcasting.

## Главное

- **`np.array`** создаёт массив `ndarray`: у всех элементов один тип (`dtype`), например `int64` или `float64`. **`np.arange(n)`** даёт числа от 0 до `n - 1`: `np.arange(3)` — это `[0, 1, 2]`.
- **Векторные операции** применяются ко всем элементам сразу и без цикла: `a * 2`, `a + b`, `a > 10`. Это короче и намного быстрее циклов на Python.
- **Форма** (`shape`) — размер по каждой оси. У вектора она `(n,)`, у матрицы — `(строки, столбцы)`.
- **Broadcasting** («растягивание») позволяет складывать массивы разной формы, если размеры совместимы. Например, к каждой строке матрицы можно прибавить вектор длины «число столбцов».
- **Булевы маски:** выражение `a > 10` даёт массив `True/False`, а `a[a > 10]` — только подходящие элементы. Тот же приём работает и в pandas.
- **Агрегаты** `a.sum()`, `a.mean()`, `a.max()` сворачивают массив в число, а с параметром `axis` — по нужной оси.

## Пример

```python
import numpy as np

prices = np.array([120.0, 80.0, 250.0, 40.0])
print(prices.dtype, prices.shape)   # float64 (4,)

with_tax = prices * 1.2              # векторно, без цикла
print(with_tax)                      # [144.  96. 300.  48.]

expensive = prices[prices > 100]     # булева маска
print(expensive)                     # [120. 250.]
print(prices.mean())                 # 122.5
```

Broadcasting: вычитаем из каждого столбца матрицы его среднее значение.

```python
import numpy as np

matrix = np.array([[1.0, 10.0],
                   [3.0, 30.0],
                   [5.0, 50.0]])
column_means = matrix.mean(axis=0)   # среднее по строкам для каждого столбца
print(column_means)                  # [ 3. 30.]
centered = matrix - column_means     # (3, 2) минус (2,) — растягивается по строкам
print(centered)
```

## Частые ошибки

- **Писать цикл** там, где хватит векторной операции: `[x * 2 for x in a]` вместо `a * 2`.
- **Смешивать типы:** если в массиве оказалась строка, весь массив станет строковым, и арифметика перестанет работать.
- **Путать `axis`:** `axis=0` сворачивает строки (ответ — по столбцам), а `axis=1` сворачивает столбцы (ответ — по строкам).
- **Писать `and`/`or` для масок:** для массивов нужны `&` и `|`, а каждое условие — в скобках: `(a > 1) & (a < 5)`.
