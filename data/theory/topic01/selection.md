# Выборка данных

Почти любой вопрос к данным начинается с выборки: «клиенты из Огайо», «ушедшие
с международным тарифом», «первые десять строк и два столбца». В pandas для
этого два инструмента — индексаторы `loc`/`iloc` и булевы маски.

## Зачем

После занятия вы сможете:

- выбирать строки и столбцы по меткам (`loc`) и по позициям (`iloc`);
- брать срезы и понимать, включается ли в них правая граница;
- отбирать строки по условию и соединять условия через `&`, `|` и `~`;
- проверять принадлежность списку значений через `isin`.

## loc, iloc и срезы

### Главное

У таблицы два индексатора, и у обоих синтаксис `df.индексатор[строки,
столбцы]`:

- **`loc`** работает с **метками** — значениями индекса строк и названиями
  столбцов;
- **`iloc`** работает с **позициями** — номерами строк и столбцов с нуля, как у
  списков Python.

Внутри скобок можно передать одну метку (позицию), список или срез. Если
столбцы не нужны, вторую часть опускают: `df.loc["c2"]` — вся строка.

Главное отличие срезов: у `iloc` срез как в Python — **правая граница не
включается** (`iloc[0:2]` — две строки). У `loc` срез по меткам **включает
обе границы** (`loc["c1":"c3"]` — три строки): метки не обязаны быть числами,
и «следующей за c3» метки может просто не существовать.

Тип результата зависит от того, что выбрано: одна строка и один столбец —
скаляр; одна строка или один столбец — Series; несколько и того, и другого —
DataFrame.

`loc` особенно удобен, когда индекс несёт смысл. Столбец делают индексом через
`df.set_index("Phone number")` — и строку клиента достают по номеру телефона,
а не по позиции, которая меняется после каждой сортировки или фильтра.
Обратная операция — `reset_index()`: индекс снова становится обычным столбцом,
а строки получают номера 0, 1, 2… С параметром `drop=True` старый индекс просто
выбрасывается — так делают после фильтрации, чтобы номера шли подряд.

Для одного значения есть быстрые варианты `df.at[метка, "столбец"]` и
`df.iat[позиция, позиция]`: они делают то же, что `loc`/`iloc`, но только для
одной ячейки.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "State": ["KS", "OH", "NJ", "OH", "OK"],
        "Total day minutes": [265.1, 161.6, 243.4, 299.4, 166.7],
        "Customer service calls": [1, 4, 0, 2, 3],
        "Churn": [False, True, False, False, True],
    },
    index=["c1", "c2", "c3", "c4", "c5"],
)

print(df.loc["c2", "State"])                     # скаляр
print(df.loc["c1":"c3", ["State", "Churn"]])     # три строки: c3 включена
print(df.iloc[0:2, 0:2])                         # две строки: позиция 2 не входит
print(df.iloc[-1])                               # последняя строка — Series
print(df.loc[:, "Total day minutes"].max())      # все строки, один столбец
```

### Частые ошибки

- **Ждать от `loc` срез «как в Python».** `df.loc[0:2]` на индексе 0, 1, 2…
  вернёт **три** строки: срез по меткам включает правую границу.
- **Позиции в `loc`.** `df.loc[0]` ищет **метку** 0. Если индекс — строки,
  будет `KeyError`; позиция — это `iloc`.
- **Цепочки скобок с присваиванием.** `df[df["Churn"]]["State"] = "XX"`
  меняет копию, а не таблицу, и pandas предупредит об этом. Присваивайте одним
  `loc`: `df.loc[df["Churn"], "State"] = "XX"`.

## Булевы маски и условия

### Главное

Сравнение столбца со значением даёт **булеву маску** — Series из True/False
той же длины, что таблица. Маска внутри квадратных скобок оставляет строки,
где стоит True: `df[df["Churn"]]`.

Условия соединяют поэлементными операторами:

- `&` — И, `|` — ИЛИ, `~` — НЕ;
- каждое условие берут **в скобки**: у `&` и `|` приоритет выше, чем у
  сравнения, и без скобок выражение разберётся неправильно.

Python-овские `and`, `or`, `not` здесь не работают: они требуют одного
True/False на весь столбец, и pandas отвечает ошибкой «The truth value of a
Series is ambiguous».

Для «значение из списка» есть `s.isin([...])`, для диапазона —
`s.between(a, b)` (обе границы включены). Маску можно передать и в `loc`,
чтобы сразу выбрать столбцы: `df.loc[маска, ["State", "Churn"]]`.

Маску удобно сохранить в переменную с понятным именем (`churned`, `risky`):
условие читается как фраза, и его можно переиспользовать — посчитать
`mask.sum()` (сколько строк подошло) или `mask.mean()` (какая доля). Есть и
текстовая запись условий — `df.query("Churn and calls > 3")`, но с
названиями столбцов через пробел она неудобна, поэтому в курсе используем
маски.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "State": ["KS", "OH", "NJ", "OH", "OK", "AL", "MA", "MO"],
        "International plan": ["No", "No", "No", "Yes", "Yes", "Yes", "No", "No"],
        "Customer service calls": [1, 4, 0, 2, 3, 0, 4, 5],
        "Churn": [False, False, False, False, True, False, True, True],
    }
)

churned = df[df["Churn"]]
print(len(churned))

# Ушли И звонили в поддержку больше трёх раз — каждое условие в скобках.
mask = df["Churn"] & (df["Customer service calls"] > 3)
print(df.loc[mask, ["State", "Customer service calls"]])

# Международный тариф ИЛИ много звонков; НЕ из Огайо.
risky = (df["International plan"] == "Yes") | (df["Customer service calls"] >= 4)
print(df[risky & ~(df["State"] == "OH")]["State"].tolist())

print(df[df["State"].isin(["OH", "NJ"])].shape)
print(df["Customer service calls"].between(1, 3).sum())
```

### Частые ошибки

- **`and` вместо `&`.** `df[a and b]` падает с «truth value of a Series is
  ambiguous». Для столбцов — только `&`, `|`, `~`.
- **Скобки.** `df["calls"] > 3 & df["Churn"]` разбирается как
  `df["calls"] > (3 & df["Churn"])`. Пишите `(df["calls"] > 3) & df["Churn"]`.
- **Маска от другой таблицы.** Маска выравнивается по индексу. Маска,
  посчитанная по отфильтрованной копии, к исходной таблице не подойдёт —
  pandas сообщит о несовпадении индексов.

## Итоги занятия

| Что | Что делает |
|---|---|
| `df.loc[метки, столбцы]` | выборка по меткам; срез включает правую границу |
| `df.iloc[позиции, позиции]` | выборка по номерам; срез не включает правую границу |
| `df[маска]` | строки, где маска True |
| `(a) & (b)`, `(a) \| (b)`, `~a` | И, ИЛИ, НЕ для масок |
| `s.isin([...])`, `s.between(a, b)` | значение из списка, из диапазона |
| `df.loc[маска, ["a", "b"]]` | строки по условию и нужные столбцы сразу |

Правило: условие — в скобках, соединение — `&`/`|`, присваивание — одним
`loc`.
