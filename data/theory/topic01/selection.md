# Выборка данных

loc, iloc и срезы; булевы маски и составные условия.

## loc, iloc и срезы

### Доступ к данным: loc и iloc

#### Зачем

Анализ — это постоянный выбор частей таблицы: нужные строки, нужные столбцы, одна ячейка. В pandas для этого два «окна»: `loc` выбирает **по подписям**, `iloc` — **по позициям**. Если их путать, легко получить не те данные и не заметить ошибку.

#### Главное

- **`df.loc[строки, столбцы]`** — выбор по меткам индекса и именам столбцов.
- **`df.iloc[строки, столбцы]`** — выбор по целым номерам позиций, как в списках Python, с нуля.
- **Срезы ведут себя по-разному:**
  - `iloc[0:3]` — позиции 0, 1, 2; правая граница **не входит**, как в Python;
  - `loc["a":"c"]` — от метки `a` до метки `c` **включительно**.
- Вместо строк или столбцов можно передать список (`["age", "city"]`) или булеву маску — условие вроде `df["age"] > 30` (подробнее — в теме «Булева индексация»).
- `df.loc[метка, "столбец"]` возвращает одну ячейку, `df.loc[метка]` — строку в виде Series.
- Через `loc` можно и **присваивать**: `df.loc[маска, "col"] = значение`.

#### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {"age": [31, 45, 27, 52], "city": ["Казань", "Москва", "Казань", "Сочи"]},
    index=["a", "b", "c", "d"],
)

print(df.loc["b", "city"])        # Москва — по метке
print(df.iloc[1, 1])              # Москва — по позиции
print(df.loc["a":"c", "age"])     # a, b, c — правая метка входит
print(df.iloc[0:2, 0])            # только a и b — правая позиция не входит
print(df.loc[df["age"] > 30, ["city"]])  # маска строк и список столбцов

df.loc[df["city"] == "Казань", "age"] = 0   # присваивание через loc
print(df)
```

#### Частые ошибки

- **Ждать от `loc[0:2]`, что он поведёт себя как `iloc`.** Если индекс — числа 0, 1, 2…, то `loc[0:2]` вернёт **три** строки (метки 0, 1 и 2), а `iloc[0:2]` — две.
- **Присваивать «цепочкой»:** `df[df["age"] > 30]["city"] = "X"` меняет временную копию, а не таблицу (pandas предупредит). Пишите одно обращение: `df.loc[df["age"] > 30, "city"] = "X"`.
- **Передавать в `iloc` имена столбцов.** Он понимает только номера позиций.

## Булевы маски и условия

### Булева индексация

#### Зачем

Многие вопросы к данным звучат как «а что у тех, кто…»: ушедших клиентов, звонивших в поддержку чаще трёх раз, жителей одного штата. Булева индексация выбирает такие строки: условие превращается в маску `True/False`, и в таблице остаются только строки с `True`.

#### Главное

- Сравнение столбца даёт **маску** — булеву Series: `df["calls"] > 3`.
- **`df[маска]`** оставляет строки, где маска истинна. Тот же выбор через `loc`: `df.loc[маска, столбцы]`.
- Условия объединяют операторами **`&`** (и), **`|`** (или), **`~`** (не). **Каждое условие — в скобках**, потому что `&` и `|` связывают сильнее, чем `>` и `==`.
- **`isin([...])`** проверяет вхождение в список значений, **`between(a, b)`** — попадание в диапазон (границы входят).
- Сумма маски — число подходящих строк, среднее — их доля.
- Для строк есть `df["col"].str.contains("текст")`.

#### Пример

```python
import pandas as pd

df = pd.DataFrame({
    "State": ["KS", "OH", "NJ", "OH", "OK", "AL", "OH"],
    "International plan": ["No", "No", "No", "Yes", "Yes", "No", "Yes"],
    "Customer service calls": [1, 1, 0, 2, 4, 5, 0],
    "Churn": [False, False, False, False, True, True, True],
})

many_calls = df["Customer service calls"] > 3
print(many_calls.sum())              # 2 клиента
print(df[many_calls])

churned_intl = df[(df["Churn"]) & (df["International plan"] == "Yes")]
print(len(churned_intl))             # 2

print(df.loc[df["State"].isin(["OH", "NJ"]), "Churn"].mean())  # 0.25
print(df[~df["Churn"]].shape[0])     # 4 оставшихся клиента
```

#### Частые ошибки

- **Писать `and` и `or`** вместо `&` и `|`. Получится ошибка `The truth value of a Series is ambiguous`.
- **Забывать скобки:** `df["a"] > 1 & df["b"] < 5` разбирается как `df["a"] > (1 & df["b"]) < 5`. Нужно `(df["a"] > 1) & (df["b"] < 5)`.
- **Менять отфильтрованную копию:** `df[mask]["col"] = 0` не трогает исходную таблицу. Пишите `df.loc[mask, "col"] = 0`.
