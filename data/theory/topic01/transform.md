# Сортировка и преобразование столбцов

Данные редко бывают сразу в нужном виде: их надо упорядочить, перекодировать
значения, добавить вычисляемые признаки и убрать лишнее. Это занятие — про
инструменты такой подготовки.

## Зачем

После занятия вы сможете:

- сортировать таблицу по одному и нескольким столбцам в нужном направлении;
- применять функцию к столбцу через `apply` и `map` и заменять значения через
  `replace`;
- добавлять вычисляемые столбцы и удалять ненужные;
- выбирать между векторной операцией и `apply` — и понимать, почему первая
  лучше.

## Сортировка

### Главное

`df.sort_values(by=…)` возвращает таблицу, отсортированную по значениям
столбца. Параметры:

- `by` — столбец или список столбцов; при списке сортировка идёт по первому, а
  при равенстве — по второму и так далее;
- `ascending` — по возрастанию (`True`, по умолчанию) или по убыванию; для
  нескольких столбцов — список направлений.

Индекс строк при сортировке **переезжает вместе со строками**: строка с
меткой 3 останется меткой 3, просто окажется в другом месте. Поэтому после
сортировки к строкам обращаются через `iloc` («первые три») или сбрасывают
индекс.

Для «верхних n» есть короткие пути: `df.nlargest(n, "столбец")` и
`df.nsmallest(n, "столбец")`. Отсортировать по самому индексу — `sort_index()`.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "State": ["KS", "OH", "NJ", "OH", "OK", "AL"],
        "Total day charge": [45.07, 27.47, 41.38, 50.90, 28.34, 37.98],
        "Customer service calls": [1, 4, 0, 2, 3, 0],
        "Churn": [False, True, False, False, True, False],
    }
)

top = df.sort_values(by="Total day charge", ascending=False).head(3)
print(top)                      # индекс остался прежним: 3, 0, 2

# Сначала ушедшие, внутри — по убыванию звонков.
print(df.sort_values(by=["Churn", "Customer service calls"], ascending=[False, False]))

print(df.nlargest(2, "Total day charge")["State"].tolist())
```

### Частые ошибки

- **Ждать изменения таблицы.** `sort_values` возвращает новую таблицу;
  исходная остаётся как была. Результат нужно присвоить.
- **Перепутать направление.** По умолчанию — по возрастанию; «самые дорогие» —
  это `ascending=False`.
- **Брать «первые» через `loc`.** После сортировки `loc[0:2]` вернёт строки с
  метками 0…2, где бы они ни стояли. Первые по порядку — `head` или `iloc`.

## apply, map и replace

### Главное

Три способа превратить значения столбца в другие:

- **`s.map(словарь или функция)`** — каждое значение заменяется по словарю или
  результату функции. Значения, которых нет в словаре, становятся `NaN`.
- **`s.apply(функция)`** — применить функцию к каждому элементу Series. У
  DataFrame `df.apply(функция)` применяет её к каждому **столбцу**, а с
  `axis=1` — к каждой **строке** (функция получает строку как Series).
- **`s.replace(что, на что)`** — заменить конкретные значения, остальные
  оставить как есть.

Разница между `map` со словарём и `replace`: `map` заменяет **всё**, и то,
чего нет в словаре, теряется; `replace` трогает только перечисленное.

Важное правило производительности: если задачу решает векторная операция
(`df["a"] + df["b"]`, сравнение, метод `.str`), используйте её. `apply` с
функцией Python вызывает её для каждой строки по очереди — на миллионе строк
это заметно медленнее.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "International plan": ["No", "No", "Yes", "Yes"],
        "Voice mail plan": ["Yes", "No", "No", "Yes"],
        "Total day minutes": [265.1, 161.6, 299.4, 166.7],
        "Total eve minutes": [197.4, 195.5, 61.9, 148.3],
    }
)

df["International plan"] = df["International plan"].map({"Yes": 1, "No": 0})
print(df["International plan"].tolist())

print(df["Voice mail plan"].replace({"Yes": "есть"}).tolist())  # «No» не тронут

df["Day level"] = df["Total day minutes"].apply(lambda m: "много" if m > 200 else "мало")
print(df["Day level"].tolist())

# По строкам (axis=1) — работает, но векторно короче и быстрее.
slow = df.apply(lambda row: row["Total day minutes"] + row["Total eve minutes"], axis=1)
fast = df["Total day minutes"] + df["Total eve minutes"]
print((slow == fast).all())
```

### Частые ошибки

- **`map` с неполным словарём.** Значение, которого нет в словаре, станет
  `NaN`. Проверяйте `isna().sum()` после `map` или используйте `replace`.
- **Забыть `axis=1`.** `df.apply(f)` подаёт в функцию столбцы, а не строки, и
  `row["Total day minutes"]` упадёт с `KeyError`.
- **`apply` там, где хватает арифметики.** Сумма, разность, сравнение столбцов
  — векторно, без `apply`.

## Новые и удалённые столбцы

### Главное

Новый столбец создают присваиванием: `df["new"] = выражение`. Выражение —
обычно векторная операция над другими столбцами: длина результата совпадает
с таблицей, и значения встают по индексу.

Несколько столбцов за раз удобно добавлять через `df.assign(new1=…, new2=…)`:
метод возвращает новую таблицу, не меняя исходную.

Удаляют столбцы методом `df.drop(columns=[…])`, строки — `df.drop(index=[…])`.
Как и большинство методов pandas, `drop` возвращает новую таблицу. Переименовать
столбцы — `df.rename(columns={"старое": "новое"})`.

Вычисляемые признаки — первый шаг к машинному обучению: «суммарная плата за
день», «доля ночных звонков», «звонков в поддержку больше трёх» часто
предсказывают отток лучше исходных столбцов.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "Total day calls": [110, 123, 114, 71],
        "Total eve calls": [99, 103, 110, 88],
        "Total night calls": [91, 103, 104, 89],
        "Total day charge": [45.07, 27.47, 41.38, 50.90],
        "Total eve charge": [16.78, 16.62, 10.30, 5.26],
        "Customer service calls": [1, 4, 0, 2],
    }
)

df["Total calls"] = df["Total day calls"] + df["Total eve calls"] + df["Total night calls"]
df = df.assign(
    total_charge=df["Total day charge"] + df["Total eve charge"],
    many_service_calls=df["Customer service calls"] > 3,
)
print(df[["Total calls", "total_charge", "many_service_calls"]])

df = df.drop(columns=["Total day calls", "Total eve calls", "Total night calls"])
df = df.rename(columns={"total_charge": "Total charge"})
print(df.columns.tolist())
```

### Частые ошибки

- **`drop` без присваивания.** `df.drop(columns=["a"])` возвращает новую
  таблицу, а `df` остаётся со столбцом `a`.
- **`drop("a")` без `columns=`.** Без указания оси `drop` ищет **строку** с
  меткой «a» и падает с `KeyError`.
- **Столбец из списка другой длины.** `df["new"] = [1, 2]` для таблицы из
  четырёх строк — `ValueError`. Новый столбец — выражение над столбцами той же
  таблицы.

## Итоги занятия

| Что | Что делает |
|---|---|
| `df.sort_values(by=…, ascending=…)` | сортировка по столбцам, индекс переезжает со строками |
| `df.nlargest(n, "col")` | n строк с наибольшими значениями |
| `s.map(словарь или функция)` | заменить все значения; нет в словаре → `NaN` |
| `s.replace({что: на что})` | заменить только перечисленные значения |
| `s.apply(f)`, `df.apply(f, axis=1)` | функция к элементам / к строкам |
| `df["new"] = …`, `df.assign(…)` | новый столбец |
| `df.drop(columns=[…])`, `df.rename(columns={…})` | удалить, переименовать столбцы |

Векторная операция — первый выбор; `apply` — когда без функции Python не
обойтись.
