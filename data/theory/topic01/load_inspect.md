# Загрузка и первый осмотр

Прежде чем что-то считать, данные нужно загрузить и посмотреть на них: сколько
строк, какие столбцы, какого они типа, где дыры. Это занимает минуту и спасает
от часа отладки.

## Зачем

После занятия вы сможете:

- прочитать таблицу из CSV с нужным разделителем, индексом и набором столбцов;
- за пять вызовов понять, что лежит в таблице: `head`, `shape`, `info`,
  `dtypes`, `columns`;
- найти пропуски и посчитать их по столбцам;
- узнать, сколько в столбце разных значений и какие они.

Во всех примерах — фрагмент данных об оттоке клиентов телеком-оператора из
mlcourse.ai (telecom_churn): штат, тариф, минуты разговоров, звонки в
поддержку и признак ухода `Churn`.

## Чтение таблиц

### Главное

Таблицы чаще всего приходят в формате CSV — текст, где строки разделены
переводом строки, а значения — запятой (или другим символом). Читает его
`pd.read_csv`. Первым аргументом обычно идёт путь к файлу или URL, но подойдёт
и любой «файлоподобный» объект — например, `io.StringIO` со строкой текста.

Самые нужные параметры:

- `sep` — разделитель значений. По умолчанию запятая; в русских выгрузках из
  Excel часто точка с запятой.
- `index_col` — какой столбец сделать индексом строк.
- `usecols` — прочитать только нужные столбцы.
- `nrows` — прочитать только первые строки (удобно для огромных файлов).

Первая строка файла по умолчанию считается заголовком — названиями столбцов.

### Пример

```python
import io

import pandas as pd

csv_text = """State;Account length;International plan;Customer service calls;Churn
KS;128;No;1;False
OH;107;No;4;True
NJ;137;No;0;False
OH;84;Yes;2;False
"""

df = pd.read_csv(io.StringIO(csv_text), sep=";")
print(df.shape)
print(df.columns.tolist())

# Только два столбца, первые три строки.
small = pd.read_csv(
    io.StringIO(csv_text), sep=";", usecols=["State", "Churn"], nrows=3
)
print(small)
```

Логический столбец `Churn` pandas сам распознал: значения `True`/`False`
стали типом `bool`.

### Частые ошибки

- **Не тот разделитель.** Если прочитать файл с `;` без `sep=";"`, вся строка
  попадёт в один столбец с длинным названием `State;Account length;…`.
  Признак — `df.shape[1] == 1`.
- **Заголовок съел первую строку данных.** Если в файле нет строки с
  названиями, укажите `header=None` и задайте имена через `names=[…]`.
- **Читать файл целиком «на пробу».** Для большого файла начните с
  `nrows=1000`: так быстрее понять, правильно ли выбраны параметры.

## head, shape, info, dtypes

### Главное

Первый осмотр таблицы — пять коротких вызовов:

- `df.head(n)` — первые n строк (по умолчанию 5), `df.tail(n)` — последние;
- `df.shape` — размер `(строк, столбцов)`, это атрибут, а не метод;
- `df.columns` — названия столбцов;
- `df.dtypes` — тип каждого столбца;
- `df.info()` — всё сразу: число строк, для каждого столбца число **непустых**
  значений и тип, плюс память.

Типы, которые встретятся чаще всего: `int64` (целые), `float64` (дробные и
целые с пропусками), `bool` (логические), `object` (строки и всё смешанное).
Столбец `object` там, где ждали чисел, — сигнал, что в данных затесался текст
(например, «нет данных» вместо числа).

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "State": ["KS", "OH", "NJ", "OH", "OK"],
        "Account length": [128, 107, 137, 84, 75],
        "Total day minutes": [265.1, 161.6, 243.4, 299.4, 166.7],
        "International plan": ["No", "No", "No", "Yes", "Yes"],
        "Churn": [False, True, False, False, True],
    }
)
print(df.head(2))
print(df.shape)
print(df.dtypes)
df.info()
```

`info()` печатает отчёт сам и возвращает `None`, поэтому его не оборачивают в
`print`.

### Частые ошибки

- **`df.shape()` со скобками.** `shape` — атрибут-кортеж, вызов падает с
  `TypeError: 'tuple' object is not callable`.
- **Смотреть только `head`.** Первые строки часто «чистые», а проблемы — в
  середине файла. `info()` покажет пропуски во всей таблице.
- **Не замечать `object`.** Числовой столбец типа `object` не посчитается
  `mean()` как число. Его приводят к числу — об этом в следующем занятии.

## Пропуски и уникальные значения

### Главное

Пропуск в pandas — это `NaN` (для чисел) или `None`/`NaN` в столбце `object`.
Найти их помогает `isna()`: таблица того же размера из True/False, где True —
пропуск. Дальше работает приём «сумма True = их число»:

- `df.isna().sum()` — число пропусков в каждом столбце;
- `df.isna().mean()` — доля пропусков в каждом столбце;
- `df.isna().any(axis=1)` — есть ли пропуск в строке.

Что делать с пропусками, решают по смыслу данных. Два базовых инструмента:

- `df.dropna()` — убрать строки, где есть хоть один пропуск (с
  `subset=[…]` — пропуск только в указанных столбцах);
- `df.fillna(значение)` — заменить пропуски значением, например медианой.

Второй вопрос первого осмотра — какие значения встречаются в столбце:

- `s.unique()` — массив различных значений в порядке появления;
- `s.nunique()` — их число (пропуски по умолчанию не считаются).

### Пример

```python
import numpy as np
import pandas as pd

df = pd.DataFrame(
    {
        "State": ["KS", "OH", None, "OH", "OK"],
        "Account length": [128, np.nan, 137, 84, 75],
        "Total day minutes": [265.1, 161.6, 243.4, np.nan, np.nan],
        "Churn": [False, True, False, False, True],
    }
)
print(df.isna().sum())          # пропуски по столбцам
print(df.isna().mean().round(2))  # их доли

print(len(df.dropna()))                                   # строки без пропусков
print(len(df.dropna(subset=["Account length"])))          # пропуск только здесь
filled = df["Total day minutes"].fillna(df["Total day minutes"].median())
print(filled.tolist())

print(df["State"].unique())   # различные значения, включая None
print(df["State"].nunique())  # их число без пропуска
```

### Частые ошибки

- **`df.count()` вместо `isna().sum()`.** `count()` считает **непустые**
  значения. Число пропусков — это `len(df) - df.count()`, проще сразу
  `isna().sum()`.
- **Сразу удалять всё через `dropna()`.** Если пропуски разбросаны по разным
  столбцам, можно потерять большую часть таблицы. Сначала посмотрите на
  `isna().mean()`.
- **Путать `unique()` и `nunique()`.** Первый возвращает сами значения (и
  пропуск среди них), второй — их число без пропуска.

## Итоги занятия

| Что | Что делает |
|---|---|
| `pd.read_csv(путь, sep=…, index_col=…, usecols=…, nrows=…)` | читает CSV |
| `df.head(n)`, `df.tail(n)` | первые и последние строки |
| `df.shape` | `(строк, столбцов)` |
| `df.dtypes`, `df.info()` | типы столбцов; сводка с непустыми значениями |
| `df.isna().sum()` | число пропусков по столбцам |
| `df.dropna(subset=…)`, `df.fillna(…)` | убрать или заполнить пропуски |
| `s.unique()`, `s.nunique()` | различные значения и их число |

Порядок первого осмотра: прочитать → `shape` и `head` → `info` → пропуски →
уникальные значения ключевых столбцов.
