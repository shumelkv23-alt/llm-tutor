# Загрузка и первый осмотр

read_csv и первый взгляд на таблицу: head, shape, info, пропуски и уникальные значения.

## Чтение таблиц

### Загрузка данных: read_csv

#### Зачем

Анализ начинается с загрузки таблицы. Чаще всего данные приходят в CSV — текстовом файле, где строки разделены переводом строки, а значения — запятыми. `pd.read_csv` читает такой файл в DataFrame. От его параметров зависит, правильно ли распознаются столбцы, разделители и типы.

#### Главное

- **`pd.read_csv(path)`** принимает путь к файлу, URL или файловый объект и возвращает DataFrame.
- **`sep`** — разделитель. По умолчанию запятая; для TSV пишут `sep="\t"`, для «русского» CSV часто нужен `sep=";"`.
- **`index_col`** — какой столбец сделать индексом строк.
- **`usecols`** — загрузить только нужные столбцы. Это быстрее и экономит память.
- **`dtype`** — задать типы столбцов заранее, например `{"State": "category"}`.
- **`decimal=","`** — если дробная часть отделена запятой.
- Для Excel есть `pd.read_excel`, для JSON — `pd.read_json`. Логика у них та же.
- Сохраняют таблицу обратно методом `df.to_csv(path, index=False)`.

#### Пример

Чтобы пример работал без файла, «файлом» будет строка в памяти (`io.StringIO`):

```python
import io

import pandas as pd

csv_text = """State,Account length,International plan,Churn
KS,128,No,False
OH,107,No,False
NJ,137,No,False
OH,84,Yes,False
OK,75,Yes,True
"""
df = pd.read_csv(io.StringIO(csv_text))
print(df.shape)          # (5, 4)
print(df.dtypes)         # Churn распознан как bool
print(df.head(2))
```

Точка с запятой, десятичная запятая и только нужные столбцы:

```python
import io

import pandas as pd

ru_text = "город;выручка;заказы\nКазань;1520,5;12\nМосква;980,0;7\n"
sales = pd.read_csv(io.StringIO(ru_text), sep=";", decimal=",", usecols=["город", "выручка"])
print(sales)
print(sales["выручка"].sum())   # 2500.5
```

#### Частые ошибки

- **Таблица из одного столбца** со всеми значениями вместе — не тот разделитель. Укажите `sep`.
- **Числа прочитались как текст** (`object`) — мешает десятичная запятая или пробелы в числах. Помогают `decimal=","` и `thousands=" "`.
- **Лишний столбец `Unnamed: 0`** — файл сохранили вместе с индексом. Читайте с `index_col=0` или сохраняйте с `index=False`.

## head, shape, info, dtypes

### Осмотр данных

#### Зачем

Прежде чем что-то считать, нужно понять, что за таблица перед вами: сколько в ней строк и столбцов, какие у столбцов типы, где пропуски. Эти пять минут осмотра экономят часы: ошибку в типе или пропуски лучше найти до анализа, а не после.

#### Главное

- **`df.head(n)`** и **`df.tail(n)`** — первые и последние `n` строк (по умолчанию 5).
- **`df.shape`** — размер таблицы: `(строки, столбцы)`.
- **`df.columns`** — имена столбцов. Пригодятся, чтобы не ошибиться в написании.
- **`df.dtypes`** — тип каждого столбца.
- **`df.info()`** — сводка в одном месте: число строк, тип каждого столбца, число **непустых** значений и объём памяти. Если непустых меньше, чем строк, в столбце есть пропуски.
- **`df.isna().sum()`** — число пропусков по столбцам.
- **`df.sample(n)`** — случайные строки. Помогает не обмануться первыми строками, которые часто бывают «особенными».

#### Пример

```python
import numpy as np
import pandas as pd

df = pd.DataFrame({
    "State": ["KS", "OH", "NJ", "OH", "OK", "AL"],
    "Total day minutes": [265.1, 161.6, 243.4, 299.4, np.nan, 223.4],
    "Customer service calls": [1, 1, 0, 2, 3, 0],
    "Churn": [False, False, False, False, True, False],
})
print(df.shape)          # (6, 4)
print(df.head(3))
df.info()                # у Total day minutes 5 непустых из 6
print(df.isna().sum())   # пропуск — в одном столбце
print(df.dtypes["Churn"])  # bool
```

#### Частые ошибки

- **Делать выводы по `head()`**: первые строки могут быть отсортированы или нетипичны. Посмотрите и `sample`.
- **Писать `print(df.info())`**: `info()` печатает сам и возвращает `None`, поэтому внизу появится лишнее `None`.
- **Не сверять число непустых значений с числом строк.** Пропуски молча меняют средние и доли.
- **Путать `shape` и `size`:** `size` — число ячеек (строки × столбцы), а не строк.
