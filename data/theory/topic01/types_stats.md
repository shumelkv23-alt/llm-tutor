# Типы данных и описательные статистики

Приведение типов, describe и ручные статистики, частоты значений.

## Типы и приведение

### Типы данных и astype

#### Зачем

От типа столбца зависит, какие операции с ним доступны и сколько памяти он занимает. Числа, прочитанные как текст, не сложить. Строки с тремя повторяющимися значениями в миллионе строк впустую расходуют память. Метод `astype` приводит столбец к нужному типу.

#### Главное

- Частые типы: `int64` (целые), `float64` (дробные, умеют хранить `NaN`), `bool`, `object` (обычно строки), `category` (категории), `datetime64[ns]` (даты).
- **`df["col"].astype("int64")`** возвращает столбец нового типа; чтобы сохранить его в таблице, присвойте результат обратно.
- **Категориальный тип** `category` хранит каждое уникальное значение один раз, а в строках — только коды. Для столбцов с небольшим набором значений (штат, тариф) это экономит память и ускоряет группировку. Группируя по такому столбцу, пишите `groupby(..., observed=True)`: иначе в результат попадут и категории, которых нет в данных, а pandas 2.x выдаст предупреждение.
- **`pd.to_numeric(s, errors="coerce")`** превращает текст в числа, а то, что не разбирается, — в `NaN`. Без `errors="coerce"` первая же «плохая» строка вызовет ошибку.
- **`pd.to_datetime`** разбирает даты из строк.
- Булево значение превращают в 0/1 через `astype("int64")`. Это удобно для подсчёта долей и для моделей.

#### Пример

```python
import pandas as pd

df = pd.DataFrame({
    "State": ["KS", "OH", "KS", "OH", "KS"] * 200,
    "Churn": [False, True, False, False, True] * 200,
    "Charge": ["45.07", "27.47", "41.38", "n/a", "28.34"] * 200,
})
print(df.dtypes)                      # State и Charge — object

df["Churn"] = df["Churn"].astype("int64")
print(df["Churn"].unique())           # [0 1]

df["Charge"] = pd.to_numeric(df["Charge"], errors="coerce")
print(df["Charge"].isna().sum())      # 200 — строки "n/a" стали NaN

before = df["State"].memory_usage(deep=True)
df["State"] = df["State"].astype("category")
after = df["State"].memory_usage(deep=True)
print(after < before)                 # True — категории занимают меньше
print(df["State"].cat.categories.tolist())  # ['KS', 'OH']
```

#### Частые ошибки

- **Вызвать `astype` и не присвоить результат.** Таблица останется прежней.
- **Приводить к `int64` столбец с пропусками.** Будет ошибка: `NaN` бывает только у дробных чисел. Сначала заполните пропуски (`fillna`) или используйте тип `"Int64"` с заглавной буквы.
- **Делать `astype(float)` над текстом с запятой** (`"45,07"`). Сначала замените запятую: `s.str.replace(",", ".")`.

## describe и ручные статистики

### Описательные статистики

#### Зачем

Описательные статистики сжимают столбец до нескольких чисел: где центр распределения, какой разброс, есть ли выбросы. С них начинается любое знакомство с признаком. Они же подсказывают, что проверить дальше.

#### Главное

- **`df.describe()`** для числовых столбцов показывает `count`, `mean`, `std`, `min`, квартили `25%`, `50%` (медиана), `75%` и `max`.
- **`df.describe(include=["object", "bool"])`** описывает нечисловые столбцы: число уникальных значений (`unique`), самое частое (`top`) и его частоту (`freq`).
- **Среднее и медиана.** Если среднее заметно больше медианы, справа есть длинный «хвост» (например, у доходов).
- **Квартили:** между `25%` и `75%` лежит половина значений. Их разность — **межквартильный размах**, устойчивая к выбросам мера разброса.
- Отдельные статистики считают методами: `mean()`, `median()`, `std()`, `quantile(0.9)`, `min()`, `max()`.
- **Доля** для булевого столбца — это просто `mean()`: `True` считается за 1, `False` — за 0.

#### Пример

```python
import pandas as pd

df = pd.DataFrame({
    "Total day minutes": [265.1, 161.6, 243.4, 299.4, 166.7, 223.4, 218.2, 157.0],
    "Customer service calls": [1, 1, 0, 2, 3, 0, 3, 0],
    "International plan": ["No", "No", "No", "Yes", "Yes", "No", "No", "Yes"],
    "Churn": [False, False, False, False, True, False, True, False],
})
print(df.describe())
print(df.describe(include=["object", "bool"]))

print(df["Total day minutes"].median())       # 220.8
print(df["Total day minutes"].quantile(0.75))
print(df["Churn"].mean())                     # 0.25 — четверть клиентов ушла
```

#### Частые ошибки

- **Опираться только на среднее.** Один выброс сильно сдвигает среднее, а медиану — нет.
- **Ждать в `describe()` все столбцы.** По умолчанию он берёт только числовые; для остальных нужен `include`.
- **Читать `std` как «типичное отклонение» при сильной асимметрии.** Для таких данных нагляднее квартили.
- **Забывать про пропуски:** `count` в `describe` меньше числа строк, если в столбце есть `NaN`.

## Частоты значений

### Частоты: value_counts

#### Зачем

Для категориальных признаков — штата, тарифа, факта ухода — первый вопрос: «сколько каких значений?». `value_counts` отвечает одной строкой. Так видно, сбалансированы ли классы, есть ли редкие категории и сколько уникальных значений.

#### Главное

- **`s.value_counts()`** возвращает Series «значение → сколько раз», отсортированную по убыванию частоты.
- **`normalize=True`** даёт доли вместо количеств (в сумме 1).
- **`dropna=False`** считает и пропуски как отдельное значение (по умолчанию они не считаются).
- **`sort=False`** сохраняет порядок первого появления, а `.sort_index()` упорядочит по самим значениям.
- **`s.nunique()`** — число уникальных значений, **`s.unique()`** — сами значения.
- У DataFrame тоже есть `value_counts()`: он считает уникальные **сочетания** значений столбцов.

#### Пример

```python
import pandas as pd

churn = pd.Series([False, False, True, False, True, False, False, False], name="Churn")
print(churn.value_counts())                 # False 6, True 2
print(churn.value_counts(normalize=True))   # False 0.75, True 0.25

plan = pd.Series(["No", "No", "Yes", None, "No", "Yes"], name="International plan")
print(plan.value_counts(dropna=False))      # No 3, Yes 2, None 1
print(plan.nunique())                       # 2 — пропуск не считается

df = pd.DataFrame({"plan": ["No", "No", "Yes", "No"], "churn": [False, True, True, False]})
print(df.value_counts())                    # частоты пар (plan, churn)
```

#### Частые ошибки

- **Не проверять баланс классов.** Если ушло 15% клиентов, модель «никто не уходит» угадывает 85% случаев. С этим числом и нужно сравнивать.
- **Терять пропуски:** без `dropna=False` их не видно, хотя пропуск — тоже информация.
- **Сравнивать количества групп разного размера.** Для сравнения долей удобнее `normalize=True`.
