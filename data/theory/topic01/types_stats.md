# Типы данных и описательные статистики

Таблица загружена — теперь нужно, чтобы каждый столбец имел правильный тип, и
получить первые цифры: средние, разброс, частоты. Это основа любого вывода о
данных.

## Зачем

После занятия вы сможете:

- привести столбец к нужному типу и не попасть в ловушку `astype(bool)`;
- получить сводку `describe()` и посчитать нужную статистику руками;
- посчитать частоты значений и их доли через `value_counts`;
- сказать по цифрам, сбалансированы ли классы целевого признака.

## Типы и приведение

### Главное

Тип столбца определяет, что с ним можно делать. Числа складываются и
усредняются, строки — нет. Тип смотрят в `df.dtypes`, а меняют методом
`astype`:

- `df["col"].astype("int64")` — к целому;
- `df["col"].astype("float64")` — к дробному;
- `df["col"].astype("category")` — к категориальному типу: экономит память на
  повторяющихся строках.

`astype` возвращает **новый** столбец, исходный не меняется. Чтобы заменить
столбец в таблице, результат присваивают обратно: `df["col"] = …`.

Строки с числами, где попадаются нечисловые значения («нет данных»), `astype`
не переварит. Для них есть `pd.to_numeric(s, errors="coerce")`: всё, что не
число, станет `NaN`.

Особая ловушка — логический тип. `astype(bool)` превращает в `True` **любую
непустую строку**, в том числе строку `"False"`. Строки «True»/«False» в
логический тип переводят сравнением (`s == "True"`) или словарём через `map`.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "Customer service calls": ["1", "4", "0", "нет данных"],
        "Churn": ["False", "True", "False", "False"],
    }
)
print(df.dtypes)

calls = pd.to_numeric(df["Customer service calls"], errors="coerce")
print(calls.tolist())          # [1.0, 4.0, 0.0, nan]

print(df["Churn"].astype(bool).tolist())  # ловушка: все True
df["Churn"] = df["Churn"] == "True"       # правильно
print(df["Churn"].dtype, df["Churn"].mean())
```

### Частые ошибки

- **`astype(bool)` для строк «True»/«False».** Получится столбец из одних
  `True`, и доля ушедших станет 100%.
- **Забыть присвоить.** `df["col"].astype(int)` без `df["col"] = …` ничего в
  таблице не меняет.
- **`astype(int)` при пропусках.** `NaN` нельзя положить в `int64` — будет
  ошибка. Сначала заполните или удалите пропуски, либо оставьте `float`.

## describe и ручные статистики

### Главное

`df.describe()` для числовых столбцов возвращает сразу восемь чисел: `count`
(непустых), `mean`, `std` (стандартное отклонение), `min`, квартили `25%`,
`50%` (медиана) и `75%`, `max`. Для нечисловых — `describe(include=["object",
"bool"])` покажет число значений, число уникальных, самое частое (`top`) и
его частоту (`freq`).

Любую из этих цифр можно посчитать отдельно: `mean()`, `median()`, `std()`,
`min()`, `max()`, `quantile(0.75)`. Чаще всего так и делают — когда нужна
одна статистика, а не вся сводка, или статистика по части таблицы.

Среднее и медиана отвечают на разные вопросы. Среднее чувствительно к
выбросам: один клиент с огромным счётом сдвигает его заметно. Медиана — это
значение «посередине», выбросы её почти не двигают. Если среднее сильно больше
медианы, в данных есть длинный хвост больших значений.

Стандартное отклонение `std` показывает, насколько типично значения отходят от
среднего. Сравнивать его удобно с самим средним: при среднем 200 минут и
`std` 50 большинство клиентов говорят примерно от 150 до 250 минут в день.
Квартили дают ту же картину без предположений о форме распределения: между
`25%` и `75%` лежит половина всех значений.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "Total day minutes": [265.1, 161.6, 243.4, 299.4, 166.7, 223.4, 218.2, 157.0],
        "Customer service calls": [1, 4, 0, 2, 3, 0, 4, 5],
        "International plan": ["No", "No", "No", "Yes", "Yes", "Yes", "No", "No"],
        "Churn": [False, False, False, False, True, False, True, True],
    }
)
print(df.describe().round(2))
print(df.describe(include=["object", "bool"]))

minutes = df["Total day minutes"]
print(minutes.mean().round(2), minutes.median(), minutes.quantile(0.75))
# Статистика по части таблицы: средние минуты у ушедших клиентов.
print(df.loc[df["Churn"], "Total day minutes"].mean().round(2))
```

### Частые ошибки

- **Ждать в `describe()` все столбцы.** По умолчанию — только числовые.
  Строки и логические — через `include`.
- **Путать `count` и число строк.** `count` в сводке — число непустых
  значений, при пропусках оно меньше `len(df)`.
- **Доверять одному среднему.** При выбросах смотрите и на медиану, и на
  квартили.

## Частоты значений

### Главное

Для категориальных признаков главная статистика — частота каждого значения.
Её считает `value_counts()`:

- `s.value_counts()` — сколько раз встречается каждое значение, по убыванию;
- `s.value_counts(normalize=True)` — доли вместо количеств (в сумме 1);
- `s.value_counts(dropna=False)` — посчитать и пропуски.

Для целевого признака частоты отвечают на важный вопрос: **сбалансированы ли
классы**. В полном датасете оттока из mlcourse.ai ушли 483 клиента из 3333 —
около 14,5%. Модель, которая всем отвечает «не уйдёт», угадает в 85,5%
случаев, хотя не умеет ничего. Это стоит помнить, когда будем оценивать
модели.

### Пример

```python
import pandas as pd

df = pd.DataFrame(
    {
        "International plan": ["No", "No", "No", "Yes", "Yes", "Yes", "No", "No"],
        "Churn": [False, False, False, False, True, False, True, True],
    }
)
print(df["Churn"].value_counts())
print(df["Churn"].value_counts(normalize=True))
print(df["International plan"].value_counts(normalize=True).round(3))
```

### Частые ошибки

- **Ждать порядок по значению.** `value_counts()` сортирует по частоте. Для
  порядка по самим значениям добавьте `.sort_index()`.
- **Делить на `len(df)` руками.** `normalize=True` делает это за вас — и не
  ошибается, когда в столбце есть пропуски (они исключены из подсчёта).
- **Забыть про пропуски.** По умолчанию `value_counts` их не показывает;
  `dropna=False` вернёт их отдельной строкой.

## Итоги занятия

| Что | Что делает |
|---|---|
| `s.astype("int64" / "float64" / "category")` | новый столбец нужного типа |
| `pd.to_numeric(s, errors="coerce")` | строки → числа, нечисловое → `NaN` |
| `s == "True"` или `s.map({...})` | строки «True»/«False» → `bool` |
| `df.describe()`, `describe(include=[…])` | сводка числовых / прочих столбцов |
| `mean`, `median`, `std`, `quantile(q)` | отдельные статистики |
| `s.value_counts(normalize=True)` | доли значений |

Перед выводами: типы правильные, цифры посмотрены и средним, и медианой,
баланс классов известен.
