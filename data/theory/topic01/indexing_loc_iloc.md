# Доступ к данным: loc и iloc

## Зачем

Анализ — это постоянный выбор частей таблицы: нужные строки, нужные столбцы, одна ячейка. В pandas для этого два «окна»: `loc` выбирает **по подписям**, `iloc` — **по позициям**. Если их путать, легко получить не те данные и не заметить ошибку.

## Главное

- **`df.loc[строки, столбцы]`** — выбор по меткам индекса и именам столбцов.
- **`df.iloc[строки, столбцы]`** — выбор по целым номерам позиций, как в списках Python, с нуля.
- **Срезы ведут себя по-разному:**
  - `iloc[0:3]` — позиции 0, 1, 2; правая граница **не входит**, как в Python;
  - `loc["a":"c"]` — от метки `a` до метки `c` **включительно**.
- Вместо строк или столбцов можно передать список (`["age", "city"]`) или булеву маску.
- `df.loc[метка, "столбец"]` возвращает одну ячейку, `df.loc[метка]` — строку в виде Series.
- Через `loc` можно и **присваивать**: `df.loc[маска, "col"] = значение`.

## Пример

```python
import pandas as pd

df = pd.DataFrame(
    {"age": [31, 45, 27, 52], "city": ["Казань", "Москва", "Казань", "Сочи"]},
    index=["a", "b", "c", "d"],
)

print(df.loc["b", "city"])        # Москва — по метке
print(df.iloc[1, 1])              # Москва — по позиции
print(df.loc["a":"c", "age"])     # a, b, c — правая метка входит
print(df.iloc[0:2, 0])            # только a и b — правая позиция не входит
print(df.loc[df["age"] > 30, ["city"]])  # маска строк и список столбцов

df.loc[df["city"] == "Казань", "age"] = 0   # присваивание через loc
print(df)
```

## Частые ошибки

- **Ждать от `loc[0:2]`, что он поведёт себя как `iloc`.** Если индекс — числа 0, 1, 2…, то `loc[0:2]` вернёт **три** строки (метки 0, 1 и 2), а `iloc[0:2]` — две.
- **Присваивать «цепочкой»:** `df[df["age"] > 30]["city"] = "X"` меняет временную копию, а не таблицу (pandas предупредит). Пишите одно обращение: `df.loc[df["age"] > 30, "city"] = "X"`.
- **Передавать в `iloc` имена столбцов.** Он понимает только номера позиций.
