# Массивы NumPy

Первое занятие модуля про данные: считаем не отдельными числами, а массивами.
Разбираем, из чего массив собирается, как читать его форму и оси и как менять
сразу все элементы — без единого `for`.

## Зачем

После занятия вы сможете:

- создать массив нужной формы и прочитать его элемент по двум индексам;
- объяснить разницу между срезом и выборкой по списку индексов;
- назвать форму массива (`shape`) и сказать, что делает `axis=0`, а что
  `axis=1`;
- получить средний цвет по каналам картинки одним вызовом;
- вставить нули между элементами без циклов и без промежуточных списков;
- назвать ловушки: выборка «по парам» вместо таблицы, перепутанные оси,
  отрицательная длина у пустого массива.

## Создание и индексация

### Главное

Массив создаётся из списка — `np.array([[1, 2], [3, 4]])` — и запоминает тип
элементов (`dtype`): у списка чисел это `int64`, у списка с точкой — `float64`.
В отличие от списка, массив умеет индексироваться **двумя** индексами сразу:
`matrix[row, column]`. Та же запись через двоеточия даёт прямоугольник —
`matrix[0:2, 1:3]` — это представление, а не копия.

Отдельный случай — выборка по списку индексов: `matrix[rows, cols]` берёт
**пары** `(rows[0], cols[0])`, `(rows[1], cols[1])` и так далее. Это не
подматрица: чтобы получить таблицу из набора строк и столбцов, нужны две
операции — `matrix[rows][:, cols]`.

`np.array` копирует данные, а `np.asarray` — нет: если массив уже массив,
`asarray` вернёт его же. Поэтому в функциях, которые не должны менять вход,
данные копируют явно.

### Пример

```python
import numpy as np

matrix = np.arange(12).reshape(3, 4)
print(matrix[1, 2])                  # 6 — одна клетка
print(matrix[[0, 2], [1, 3]])        # [ 1 11] — пары (0,1) и (2,3)
print(matrix[0:2, 1:3])              # [[1 2] [5 6]] — прямоугольник
print(np.array([1, 2, 3]) is np.asarray([1, 2, 3]))   # False: список → новый массив
```

### Частые ошибки

- **Путать выборку по парам с подматрицей.** `matrix[[0, 2], [1, 3]]` — это
  два числа, а не таблица 2×2.
- **Индексировать список кортежем.** `[1, 2][0, 1]` — `TypeError`: двойная
  индексация есть только у массива.
- **Думать, что срез копирует.** `matrix[0:2, 1:3]` — вид на те же данные:
  запись в него меняет исходный массив.
- **Смешивать типы.** Массив из целых и дробных чисел станет `float64` целиком;
  `dtype=np.float64` у `np.array([1, 2])` — тоже, хотя числа выглядели целыми.

## Форма и оси

### Главное

`shape` — это длины по осям: у матрицы 3×4 — `(3, 4)`, у цветной картинки —
`(высота, ширина, 3)`. `ndim` — число осей, `size` — сколько всего элементов.
`reshape` меняет форму, не меняя порядок элементов в памяти: тот же плоский
набор читается по-другому.

Ось — это номер измерения в операции. `sum(axis=0)` складывает **вдоль** нулевой
оси: строки схлопываются, остаётся по числу на каждый столбец. `axis=1`
складывает вдоль первой оси — остаётся по числу на каждую строку. У картинки оси
0 и 1 — пространство, поэтому `image.mean(axis=(0, 1))` усредняет пиксели и
оставляет три средних по каналам. Правило простое: у результата та ось, которую
указали, исчезает.

Осей на результат хватает не всегда: `np.unique(matrix, axis=0)` берёт
уникальные строки и сортирует их, а собрать матрицу из двух векторов «в
столбцы» можно `np.stack([first, second], axis=1)` или `np.column_stack` — без
транспонирования и без цикла.

### Пример

```python
import numpy as np

image = np.arange(2 * 3 * 3).reshape(2, 3, 3)
print(image.shape)                   # (2, 3, 3)
print(image.mean(axis=(0, 1)))       # [7.5 8.5 9.5] — средние по трём каналам

matrix = np.arange(12).reshape(3, 4)
print(matrix.sum(axis=0))            # [12 15 18 21] — по столбцам
print(matrix.sum(axis=1))            # [ 6 22 38] — по строкам

first = np.array([1, 2, 3])
second = np.array([4, 5, 6])
print(np.stack([first, second], axis=1))   # [[1 4] [2 5] [3 6]]
```

### Частые ошибки

- **Перепутанные оси.** `mean(axis=0)` у таблицы «усредняет по строкам» только
  на словах: на деле остаётся по одному числу на столбец.
- **Транспонирование там, где нужно reshape.** Для `construct_matrix` из
  задания хватает `np.stack(..., axis=1)`; транспонирование в лаборатории
  запрещено — и справедливо, потому что порядок элементов здесь ни при чём.
- **`np.unique` без `axis`.** Без `axis=0` уникальными станут отдельные числа, а
  не строки: от матрицы останется плоский список.
- **Усреднение всей картинки вместо каналов.** `image.mean()` — одно число;
  «средний цвет» — это `axis=(0, 1)`.

## Вставка нулей

### Главное

Между `n` элементами нужно `n - 1` нулей, то есть массив длины `2n - 1`.
Собирается он в два шага: `np.zeros(2 * n - 1, dtype=x.dtype)` создаёт заготовку,
а `out[::2] = x` раскладывает по чётным позициям исходные числа одним
присваиванием срезу — циклов и списков не нужно. Нечётные позиции остаются
нулями: их можно показать отдельно, `out[1::2]`.

`dtype` при `np.zeros` по умолчанию дробный (`float64`), поэтому его берут у
входа: иначе массив целых превратится в массив дробных. Альтернатива без
арифметики длины — `np.insert(x, np.arange(1, len(x)), 0)` — делает то же самое и
тоже без цикла.

Пустой вход — отдельный случай: `2 * 0 - 1` даёт `-1`, а `np.zeros(-1)` падает с
`ValueError: negative dimensions are not allowed`. Проверка на пустоту нужна до
арифметики, иначе «нулей между элементами» не получится даже нуля.

### Пример

```python
import numpy as np

x = np.array([1, -5, 3])
out = np.zeros(2 * len(x) - 1, dtype=x.dtype)
out[::2] = x
print(out)              # [ 1  0 -5  0  3]
print(out[1::2])        # [0 0] — позиции, которые остались нулями
print(np.insert(x, np.arange(1, len(x)), 0))   # [ 1  0 -5  0  3]
print(2 * 0 - 1)        # -1: у пустого входа длина вышла бы отрицательной
```

### Частые ошибки

- **Собирать результат списком.** `[] + [x[i], 0]` — цикл там, где хватает
  одного присваивания срезу; в задании циклы запрещены.
- **Забыть `dtype`.** `np.zeros(5)` — дробный массив: сравнение с целым
  результатом пройдёт, а тип поедет дальше по вычислениям.
- **Оставить пустой вход без проверки.** `np.zeros(-1)` — исключение, а не
  пустой массив.
- **Шаг в другой позиции.** `out[1::2] = x` поставит числа на нечётные места и
  добавит нули и спереди, и сзади.

## Итоги занятия

| Задача | Инструмент | Что важно |
|---|---|---|
| Элемент и прямоугольник | `matrix[i, j]`, `matrix[0:2, 1:3]` | срез — вид, не копия |
| Выборка по парам индексов | `matrix[rows, cols]` | пары, а не подматрица |
| Свод по оси | `sum(axis=0)`, `mean(axis=(0, 1))` | указанная ось исчезает |
| Уникальные строки | `np.unique(matrix, axis=0)` | строки отсортированы |
| Таблица из векторов | `np.stack([a, b], axis=1)` | без транспонирования |
| Нули между элементами | `out[::2] = x` | длина `2n - 1`, `dtype` от входа |

Правило занятия: массив — это форма плюс тип, а любая операция над ним отвечает
на вопрос «вдоль какой оси». Цикл в numpy почти всегда означает, что нужный
инструмент просто не найден.
