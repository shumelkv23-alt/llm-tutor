# Пропуски в массивах

Второе занятие модуля про данные. Настоящие данные приходят с дырками, и пропуск
в numpy — не «ноль» и не пустое место, а особое число `nan`, которое ведёт себя не
как остальные. Учимся находить его маской и заменять средним, не растеряв числа,
которые уцелели.

## Зачем

После занятия вы сможете:

- объяснить, почему `matrix == np.nan` пропусков не находит, а `np.isnan(matrix)`
  находит;
- читать маску пропусков: сколько их в строке, в столбце, во всей матрице;
- считать среднее по оставшимся числам так, чтобы пропуск его не отравил;
- заменять пропуски средним и отдельно обрабатывать случай «пропусков больше
  нет»;
- назвать ловушки: `nan` внутри целочисленного массива, `np.nanmean` по пустому
  набору, испорченный вход.

## Маска пропусков

### Главное

`nan` (not a number) — это значение типа `float64`, а не отсутствие элемента:
массив с ним сохраняет форму и размер. Особенность у него одна, зато главная:
`nan` не равен сам себе, `np.nan == np.nan` даёт `False`. Значит, **сравнение для
поиска пропусков не годится**: `matrix == np.nan` сравнивает каждое число с
`nan`, то есть повторяет случай `nan == nan`, и результат получается из одних
`False` — независимо от того, сколько пропусков в матрице.

Пропуски находит только `np.isnan(matrix)`: она возвращает булев массив той же
формы, где `True` стоит на месте пропуска. С этой маской работают обычные
операции: `~mask` переворачивает её, `mask.sum()` считает пропуски (при сложении
`True` — это 1), `mask.sum(axis=1)` — по строкам, `mask.any()` отвечает на
вопрос «есть ли хоть один».

### Пример

```python
import numpy as np

matrix = np.array([[np.nan, 1, 2, 3], [4, np.nan, 5, np.nan]])
print(np.isnan(matrix))              # [[ True False False False] [False  True False  True]]
print((matrix == np.nan).any())      # False: сравнение пропусков не видит
mask = np.isnan(matrix)
print(mask.sum(), mask.sum(axis=1))  # 3 [1 2] — всего и по строкам
print(matrix[~mask])                 # [1. 2. 3. 4. 5.] — только числа
```

### Частые ошибки

- **Искать пропуски сравнением с `nan`.** `matrix == np.nan` даёт одни `False` —
  этот способ не работает никогда. Обратное сравнение `matrix != matrix` пропуски
  как раз находит (пропуск не равен сам себе), но читается как опечатка: пишите
  `np.isnan`. И осторожно с контейнерами: `np.nan in [np.nan]` может ответить
  `True` — не потому, что значения равны, а потому что список сначала сравнивает
  элемент с самим собой; на массиве этот фокус не работает.
- **Заводить пропуск в целочисленном массиве.** У массива целых `np.isnan` честно
  вернёт все `False`: хранить пропуск там негде, запись `array[0] = np.nan`
  падает с `ValueError: cannot convert float NaN to integer`. Массив с числами и
  `np.nan` становится дробным целиком.
- **Путать пропуск с нулём.** `np.nan_to_num(matrix)` заменяет `nan` на 0 — это
  тоже ответ, но с другим смыслом: ноль участвует в среднем и тянет его вниз, а
  пропуск в расчёт не идёт.

## Заполнение средним

### Главное

Задача лаборатории: заменить каждый пропуск на среднее арифметическое остальных
элементов, а если пропуски во всей матрице — вернуть нулевую матрицу той же
формы. Тонкость в первом шаге: обычное `matrix.mean()` здесь не подходит — `nan`
отравляет сумму, и среднее выходит `nan`. Считать надо **по числам, которые
остались**: `matrix[~mask].mean()` (то же самое делает `np.nanmean(matrix)`).

Замена — это одна операция `np.where(mask, average, matrix)`: где маска истинна,
берётся среднее, где ложна — исходное значение. `np.where` возвращает новый
массив, а вход остаётся нетронутым. Вариант «на месте» — `matrix[mask] =
average` — меняет данные вызывающего, поэтому его делают на копии.

Случай «все элементы пропуски» проверяют заранее, через `mask.all()`: среднее по
пустому набору не определено, а задание требует нули. Пустая матрица
(`np.array([[]])`) — тот же случай: у пустого массива `all()` возвращает `True`,
и правило выдаёт нулевую матрицу нужной формы — `np.zeros_like(matrix)`.

### Пример

```python
import numpy as np

matrix = np.array([[np.nan, 1, 2, 3], [4, np.nan, 5, np.nan]])
mask = np.isnan(matrix)
print(matrix.mean())                     # nan: пропуск портит сумму
average = matrix[~mask].mean()
print(average)                           # 3.0
print(np.where(mask, average, matrix))   # [[3. 1. 2. 3.] [4. 3. 5. 3.]]
print(matrix[0])                         # [nan  1.  2.  3.] — вход не изменился

filled = np.ones((2, 2)) * np.nan
print(np.isnan(filled).all())            # True: заменять не на что
print(np.zeros_like(filled).shape)       # (2, 2) — форма сохраняется
```

### Частые ошибки

- **Считать среднее вместе с пропусками.** `matrix.mean()` на такой матрице —
  `nan`, и после замены вся матрица станет `nan`. Ошибка коварная: формула
  выглядит верной, а данные в ней уже другие.
- **Забыть про «все пропуски».** Среднее по нулю чисел — снова `nan`, а задание
  требует нули: без проверки `mask.all()` вернётся матрица из `np.nan`.
- **Испортить вход.** `matrix[mask] = average` без предварительной копии правит
  массив вызывающего: следующий расчёт среднего получит уже заполненные данные.
- **`np.nanmean` по пустому набору.** На матрице, где числа есть, она молчит, а
  на всех пропусках выдаёт предупреждение `RuntimeWarning: Mean of empty slice`
  и тот же `nan` — проверка на `mask.all()` нужна в любом случае.
- **`np.array_equal` и пропуски.** Две одинаковые матрицы с `nan` он объявляет
  разными: пропуск не равен сам себе, и функция это честно учитывает
  (`equal_nan=True` меняет ответ). Заполненные матрицы сравнивать можно как
  обычно, а вот «вход не изменился» у матрицы с пропусками проверяют маской:
  `np.isnan(before[0, 0])`.

## Итоги занятия

| Задача | Инструмент | Что важно |
|---|---|---|
| Найти пропуски | `np.isnan(matrix)` | сравнение с `np.nan` их не видит |
| Сосчитать их | `mask.sum()`, `mask.sum(axis=1)` | при сложении `True` — это 1 |
| Взять только числа | `matrix[~mask]` | `~` переворачивает маску |
| Среднее без пропусков | `matrix[~mask].mean()`, `np.nanmean` | `nan` отравляет `mean` |
| Заполнить пропуски | `np.where(mask, average, matrix)` | новый массив, вход цел |
| Все пропуски | `mask.all()`, `np.zeros_like` | среднее по пустому набору не определено |

Правило занятия: пропуск — такое же значение, как остальные, только со своим
характером. Сначала маска, потом всё остальное. В таблицах та же работа выглядит
короче — `isna`, `fillna`, — но устроена так же.
