# Рекурсия и обход словаря

Метрики качества рекламы хранят деревом: сайт, страница, группа пользователей,
клики. Чтобы отправить такое дерево в систему графиков, его разворачивают в
плоский список — «путь через точку, значение». Занятие про две реализации
одной задачи: рекурсивную и итеративную.

## Зачем

После занятия вы сможете:

- написать рекурсивную функцию обхода вложенного словаря: база и шаг;
- собрать путь из ключей через точку, не теряя префикс;
- выбрать между «мутировать переданный список» и «возвращать новый»;
- заменить рекурсию явным стеком и объяснить, зачем;
- назвать цену каждой реализации по времени и памяти и её ограничение.

## Рекурсивный обход

### Главное

Рекурсивная функция — это две части, и обе обязательны:

- **база** — случай, в котором функция не зовёт себя. Здесь: значение не
  словарь, значит это лист дерева, и в результат идёт пара «путь — значение»;
- **шаг** — значение словарь: для каждого ключа функция зовёт себя, добавляя
  ключ к префиксу. Путь собирается как `f"{prefix}.{key}"`, а на верхнем
  уровне — просто `key`: иначе первый ключ получит ведущую точку.

Есть две формы одной и той же рекурсии:

- **с мутацией** — функция получает список `result` и дописывает в него пары,
  сама ничего не возвращая. Лишних копий нет, но вызывающий обязан завести
  список заранее;
- **без мутации** — функция возвращает список пар, собранный из результатов
  вложенных вызовов. Здесь важен способ склейки: `result.extend(...)`
  дописывает в тот же список, а `result + inner` каждый раз создаёт новый —
  на глубоком дереве это лишняя работа пропорционально глубине.

Входной словарь при этом не трогают: `pop`, `del` и присваивание по ключу
меняют данные вызывающего, а обход — операция чтения. Тесты лаборатории
сравнивают вход до и после вызова не случайно.

Ограничение рекурсии — стек вызовов: по умолчанию Python позволяет около
тысячи вложенных вызовов (`sys.getrecursionlimit()`), и на дереве в пять тысяч
уровней рекурсивный обход падает с `RecursionError`.

### Пример

```python
def traverse_dictionary_immutable(dct: dict, prefix: str = "") -> list[tuple[str, int]]:
    """Пары «путь через точку — значение»; входной словарь не меняется."""
    result = []
    for key, value in dct.items():
        path = f"{prefix}.{key}" if prefix else key
        if isinstance(value, dict):
            result.extend(traverse_dictionary_immutable(value, path))
        else:
            result.append((path, value))
    return result


def traverse_dictionary_mutable(
    dct: dict, result: list[tuple[str, int]], prefix: str = ""
) -> None:
    """То же, но пары дописываются в переданный список."""
    for key, value in dct.items():
        path = f"{prefix}.{key}" if prefix else key
        if isinstance(value, dict):
            traverse_dictionary_mutable(value, result, path)
        else:
            result.append((path, value))


data = {"a": 1, "b": {"c": 2, "d": {"e": 4}}, "f": 5}
print(traverse_dictionary_immutable(data))

collected: list[tuple[str, int]] = []
traverse_dictionary_mutable(data, collected)
print(collected)
print(data)                         # входной словарь цел: обход только читает
print(traverse_dictionary_immutable({}))
```

### Частые ошибки

- **Нет базы.** Функция зовёт себя на значении, которое не словарь, и уходит в
  `RecursionError` вместо того, чтобы записать пару.
- **Префикс теряется.** Вложенный вызов без `prefix=path` даёт ключи без
  родительского пути: вместо `b.d` — `d`. И наоборот, `f"{prefix}.{key}"` без
  проверки на пустой префикс даёт ведущую точку в первом ключе.
- **`result + inner` вместо `extend`.** Каждый уровень копирует накопленный
  список; на глубоком дереве это разница в разы, а на очень глубоком —
  заметное время.
- **Мутация входа.** `dct.pop(...)`, `del dct[key]`, `dct[key] = None` внутри
  обхода ломают данные вызывающего — и часто сам обход: менять словарь в цикле
  по нему нельзя.
- **Возврат и мутация одновременно.** Функция, которая и дописывает в
  `result`, и возвращает свой список, оставляет два источника правды;
  выбирайте одну форму.

## Итеративный обход

### Главное

Любую рекурсию можно заменить явным стеком: список пар «узел, префикс». Пока
стек не пуст, берём верхнюю пару, разбираем её словарь и кладём на стек
вложенные словари с их путями; листья сразу уходят в результат.

Что это меняет:

- **глубина больше не ограничена лимитом рекурсии** — стек живёт в куче, а не
  в стеке вызовов, и дерево в сто тысяч уровней обходится без `RecursionError`;
- **порядок обхода другой** — `pop()` берёт последний добавленный узел, и
  пары выходят не в том порядке, что у рекурсивной версии. Тесты сравнивают
  `sorted(result)`, поэтому порядок не проверяется; если он важен, стек
  разбирают с другого конца или сортируют результат;
- **сложность та же** — O(n) по времени на обход всех узлов и O(d) по памяти
  на стек (у рекурсии это стек вызовов, у итерации — список в куче), где d —
  глубина дерева.

Меняется не сложность, а точка отказа: рекурсивная версия падает на глубине,
итеративная — только когда кончится память.

### Пример

```python
def traverse_dictionary_iterative(dct: dict) -> list[tuple[str, int]]:
    """Обход вложенного словаря явным стеком: лимит глубины рекурсии не мешает."""
    result: list[tuple[str, int]] = []
    stack: list[tuple[dict, str]] = [(dct, "")]
    while stack:
        current, prefix = stack.pop()
        for key, value in current.items():
            path = f"{prefix}.{key}" if prefix else key
            if isinstance(value, dict):
                stack.append((value, path))
            else:
                result.append((path, value))
    return result


def deep_dictionary(levels: int) -> dict:
    """Дерево в `levels` уровней: {'0': {'1': {… : 1}}}."""
    root: dict = {}
    node = root
    for index in range(levels):
        child: dict = {}
        node[str(index)] = child
        node = child
    node[str(levels)] = 1
    return root


data = {"a": 1, "b": {"c": 2, "d": {"e": 4}}, "f": 5}
print(sorted(traverse_dictionary_iterative(data)))
print(sorted(traverse_dictionary_iterative({})))

tree = deep_dictionary(5000)
path, value = traverse_dictionary_iterative(tree)[0]
print(value, path.count(".") + 1)   # один лист на глубине 5001
```

### Частые ошибки

- **Стек, из которого забыли достать начальный узел.** Если положить корень и
  не разобрать его, результат пуст, а функция выглядит работающей.
- **Дети кладут без префикса.** `stack.append((value, key))` вместо
  `stack.append((value, path))` теряет путь так же, как в рекурсии.
- **Ожидание того же порядка, что у рекурсии.** Явный стек с `pop()` даёт
  другой порядок пар; сравнение результатов — через `sorted`, а если порядок
  нужен, его задают явно.
- **Стек как «очередь».** `pop(0)` на списке каждый раз сдвигает все элементы
  и превращает O(n) в O(n²) — для очереди есть `collections.deque`.
- **Проверка только на `dict` без мысли о других мапах.** Учебные данные —
  обычные словари; в реальных данных вложенными могут быть и другие
  отображения, и тогда `isinstance` придётся расширить.

## Итоги занятия

| Что | Как | Цена |
|---|---|---|
| Рекурсия с мутацией | `traverse(dct, result)` | O(n), стек вызовов O(d) |
| Рекурсия без мутации | `result.extend(traverse(...))` | O(n), стек вызовов O(d) |
| Склейка через `+` | `result + traverse(...)` | копии на каждом уровне |
| Итерация стеком | `while stack: pop()`, дети в стек | O(n), память O(d) в куче |
| Путь ключа | `f"{prefix}.{key}" if prefix else key` | без ведущей точки |
| Вход | читать, не менять | иначе данные вызывающего испорчены |

Правило занятия: рекурсия — это база плюс шаг, и если шаг забыли про префикс,
дерево развалится на отдельные ключи. Явный стек нужен там, где глубина
дерева превышает лимит рекурсии, и стоит помнить, что порядок обхода при этом
меняется.
