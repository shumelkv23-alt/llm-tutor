# Переобучение и параметры дерева

Дерево без ограничений легко добивается идеальной точности на обучающих
данных — и именно поэтому плохо работает на новых. Занятие объясняет, что
такое переобучение, какими параметрами `DecisionTreeClassifier` его
сдерживают и какие у деревьев сильные и слабые стороны.

## Зачем

После занятия вы сможете:

- распознать переобучение по разрыву между качеством на обучении и на тесте;
- ограничить рост дерева параметрами `max_depth`, `min_samples_leaf` и
  `max_features`;
- построить график зависимости качества от глубины и выбрать разумную глубину;
- назвать достоинства и недостатки деревьев решений.

## Переобучение

### Главное

**Переобучение** — ситуация, когда модель хорошо описывает обучающую выборку,
но плохо работает на новых данных. Дерево, выросшее до одного объекта в
каждом листе, запоминает не закономерность, а шум и частные случаи: «клиент
№ 137 с 213 минутами ушёл». На новых клиентах такие правила не срабатывают.

Признак переобучения — **разрыв**: точность на обучающей выборке близка к 100%,
а на тестовой заметно ниже. Противоположная проблема — **недообучение**: модель
слишком проста (скажем, дерево глубины 1) и плохо работает и на обучении, и на
тесте.

Сложность дерева регулируется его размером, и поиск золотой середины —
центральная задача настройки. Качество на тесте при росте сложности обычно
сначала растёт, потом падает; лучшая сложность — у вершины.

### Пример

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(6)
X = rng.normal(size=(600, 5))
y = (X[:, 0] + 0.5 * X[:, 1] + rng.normal(0, 1.0, 600) > 0).astype(int)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17
)

for depth in (1, 3, 5, 10, None):
    tree = DecisionTreeClassifier(max_depth=depth, random_state=17).fit(X_train, y_train)
    print(depth, "обучение", round(tree.score(X_train, y_train), 3),
          "тест", round(tree.score(X_test, y_test), 3))
```

### Частые ошибки

- **Оценивать дерево по обучающей выборке.** Глубокое дерево всегда выглядит
  отлично на данных, на которых его вырастили.
- **Считать более сложную модель более точной.** Точность на новых данных
  растёт лишь до определённого предела.
- **Бороться с переобучением ростом дерева.** Чтобы его уменьшить, дерево
  ограничивают, а не растят до чистых листьев.

## Параметры DecisionTreeClassifier

### Главное

Основные параметры, ограничивающие дерево:

- `max_depth` — максимальная глубина дерева;
- `min_samples_leaf` — минимальное число объектов в листе: дерево не создаст
  лист, на котором держится слишком мало данных;
- `min_samples_split` — минимальное число объектов в узле, чтобы делить его
  дальше;
- `max_features` — сколько признаков перебирать при поиске лучшего разбиения
  (число, доля или `"sqrt"`);
- `criterion` — `"gini"` или `"entropy"`.

Эти параметры — **гиперпараметры**: их задаёт человек до обучения, модель
сама их не подбирает. Лучшие значения ищут на отложенной выборке или
кросс-валидации (в полном курсе mlcourse.ai ей отведено отдельное занятие). Типичная практика — построить кривую
качества по значению параметра и выбрать точку, где качество на проверке
максимально.

Грубое правило: чем сильнее ограничение (меньшая глубина, большее
`min_samples_leaf`), тем проще дерево и тем меньше оно склонно к переобучению,
но тем выше риск недообучения.

### Пример

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(7)
X = rng.normal(size=(800, 6))
y = (X[:, 0] - X[:, 2] + rng.normal(0, 1.2, 800) > 0).astype(int)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=17
)

best = None
for depth in range(1, 11):
    tree = DecisionTreeClassifier(max_depth=depth, min_samples_leaf=5, random_state=17)
    score = tree.fit(X_train, y_train).score(X_test, y_test)
    if best is None or score > best[1]:
        best = (depth, score)
print("лучшая глубина:", best[0], "точность", round(best[1], 3))

limited = DecisionTreeClassifier(max_depth=4, min_samples_leaf=20, max_features=3,
                                 random_state=17).fit(X_train, y_train)
print(limited.get_depth(), limited.get_n_leaves())
```

### Частые ошибки

- **Подбирать гиперпараметры по тестовой выборке и там же оценивать итог.**
  Тест перестаёт быть независимым; подбирайте на кросс-валидации.
- **Менять только `max_depth`.** Часто полезнее `min_samples_leaf`: он
  защищает от листьев из пары объектов.
- **Путать `max_features` с числом признаков в модели.** Параметр только
  ограничивает перебор на каждом узле; в разных узлах могут быть разные
  признаки.

## Плюсы и минусы деревьев

### Главное

**Достоинства.** Дерево легко **интерпретировать**: правила можно прочитать и
объяснить. Оно работает и с числовыми, и с категориальными признаками, не
требует масштабирования, быстро обучается и предсказывает.

**Недостатки.**

- **Неустойчивость.** Небольшое изменение данных может сильно изменить
  дерево, потому что ранние разбиения определяют всё остальное.
- **Переобучение** без ограничений.
- **Ступенчатая граница.** Разделяющая поверхность состоит из отрезков,
  перпендикулярных осям; наклонные границы дерево приближает «лесенкой».
- **Нет экстраполяции.** За пределами области обучающих данных дерево
  возвращает константу, как в ближайшей крайней области.

Неустойчивость и склонность к переобучению — главный повод для ансамблей
деревьев (случайный лес), которым посвящены следующие занятия этого модуля.

### Пример

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor

rng = np.random.default_rng(8)
X = rng.normal(size=(150, 2))
y = (X[:, 0] + X[:, 1] + rng.normal(0, 0.5, 150) > 0).astype(int)

# Неустойчивость: корень дерева на разных подвыборках из 100 объектов.
for seed in range(5):
    idx = np.random.default_rng(seed).choice(150, size=100, replace=False)
    tree = DecisionTreeClassifier(max_depth=1, random_state=0).fit(X[idx], y[idx])
    print("подвыборка", seed, "- признак", int(tree.tree_.feature[0]),
          "порог", round(float(tree.tree_.threshold[0]), 2))

# Нет экстраполяции: далеко за пределами данных прогноз не меняется.
line_x = np.arange(0, 20).reshape(-1, 1)
line_y = 2.0 * line_x.ravel()
model = DecisionTreeRegressor(max_depth=5, random_state=0).fit(line_x, line_y)
print(model.predict([[19], [100], [1000]]))
```

### Частые ошибки

- **Ждать, что дерево продолжит тренд.** Для данных, выходящих за пределы
  обучающих, оно вернёт значение крайнего листа.
- **Полагаться на одно дерево.** Его структура зависит от случайностей в
  данных; для надёжности используют ансамбли.
- **Считать интерпретируемость бесплатной.** Дерево глубины 20 уже нельзя
  прочитать, его правила бесполезны для объяснения.

## Итоги занятия

| Что | Что делает |
|---|---|
| переобучение | высокая точность на обучении, низкая на тесте |
| `max_depth` | максимальная глубина |
| `min_samples_leaf`, `min_samples_split` | минимальный размер листа и узла для деления |
| `max_features` | сколько признаков перебирать на каждом узле |
| `tree.get_depth()`, `tree.get_n_leaves()` | размер обученного дерева |

Дерево: легко объяснить, быстро обучается, не требует масштабирования; но
неустойчиво, склонно к переобучению и не экстраполирует.
