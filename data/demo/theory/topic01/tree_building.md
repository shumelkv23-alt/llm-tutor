# Как строится дерево

Прошлое занятие объяснило, чем измеряют качество разбиения. Теперь соберём
алгоритм: как дерево растёт шаг за шагом, какие пороги оно проверяет для
числового признака и как та же идея работает, когда нужно предсказывать число,
а не класс.

## Зачем

После занятия вы сможете:

- описать жадный алгоритм построения дерева и объяснить, почему он не
  гарантирует лучшее дерево;
- найти кандидатов в пороги для числового признака и выбрать лучший;
- объяснить, как устроено дерево регрессии и почему его прогноз — «лесенка»;
- обучить `DecisionTreeRegressor` и посмотреть на его ступеньки.

## Жадное построение

### Главное

Алгоритмы ID3 и C4.5 строят дерево **жадно** (рекурсивно):

1. Для текущей группы объектов перебрать все признаки и все возможные
   пороги.
2. Выбрать разбиение с наибольшим приростом информации (или другого критерия).
3. Разделить группу на две части и повторить шаги 1–2 для каждой.
4. Остановиться, когда сработало условие остановки: группа «чистая»,
   достигнута максимальная глубина, в группе слишком мало объектов.

«Жадно» значит: на каждом шаге берётся лучшее разбиение **сейчас**, без
заглядывания вперёд. Такой алгоритм быстр, но не гарантирует глобально
лучшее дерево: поиск оптимального дерева — NP-полная задача, и жадный
алгоритм — эвристика. Иногда слабое разбиение сегодня открывает отличное
завтра, а жадный алгоритм этого не увидит.

Если не остановить рост, дерево дойдёт до листьев с одним объектом и
идеально запомнит обучающую выборку — в следующем занятии мы увидим, чем это
плохо.

### Пример

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(4)
X = rng.normal(size=(200, 3))
y = ((X[:, 0] > 0) & (X[:, 1] > 0)).astype(int)   # правило из двух условий

for depth in (1, 2, 3):
    tree = DecisionTreeClassifier(max_depth=depth, random_state=0).fit(X, y)
    print(depth, "глубина,", tree.get_n_leaves(), "листьев, точность",
          round(tree.score(X, y), 3))

tree = DecisionTreeClassifier(max_depth=2, random_state=0).fit(X, y)
print("корень разбивает по признаку", tree.tree_.feature[0],
      "при пороге", round(float(tree.tree_.threshold[0]), 2))
```

### Частые ошибки

- **Думать, что дерево нашло лучшее из всех возможных.** Оно нашло лучшее по
  жадному правилу, а оптимум глобальный может быть другим.
- **Не ограничивать рост.** Без условий остановки дерево растёт до чистых
  листьев.
- **Принимать порядок вопросов за важность.** Корневой признак — лучший для
  разбиения всех данных сразу, но это не весь вклад признака.

## Пороги по количественному признаку

### Главное

Для категориального признака вариантов разбиения немного. Для числового
порогов бесконечно много, но проверять нужно не все. Алгоритм сортирует
значения признака и рассматривает только **середины между соседними
значениями, где меняется класс**. Если подряд идут возраст 38 (класс 1) и
49 (класс 0), кандидатом будет порог (38 + 49) / 2 = 43,5. Между двумя
соседними значениями одного класса порог не нужен: он не может улучшить
разбиение.

Для каждого кандидата считается прирост информации; побеждает порог с
наибольшим. Так что на числовом признаке дерево задаёт вопросы вида
«признак ≤ порог?».

Этот перебор объясняет два свойства. Во-первых, дерево не требует
масштабирования признаков: порог сравнивается с самим признаком, и единицы
измерения не важны. Во-вторых, граница между классами состоит из отрезков,
параллельных осям координат.

### Пример

```python
import numpy as np

ages = np.array([22, 25, 31, 38, 49, 53, 60])
churn = np.array([0, 0, 0, 1, 0, 1, 1])


def entropy(labels):
    if len(labels) == 0:
        return 0.0
    p = np.bincount(labels) / len(labels)
    p = p[p > 0]
    return float((p * np.log2(1 / p)).sum())


order = np.argsort(ages)
ages, churn = ages[order], churn[order]
candidates = [
    float(ages[i] + ages[i + 1]) / 2 for i in range(len(ages) - 1) if churn[i] != churn[i + 1]
]
print("кандидаты:", candidates)

for threshold in candidates:
    left, right = churn[ages <= threshold], churn[ages > threshold]
    gain = entropy(churn) - (len(left) * entropy(left) + len(right) * entropy(right)) / len(churn)
    print(threshold, round(gain, 3))
```

### Частые ошибки

- **Перебирать пороги между одинаковыми классами.** Это пустая работа: такой
  порог не уменьшит неопределённость.
- **Масштабировать признаки перед деревом «на всякий случай».** Дереву это не
  нужно (kNN — другое дело).
- **Ждать наклонных границ.** Дерево делит пространство вдоль осей; наклонную
  прямую оно приближает «лесенкой».

## Дерево для регрессии

### Главное

Когда целевая переменная — число, дерево строится по той же схеме, но меняются
две вещи. Критерий качества разбиения — не энтропия, а **дисперсия**
целевой переменной в листе: разбиение хорошо, если внутри каждой части
значения близки друг к другу. А ответ в листе — не самый частый класс, а
**среднее** целевой по объектам листа.

Отсюда вид прогноза: функция признака, которая **постоянна на каждом
интервале** — график похож на ступеньки. Чем глубже дерево, тем больше
ступенек и тем точнее оно подгоняется к обучающим данным. Слишком глубокое
дерево начнёт повторять шум.

В scikit-learn дерево регрессии — `DecisionTreeRegressor`; обучение и
прогноз те же: `fit`, `predict`. Качество измеряют, например, средней
квадратичной ошибкой.

### Пример

```python
import numpy as np
from sklearn.metrics import mean_squared_error
from sklearn.tree import DecisionTreeRegressor

rng = np.random.default_rng(5)
x = np.sort(rng.uniform(0, 10, 80)).reshape(-1, 1)
y = np.sin(x).ravel() + rng.normal(0, 0.2, 80)

for depth in (1, 3, 8):
    model = DecisionTreeRegressor(max_depth=depth, random_state=0).fit(x, y)
    steps = len(np.unique(model.predict(x)))
    print(depth, "глубина:", steps, "ступенек, MSE",
          round(mean_squared_error(y, model.predict(x)), 3))
```

### Частые ошибки

- **Ждать гладкой кривой.** Дерево даёт кусочно-постоянную функцию; для
  плавных зависимостей лучше подходят другие модели.
- **Радоваться нулевой ошибке на обучении.** Очень глубокое дерево повторяет
  шум; проверяйте на отложенных данных.
- **Применять критерий классификации к числам.** Для регрессии нужен критерий
  по дисперсии (в scikit-learn — `criterion="squared_error"`, он по умолчанию).

## Итоги занятия

| Что | Что делает |
|---|---|
| жадный алгоритм | на каждом шаге берёт лучшее разбиение «сейчас», не гарантирует оптимум |
| кандидаты в пороги | середины между соседними значениями, где меняется класс |
| `tree.tree_.feature[0]`, `tree.tree_.threshold[0]` | признак и порог в корне обученного дерева |
| дисперсия в листе | критерий разбиения для регрессии |
| `DecisionTreeRegressor(max_depth=…)` | дерево регрессии, прогноз — среднее в листе |

Порядок работы: перебрать признаки и пороги → выбрать лучшее разбиение →
повторить в частях → остановиться по условию.
