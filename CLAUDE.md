# llm_tutor

Веб-приложение — тьютор по курсу mlcourse.ai: 5 модулей в одном графе, от
Pandas/EDA до бэггинга и случайного леса (модули 6–10 не написаны). Несколько
учеников со входом; у каждого ученика своя БД на курс (`user_id` в схеме курса
нет — ученика задаёт файл БД). Курс в вебе один — `mlcourse` (прежний id
`mlcourse-topic01` переадресуется, его БД и записи на курс переносятся).

**Главный принцип:** LLM — интерфейс и генератор текста, а не источник истины.
Состояние ученика, вердикты по заданиям, закрытие узлов считает код; журнал
`events` — источник истины.

## Стек и запуск

Python 3.12, FastAPI + Jinja2 (JS и CSS без сборки), OpenRouter (httpx),
SQLite + FTS5, NetworkX, pydantic 2, менеджер — `uv`. Код ученика выполняется в
браузере: Pyodide в Web Worker, редактор CodeMirror 5 (лежит в `static/vendor`).
Секреты — `.env` (шаблон `.env.example`).

```bash
uv sync
uv run pytest -q                       # весь набор без браузера, ~30 с
uv run pytest -q -m e2e tests/e2e      # Playwright; Pyodide — из E2E_PYODIDE_DIR
uv run python -m llm_tutor.web         # http://127.0.0.1:8000
```

| `core/` | `turn` (ход: ответ на задание / тьютор, вход в узел, закрытие, переход между модулями), `guided` (урок по частям, «ответ или реплика»), `verify` (проверочный проход), `lesson` (статусы тем, переход, анкета модуля, начало урока), `overview`, `context` (пакет промпта), `intents` |

| `course/`, `rag/`, `grader/`, `llm/`, `db/` | граф и seed (`load_course` — все модули), поиск по материалам, автопроверка и рубрики, клиент и промпты, репозитории |

Данные: `data/seed_topicNN.json` — по файлу на модуль (граф тем, банк заданий,
анкета модуля в разделе `topic`); всего 103 темы и 264 задания, задания с
кодом несут `starter`/`setup`/`tests` и рубрику. `data/theory/topicNN/*.md` —
конспекты тем (пока только модуль 1). Тестовые курсы из двух модулей —
`tests/course_fixtures.py`. Открытые находки ревью — `problems.md`.

## Процесс

Брейншторм → спека → план → реализация срезами по TDD → **адверсариальное
ревью каждого среза отдельным агентом** (находки воспроизводятся запуском
кода, ревьюер ничего не правит) → триаж → фиксы отдельным коммитом с
регрессионными тестами.

## Конвенции

- Комментарии, докстринги и коммиты пишутся по-русски. Формат коммита: `Срез N: …`,
  `Аудит среза N: …`.
- Слои: `web → core/student/db`. `core/*` и `student/*` не импортируют `web/*`.
- Вывод: `core.*` отдаёт **сырой** текст (Markdown). В веб он попадает через
  `web.markdown.render` (HTML запрещён, ссылки только http(s)) или как
  `textContent` в JS. `innerHTML` — только для HTML, отрендеренного сервером.
- CSP без `unsafe-inline`: никаких встроенных `<script>` и `style=""`; ширины и
  проценты ставит JS через CSSOM. Новые внешние адреса — только через
  `content_security_policy`.
- Схема БД меняется только миграциями (`migrations/` — БД ученика,
  `migrations_accounts/` — аккаунты). Новые поля состояния кладутся в
  `SessionState` (JSON) с дефолтами.
- Тесты асинхронные без декоратора (`asyncio_mode=auto`). Веб — через
  фикстуры `web`/`student` (`tests/conftest.py`), подставной тьютор — в
  `tests/web_fakes.py`. Браузерные — с маркером `e2e`, шаги в `tests/e2e/helpers.py`.

## Подводные камни

- **Атомарность хода** держится на `asyncio.Lock` ученика (`userdb`): всё
  внутри `async with ctx.lock` выполняется без чужих ходов этого ученика.
  Замок живёт в процессе — запускать один воркер uvicorn.
- Подпись `"Уверенно"` в `student/survey.SELF_LEVELS` **не менять**. По ней
  узлы получают статус маршрута `claimed` (🔍): знакомое по анкете, его
  проверяют в конце.
- SQLite в вебе открывается с `check_same_thread=False`: соединение из пула
  используется не в том потоке, где открыто.
- Тёмные токены в `tokens.css` записаны дважды (выбранная тема и системная) —
  правятся парно, `tests/test_audit_48.py` сверяет копии.
- Windows: вставка многострочного Python через heredoc в stdin путает `\n` в
  строковых литералах. Точечные правки делай инструментом Edit.
- Агента типа `fork` в окружении может не быть. Тогда ревью делает
  `general-purpose` с самодостаточным ТЗ.
- **Модули грузятся только вместе** — через `load_course` (в вебе — `courses.course_data` + `apply_course`). `load_seed` берёт
  один файл как весь курс и гасит остальные модули.
- **Межмодульные рёбра — только назад** (от прошлого модуля к следующему),
  иначе `CourseGraphError`. Жёсткое межмодульное ребро валидно, но `seed`
  печатает о нём предупреждение — обосновывай в коммите.
- Урок по частям (срез 28): вход в тему — части объяснения и кнопка
  «Дальше»/«Проверим», задание — после последней части. В вебе кнопку рисует
  `state.lesson_button` (из `SessionState`, переживает перезагрузку), ход —
  `POST /lesson/next`.
  Тему закрывает один верный ответ; вторая ошибка — тема закрывается слабой (⚠️).
- `core/guided` не импортирует `core/turn`, а `core/lesson` импортирует: иначе
  цикл импорта.
- Дистрактор, который что-то утверждает о поведении библиотеки, проверяй
  запуском (`uv run --with numpy,pandas,scikit-learn python <скрипт>`): трижды
  «ложный» вариант оказывался верным (3046, 4037, 5029/5044).
- Тесты не должны зависеть от `.env`: передавай фикстуру `settings` во всё, что
  иначе зовёт `get_settings()`.
