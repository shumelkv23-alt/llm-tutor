# Конспект: определения и пояснения, свои заметки, выполненные задания

## Задача

Страница «Конспект» (`/notes`) сейчас делит записи по типу носителя:
«Вопросы тьютору» / «Мои решения» и фильтр «Текст / Код». Ученику нужен
учебный конспект, а не архив переписки: пояснения к разобранным вопросам,
**своя заметка рядом** и выполненные задания в виде «условие сверху — мой
ответ или код снизу».

## Решения

1. **Две ленты вместо двух лент с фильтром типа.**
   - «Определения и пояснения» — вопросы, которые ученик задал тьютору
     (`?view=questions`, по умолчанию), с выделенным фрагментом, полным
     ответом и личной заметкой. Записи внутри занятия сгруппированы по
     **разделам** занятия (порядок разделов — по последнему вопросу).
   - «Выполненные задания» — ответы на задания (`?view=solutions`):
     условие задания целиком, ниже ответ ученика или его код и вердикт.
   - Фильтр `?kind=text|code` убирается: тип виден по самой записи, а ленты
     уже разделяют вопросы и решения.
2. **Личная заметка ученика** к записи конспекта (к вопросу тьютору).
   - Пишется и правится на странице без перезагрузки; пустая заметка
     удаляет запись.
   - Автоитог тьютора «Что вы узнали» со страницы убирается: заметка теперь
     своя. Поле `takeaway` остаётся в журнале (историю не переписываем), но
     страница его не показывает.
3. **Условие задания — целиком**, отрендеренное тем же `web.markdown.render`,
   что и в занятии (таблицы, код, ссылки — безопасно). Обрезка до 200 знаков
   (`_prompt_preview`) больше не нужна.
4. **Показываются все решения, а не только верные**: вердикт («Верно»,
   «Неверно», процент) стоит рядом, ошибки тоже полезны для повторения.
5. Названия и пустые состояния страницы говорят на языке ученика:
   «Определения и пояснения», «Выполненные задания», «Моя заметка».
6. **Код в «Определениях и пояснениях» не показывается.**
   - Вопрос с выделенным кодом (источник фрагмента «Код») в ленту не
     попадает: разбор кода — не определение.
   - Вопрос с длинной вставкой кода в самом тексте (огороженный блок больше
     `notes.MAX_CODE_LINES = 3` непустых строк) тоже не попадает: ученик
     вставил функцию и просит её проверить — это разбор кода.
   - Мелкий код (до трёх строк и внутристрочный) допускается.
   - В ответе тьютора длинные блоки кода сворачиваются под спойлер
     «Показать код»; текст пояснения остаётся видимым.
   - Из ленты записи не удаляются: в истории чата занятия они остаются.
7. **Поиск по конспекту** — `?q=` на странице. Ищет по вопросу, выделенному
   фрагменту, ответу тьютора и личной заметке (в «Выполненных заданиях» — по
   условию и ответу/коду ученика). Нужны все слова запроса, регистр не важен.
   Поиск идёт по выбранной ленте и фильтрам курса/темы; лимит считается после
   отбора.
8. **Структура записи:** курс → занятие (модуль подписью) → раздел занятия →
   записи от новых к старым. У раздела — заголовок `h4`, у вопроса — `h5`.

## Данные заметки

Новая таблица в БД ученика по курсу — миграция `011_notes.sql`:

```sql
CREATE TABLE IF NOT EXISTS note_entries (
  message_id INTEGER PRIMARY KEY REFERENCES messages(id) ON DELETE CASCADE,
  text       TEXT NOT NULL,
  updated_at REAL NOT NULL
);
```

- Заметка привязана к записи конспекта — реплике-вопросу ученика
  (`messages.meta.question = true`). Чужая реплика (ответ, команда,
  реплика тьютора) адресом заметки не становится: API отвечает 404.
- Пустой текст удаляет строку; правка — upsert по `message_id`.
- Предел — `notes.NOTE_MAX_CHARS = 2000` знаков; края обрезаются.
- Заметка хранится и показывается **как текст** (переносы строк сохраняются,
  HTML экранируется): Markdown в личных заметках не рендерится.

## API

`PUT /api/courses/{course_id}/notes/{message_id}` с телом `{"text": "…"}`.

- Только записанный ученик и существующий курс — та же зависимость
  `lesson_context`, что у ходов занятия (403 / 404 / 503).
- Ответ: `{"text": "<сохранённый текст>"}`; удаление — `{"text": ""}`.
- 404 — записи нет или это не вопрос; 422 — текст длиннее предела.
- Запись идёт под замком ученика (`lesson_context.lock`), как ходы.

## Интерфейс

- Переключатель лент: «Определения и пояснения» / «Выполненные задания».
- Строка поиска (GET-форма) с кнопкой «Найти» и «Сбросить»; запрос
  сохраняется в чипах курса/темы и в переключателе лент.
- Пустая выдача поиска — «По запросу «…» ничего не найдено» и сброс.
- Вопрос: время, источник фрагмента («Теория» / «Задание»), заголовок
  раздела, фрагмент, вопрос-заголовок, блок «Моя заметка» (кнопка «Добавить
  заметку» / «Изменить»), свёрнутый «Полный ответ»; длинный код в ответе —
  под спойлером «Показать код».
- Блок заметки: сохранённый текст (или пусто), по кнопке — `textarea`,
  «Сохранить» / «Отмена», статус ошибки. Без JS форма скрыта: страница
  остаётся читаемой, править заметку нельзя.
- Задание: время, вердикт, условие (`prompt_html`), код или текстовый ответ,
  отчёт проверки у кода.
- JS — один файл `static/js/notes.js`, только `textContent` и `App.request`;
  CSP не меняется, встроенных скриптов и стилей нет.
- Стили — `notes.css`, цвета только из токенов.

## Что не входит

- Разбор кода в конспекте: вопросы с кодом остаются только в истории чата и
  в ленту определений не попадают.
- Заметки к занятиям без вопроса и к выполненным заданиям — только к записи
  конспекта (вопросу тьютору).
- Рендер Markdown в заметке, теги, подсветка найденного, отдельный поисковый
  индекс: поиск идёт по уже загруженным записям (лимиты `NOTE_LIMIT` /
  `SOLUTION_LIMIT`).
- Правка старых записей и удаление самих записей конспекта.
- Показ автоитога тьютора (`takeaway`) — данные остаются, страница их не
  выводит.

## Тесты

- Миграция: таблица `note_entries` есть, `SCHEMA_VERSION` = 11.
- `notes.save_note`: создаёт, правит (upsert), удаляет пустой, обрезает края,
  отклоняет не-вопрос и слишком длинный текст.
- `notes.question_entries` отдаёт заметку вместе с записью; страница
  показывает сохранённый текст и экранирует HTML.
- API: сохранение и удаление, 404 на не-вопрос, 422 на длинный текст,
  запись без входа и на чужой курс недоступна.
- Ленты: «Определения и пояснения» / «Выполненные задания»; фильтра
  «Текст / Код» нет; старые ссылки с `?kind=` страницу не ломают.
- Вопрос с выделенным кодом и с длинной вставкой кода в тексте в
  «Определениях и пояснениях» не показывается; мелкий код не мешает.
- Длинный код в ответе тьютора свёрнут под «Показать код», мелкий — нет.
- Поиск: находит по вопросу, ответу и заметке; в заданиях — по условию и
  ответу; нужны все слова, регистр не важен; пустая выдача — подсказка и
  сброс; запрос сохраняется в чипах.
- Записи занятия сгруппированы по разделам, порядок — по новому входу.
- Условие задания показывается целиком и отрендеренным, а не обрезанным.
- Ошибочное решение и его вердикт видны.
