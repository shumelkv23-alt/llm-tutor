## Срез 74 — данные графа

**Files:** `web/api_lesson.py`, `web/views.py`, `tests/test_web_graph.py`

- [x] `views.graph_view(conn, settings)`: узлы из `topic_rows` (статус, слабое,
      владение %, `confident`, модуль), связи графа курса, модули, текущее
      занятие, пройдена ли анкета, висит ли задание.
- [x] `GET /api/courses/{id}/graph` через `lesson_context`: 403 без записи,
      404 неизвестный курс, сессию не заводит.
- [x] Тесты: форма ответа, статусы после закрытия занятия, слабое, рёбра
      совпадают с графом, нет узлов неопубликованных модулей, чтение не
      открывает сессию.

**Files:** `templates/profile.html`, `static/js/knowledge-graph.js`,

- [x] Карточка занятия и «Перейти к занятию» (`/lesson/switch`, подтверждение
      при висящем задании, затем `/lesson/{id}`).

      на 390 px.
