# План: личный конспект ученика (вопросы тьютору)

Спека — `docs/superpowers/specs/2026-11-20-notebook-design.md`.

## Срез 1. Разметка вопросов в журнале

- `core/turn.post_turn(..., question: bool = False)`: в `meta` реплики ученика —
  `{"question": true, "node": …, "section": …}`. Занятие — `review_node_id` или
  `state.current_node_id`; раздел — `state.section_id` (только для урока, не
  повторения). Пустой текст ученика не помечается.
- `core.turn.handle_turn`: общий `post_turn` получает `question=not is_answer or
  force_stuck` — тьюторская ветка и «не понял»; ответ на задание — нет.
- `core.review.chat`: `question=True` (занятие уже в `review_node_id`).
- Тесты: `tests/test_notes.py` — мета вопроса и отсутствие меты у ответа.

## Срез 2. Сборка конспекта

- `web/notes.py`:
  - `question_entries(conn)` — вопросы из `messages` + следующий ответ
    `assistant`; фрагмент через `core.context.focus_from_meta`; ответ через
    `web.markdown.render`; лимит `NOTE_LIMIT`;
  - `lesson_notes(conn)` — группировка по занятию, имя занятия/модуль из
    `CourseGraph` и `repos.get_topics`, название раздела из `Concept.sections`.
- Тесты: разбор меты, ответ, фрагмент, занятие, пустой курс.

## Срез 3. Страница «Конспект»

- `pages.py`: `NavItem("notes", "/notes", "Конспект", "note")` и
  `GET /notes` (фильтр `?course=`), данные по курсам ученика.
- `templates/notes.html`: фильтр курсов, панели курсов, занятия, записи;
  ответ — `<details>`.
- `static/css/notes.css`, иконка `note` в спрайте.
- Тесты: страница с вопросом и фрагментом, группировка и порядок, фильтр,
  скрытие ответов/объяснений/проекта, гость, экранирование HTML, спрайт.

## Срез 4. Документы

- `CLAUDE.md`: строка «Конспект» в таблице слоёв и раздел про пометку вопросов.
- Полный прогон `uv run pytest -q`.

## Срез 5. Краткая выжимка вместо полного ответа

- `llm/schemas.TutorReply.takeaway` — итог хода «что ученик узнал».
- `llm/prompts._TUTOR_TURN_CONTRACT` — поле и правило: 1–2 фразы без
  пересказа ответа; пустая строка, если объяснения не было.
- `core.turn`: `post_turn(takeaway=…)` кладёт итог в `meta` ответа
  (`key = "takeaway"`, обрезка `TAKEAWAY_MAX_CHARS`); `_tutor_branch` отдаёт
  его шестым элементом, ход занятия и чат повторения передают в `post_turn`.
- `web/notes.py`: ответ читается вместе с `meta`; выжимка — `takeaway`, без
  него первый абзац ответа; обрезка `BRIEF_CHARS = 320`.
- `templates/notes.html`, `notes.css`: вопрос — заголовок, блок «Что вы
  узнали», полный ответ — `<details>` «Полный ответ».
- Тесты: мета `takeaway`, приоритет итога над ответом, запасной первый абзац,
  обрезка, экранирование, сбой модели, промпт.
