# План: голосовой ввод и фильтры конспекта

Спека — `docs/superpowers/specs/2026-11-24-voice-input-design.md`.

## Срез 1. Модуль голосового ввода

- Иконка `mic` в `static/icons.svg`.
- `static/js/voice.js`: `window.Voice = { available, create(field) }`.
  Браузерное распознавание (`SpeechRecognition` / `webkitSpeechRecognition`),
  `ru-RU`, промежуточные результаты, вставка по курсору, `input`-событие,
  перезапуск на паузе, остановка, ошибки уведомлением, одно поле за раз.
- `lesson.html`: подключить `voice.js` перед `chat.js` и `practice.js`.
- `lesson.css`: кнопка микрофона и «слушаю» (пульс, `prefers-reduced-motion`).
- Тест: иконка `mic` в спрайте (общий тест спрайта).
- E2E `tests/e2e/test_voice.py`: подставной `SpeechRecognition`, вставка
  текста в поле чата, повторный клик останавливает запись.

## Срез 2. Чат тьютора

- `chat.js`: кнопка перед «Отправить»; отправка и переключение на наставника
  «Объясни новичку» останавливают запись; в ветке наставника кнопка скрыта.
- `form.querySelector("button[type=submit]")` — иначе микрофон перехватил бы
  выключение кнопки отправки.

## Срез 3. «Практика»

- `practice.js`: микрофон у открытого ответа (`open`), подсказка в
  placeholder; остановка при отправке и перерисовке; `voice` — на модуль.
- Короткий ответ, вариант и код — без микрофона.

## Срез 4. Фильтры конспекта

- `pages.notes_page`: параметр `lesson`, авто-выбор единственного курса,
  `lesson_filters`, `selected_lesson`, счётчики по показанному.
- `templates/notes.html`: панель `notes-toolbar` и ряды чипов «Курс» / «Тема».
- `notes.css`: панель, подписи рядов, счётчик у чипа темы.
- Тесты: чипы тем, фильтр по занятию, неизвестное занятие, один курс.

## Срез 5. Документы

- `CLAUDE.md`: `voice` в списке JS, подводный камень про голос и фильтры.
