# Показ llm_tutor по шагам: каждое действие — наглядно

Сценарий для показа тимлидам. На каждом шаге сначала ход в браузере, потом команда,
которая показывает, **что этот ход сделал внутри**: из чего собран контекст модели,
какие строки легли в журнал, как пересчиталась оценка ученика, что изменилось в
расписании, в «Объясни новичку» и в проекте.

Все команды — `scripts/showcase.py`. Он читает те же базы, что и сервер, и считает
всё функциями самого приложения (`core.context`, `student.beta`, `student.planner`,
`student.explain`…), поэтому показывает ровно то, что видит код. Модель скрипт не
вызывает.

Диаграммы к каждому шагу — на странице-артефакте «Разбор llm_tutor». Справочник с
ответами на неудобные вопросы — `docs/demo/README.md`.

## Как разложить экран

```
┌────────────────────────────┬──────────────────────────────────┐
│ Браузер: приложение        │ Терминал 1: sc watch             │
│ http://127.0.0.1:8000      │ живая лента записей в базу       │
│                            ├──────────────────────────────────┤
│                            │ Терминал 2: команды шагов        │
│                            │ sc context / mastery / review …  │
└────────────────────────────┴──────────────────────────────────┘
```

`watch` — главный «вау»-эффект: ученик нажимает кнопку, а справа через секунду
появляются строки `events`, пересчёт α/β, смена состояния и расписания. Его держат
открытым весь показ.

## 0. Подготовка (за день до показа)

```bash
git switch claude/great-pasteur-e8w5ce     # в ветке есть «Объясни новичку» и «Проект»
uv sync
# .env: OPENROUTER_API_KEY — настоящий ключ (урок, чат, новичок, наставник)
# материалы RAG — data/materials.sqlite3 (README, раздел про ingest); без них тьютор
#   опирается на конспект раздела, а в контексте будет «материалы RAG: empty»

# Отдельные базы для показа, чтобы не трогать рабочие:
export ACCOUNTS_DB_PATH=data/showcase/accounts.sqlite3
export USERS_DIR=data/showcase/users
alias sc="uv run python scripts/showcase.py"

uv run python scripts/demo_students.py            # Аня (3 занятия) и Борис (2, с ошибками)
uv run python -m llm_tutor.web.cli make-admin --email ann@example.com
uv run python -m llm_tutor.web                    # тот же терминал с export — сервер
```

Пароль демо-учеников — `секретный-пароль`. Во всех терминалах должны стоять одни и те же
`ACCOUNTS_DB_PATH` и `USERS_DIR`, иначе скрипт и сервер смотрят в разные базы.

Проверка за 2 минуты до начала:

```bash
sc students          # оба ученика на месте, у каждого свой файл базы
sc --email boris@example.com context | head -5    # контекст собирается
```

Прогон без ключа (репетиция): `demo_students.py` работает и так, но урок, новичок и
наставник в браузере ответят «не смог получить ответ».

**Сделать:** в браузере зарегистрируй новую ученицу (Вика) и запишись на курс — файл её

**Увидите:** по каждому блоку анкеты — события `source = self`, вес 0.3:

```
event  источник  ответ    вес   α/β        оценка
1      self      неверно  0.30  1.00/1.30  ██████░░░░░░░░ 0.43     ← «Впервые вижу»
```

**Сказать:** «Самооценка — свидетельство с весом 0.3. Она не закрывает занятие:

## Шаг 4. Ответ на задание и пересчёт оценки · 3 мин

**Сделать:** «Дальше» до «Проверим», затем **неверный** ответ, потом верный. Следи за
терминалом 1. После — `sc --email vika@example.com mastery --node pandas_structures` (id занятия —
во второй колонке `sc mastery`).

**Увидите в `watch`** (реальная лента):

```
20:02:04 📥 events #9 Series и DataFrame · checked · задание 13 · верно (result 1.0) · вес 1.00
20:02:04 📈 mastery Series и DataFrame: α 1.00→2.00, β 2.30→2.30, оценка 0.30 ▲ 0.47 ██████░░░░░░
20:02:04 🧭 state.passed_sections: [] → ['why']
20:02:04 🧭 state.section_id: 'why' → 'series'
```

Неверный ответ — `β += 1`, оценка падает (0.43 → 0.30), `state.check_misses: 0 → 1`,
выдан второй вопрос того же раздела.

**`mastery --node`** пересчитывает оценку по журналу, событие за событием:

```
event  источник  задание  ответ    вес   α/β        оценка
1      self               неверно  0.30  1.00/1.30  ██████░░░░░░░░ 0.43
8      checked   1        неверно  1.00  1.00/2.30  ████░░░░░░░░░░ 0.30
9      checked   13       верно    1.00  2.00/2.30  ███████░░░░░░░ 0.47
10     autotest  1021     верно    1.00  3.00/2.30  ████████░░░░░░ 0.57
```

**Сказать:** «Вердикт дал код: выбор варианта — `autocheck`, код ученика — тесты в
браузере (Pyodide). Модель здесь не участвовала. Ход — один коммит: реплики, событие,
α/β, состояние занятия, расписание. Оценка = α/(α+β), неопределённость — ширина
Beta. Вес: тесты и выбор — 1.0, открытый ответ по рубрике — 0.5, анкета — 0.3».

Таблица `sc mastery` целиком — колонки «α/β в БД» и «α/β сейчас» (с забыванием
λ = 0.05/сут), «оценка», «σ», «режим» планировщика, ступень повторения.

## Шаг 5. «Не понял» и лестница подсказок · 1 мин

**Сделать:** в чате урока напиши «не понял, объясни подробнее».

**Увидите в `watch`:**

```
💬 ученик не понял, объясни подробнее
💬 тьютор …Ок, остаёмся на этом узле и разбираемся глубже.
🧭 state.hint_level: 0 → 1
🧭 state.mode: None → 'reinforce'
```

**Сказать:** «Событий нет: просьба о помощи — не свидетельство незнания. Уровень
подсказки выбирает модель, но код не даёт подняться больше чем на 1 за ход — иначе
один ответ модели выдал бы готовое решение».

**Плюс:** выдели фрагмент конспекта → «Объясни проще». В ленте у реплики ученика
`meta={"quote": {"source": "theory", …}}` — цитата идёт модели как данные.

```
занятие                   лестница  ступень  интервал  срок
Series и DataFrame        ◉○○○○○    0        1 дн      25.10 20:01 UTC (просрочено 2.0 дн)

  1. Series и DataFrame  разминка · «Срочное»
```

В `watch` после ответа: `🔁 review_schedule …: ступень 0 → 1, срок … (через 3.0 дн)`,

вниз и завтра. Ответ повторения — обычное свидетельство в журнале, поэтому забытое
занятие само вернётся в маршрут. Разминка из 1–2 вопросов встаёт на границе занятий».

видно выше. Судит скрытый оценщик, но correct засчитывается, только если его цитата
дословно есть в реплике ученика. Что сказать новичку на ход — выбирает код (7
установок по приоритету). Это закрепление, а не экзамен: вес 0.3, занятие оно не
закрывает и не переоткрывает, но ошибка отправляет занятие в повторение на завтра».

но меняет её только ученик, а код выбрасывает лишние поля. Если модель выдала решение
кодом (блок длиннее 8 строк) — повтор со строгой установкой, потом запасная реплика.
Код и данные проекта — вне платформы, в журнал проект не пишет: защита у
преподавателя — следующий шаг».

## Шпаргалка команд

| Команда | Что показывает |
|---|---|
| `sc students` | ученики, файлы их баз, число событий и закрытых занятий |
| `sc watch` | живая лента: реплики, `events`, α/β, состояние, маршрут, расписание, explain, проект |
| `sc context [--text …] [--full]` | контекст тьютора, разрезанный на блоки с размерами |
| `sc context --role novice\|evaluator\|mentor` | что видят роли «Объясни новичку» (и есть ли эталон) |
| `sc context --role project` | что видит наставник проекта |
| `sc mastery [--all]` | оценка, σ, режим планировщика, статус, ступень повторения |
| `sc mastery --node ID` | пересчёт α/β занятия по журналу, событие за событием |
| `sc review` | лестница, сроки и что повторять прямо сейчас |
| `sc time-travel --days N [--node ID]` | сдвинуть сроки повторения (только для показа) |
| `sc explain [--session N]` | задания, сессии, покрытие идей, установки новичку, события |
| `sc explain --reference ID` | эталон занятия: идеи и загвоздки |
| `sc project` | карточка, этапы, обязательные заметки, чат с предложениями |
| `sc close-module N…` | закрыть модули в маршруте без событий (только для показа) |

Учеников несколько — добавляй `--email`. Цвета выключаются переменной `NO_COLOR=1`.

## Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| `Нет базы аккаунтов …` | в терминале нет `export ACCOUNTS_DB_PATH/USERS_DIR`, как у сервера |
| `watch` молчит | смотришь не того ученика: `--email`; или ход не дошёл до сервера (ошибка в браузере) |
| тьютор отвечает «не смог получить ответ» | нет ключа или сети; проверочные задания и повторение работают и без модели |
| после `close-module` урок не идёт | висит «Объясни новичку» — это и есть блокировка; объясни или покажи на другом ученике |
| «Проект» не открывается | `sc project` покажет, сколько занятий закрыто; `close-module 1 2 3 4 5` |
