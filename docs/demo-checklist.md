# Чек-лист показа: курс из пяти модулей

Бот: `uv run python -m llm_tutor.bot.main` (рабочая БД `data/llm_tutor.sqlite3`:
курс и материалы загружены, данные ученика стёрты — бот видит нового ученика).
Отмечаем ✅/❌ и пишем, что увидели.

| # | Действие | Ожидаем |
|---|---|---|
| 0 | `/start` | «👋 Привет! Я тьютор по курсу mlcourse.ai: 5 модулей, от pandas до случайного леса.» и анкета модуля 1 |
| 0а | Пройти анкету | Первая часть урока темы и кнопка «Дальше ▶️» — **без вопроса** |
| 0б | «Дальше ▶️» до конца, потом «Проверим ✅» | Части показываются сразу (без «печатает…»), после последней — один вопрос с вариантами |
| 0в | Вместо ответа написать «а что такое индекс» (без «?») | Ответ тьютора, задание висит: «Задание ждёт ответа», провала нет |
| 0г | Ответить неверно | Разбор ошибки и **другой** вопрос по той же теме |
| 0д | Ещё раз неверно | Разбор, «Тема пока слабое место — вернёмся к ней позже», первая часть следующей темы |
| 0е | Верный ответ на проверке | «✅ Тема … закрыта» и сразу первая часть следующей темы с «Дальше ▶️» |
| 1 | `/start` ещё раз | «👋 С возвращением! Модуль 1 «Первичный анализ данных с Pandas» — продолжаем «…».» Без анкеты и без задержки на модель |
| 2 | `/plan` | Шапка «🗺 Маршрут · Модуль 1/5 · Первичный анализ данных с Pandas — пройдено X из 21», в списке только темы модуля 1 |
| 3 | «☰ Меню» → «🎚 Темы» (или `/themes`) | «Куда идём?» и пять модулей: «▶️ 1. Первичный анализ данных с Pandas», «🔜 2. Визуальный анализ данных» … «🔜 5. Бэггинг и случайный лес» |
| 4 | Тап по модулю 2 | Темы модуля 2 («Типы признаков», «matplotlib и seaborn», …) и кнопка «← Модули» |
| 5 | «← Модули» | Снова список пяти модулей |
| 6 | Модуль 2 → тема, например «Зачем визуализировать данные» | Если пререквизиты не закрыты: «… — не закрыты пререквизиты (…). Всё равно идём?» → «🎯 Да» |
| 7 | После прыжка | «📘 Модуль 2 · Визуальный анализ данных», вводная и анкета модуля 2 (вопрос об уровне, потом блоки) |
| 8 | Пройти анкету модуля 2 | Урок начинается **с выбранной темы**, а не с первой темы модуля |
| 9 | `/plan` | «Модуль 2/5 · Визуальный анализ данных» |
| 10 | Вопрос свободным текстом по теме модуля 2 | Ответ опирается на материалы модуля 2, без материалов модулей 3–5 |
| 11 | `/start` ещё раз | «С возвращением! Модуль 2 «Визуальный анализ данных» — …» |

Если что-то пойдёт не так — откат БД из бэкапа (бот остановлен, копировать
backup API, а не файлом): `…backup-20261009-144030` — курс из 5 модулей и
прогресс прежнего ученика; `…backup-20261009-143610` — состояние до загрузки
модулей 2–5.
